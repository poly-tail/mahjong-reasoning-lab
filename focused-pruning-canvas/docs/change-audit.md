# 変更監査

仕様の削除・弱体化なし。受入条件の正本は acceptance.md。

| 変更前                            | 変更後                                             | 理由                                            | 吸収先                                                                   | 復活条件                                                                   |
| --------------------------------- | -------------------------------------------------- | ----------------------------------------------- | ------------------------------------------------------------------------ | -------------------------------------------------------------------------- |
| 空フォルダならルートへ新規作成    | 既存アプリ内の未使用 focused-pruning-canvas へ作成 | 依頼第0節と既存ファイル保全                     | 本パッケージのルート                                                     | 独立配置時も同一ファイル構成                                               |
| 依存を新規取得して環境を構築      | 既存の互換依存を使用し、lockfileを独立生成         | 環境のオフライン制約を維持して実装・検証を続行  | READMEの独立配置用npm ci手順、verificationの未確認事項                   | registryへアクセスできる再現環境でnpm ciを実行                             |
| ルート配置を前提としたCI workflow | 独立パッケージ内のworkflowテンプレート             | 既存アプリに対する変更を避ける第0節の指示を優先 | READMEとverificationに入れ子のworkflowが親repoでは実行されないことを明示 | 本パッケージを独立repo rootへ配置、または親repo CIへの接続を依頼されたとき |

計算式・seed・上限・保護規則・三値論理・入出力の意味は変更していない。reviewで見つけた不具合の修正は verification.md を参照。
