# Quick Reading Input

QuickReadingInputPanel は、Phase1: Reading Probability Core の入力UIです。

読みを4軸への影響、候補確率、未配分確率、枝刈り/ロック方針として active case に反映します。

Phase1では、押し引きの最終判断、牌選択の推奨、局収支EV、順位点EV、Action Recommendation は扱いません。4軸評価だけで「押す/引く/何を切る」を推奨してはいけません。

## 確率とスコアを分ける

- 候補確率は%で扱います。
- 未配分確率は%で扱います。
- 影響ウェイトは0〜100のスコアで扱います。
- 軸確信度は0〜100のスコアで扱います。

候補確率と未配分確率は%です。影響ウェイトと軸確信度は%ではなく、0〜100のスコアです。

4軸は読みの影響射影先であり、最終的な行動判断軸ではありません。

## 影響ウェイト

影響ウェイトは、その読みが正しい場合に、その軸をどれだけ動かすかを表す重みスコアです。確率ではないため、4軸の合計を100にする必要はありません。

同じ読みが複数軸を同時に強く動かしてよいです。たとえば「染め移行」は打点と待ち・形の両方を強く動かすことがあります。

表示例:

- `70/100`
- `35/100`
- `0/100`

内部的には従来どおり0〜1へ変換して保存します。UIで70を入力した場合、内部の `magnitude` は `0.7` です。

## 軸確信度

軸確信度は、その軸への影響方向・影響ウェイトの見積もりをどれだけ信頼するかを表すスコアです。読み全体の確信度や候補確率とは別です。

UIで80を入力した場合、内部の axis confidence は `0.8` です。

## 目安

影響ウェイト:

- 0: 影響なし
- 1〜20: 弱い
- 21〜40: 中
- 41〜60: 強い
- 61〜80: 非常に強い
- 81〜100: 決定的級、過信注意

軸確信度:

- 0〜20: 根拠がかなり弱い
- 21〜40: 弱い根拠
- 41〜60: 仮説として置ける
- 61〜80: 比較的信頼できる
- 81〜100: 強い根拠

影響ウェイトが高くても、軸確信度が低い場合は過大反映に注意してください。mixed/unknown の軸が残る場合、hard pruneではなく downweight / keep top-k を検討してください。

## 未配分確率

候補確率合計が100%未満の場合、その差分を未配分確率として表示します。

未配分確率は、候補漏れ、例外パターン、観測ノイズ、未知バッファを表します。既存候補への自動按分は禁止です。按分する場合は、ユーザーが明示的に「既存候補へ按分」を選びます。

扱い:

- 具体候補を提案する
- 例外集に入れる
- 未知バッファとして保持する
- 既存候補へ明示的に按分する
- いったん未配分のまま残す

Reading Drawer から追加する候補や Exception Library に入れる候補も、押し引き判断ではなく読み候補空間の整理に使います。
