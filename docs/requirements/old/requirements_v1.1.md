# Tenhou Hojo Helper 要件定義書 v1.1

## 1. 目的
- 捨て牌可視化ツールの要件を整理し、機能責務を明確化する。

## 2. スコープ
- GUI 描画、牌画像管理、捨て牌配置、外部キャプチャとの連携境界を対象とする。
- ネットワーク処理、牌認識、高度な分析は対象外とする。

## 3. 用語
- **座席**: 自家、下家、対面、上家。
- **捨て牌データ (`sutehaiLL`)**: 座席ごとの牌 ID とドロー種別を持つデータ。
- **ドロー種別**: 手出しとツモ切りの区別。

## 4. システム概要
- Python 3.x と `tkinter` による GUI アプリケーション。
- `Pillow` を用いて画像の縮小・回転・差分生成を行う。
- キャプチャモジュールが捨て牌データを供給する。

## 5. 利用者
- 対局の振り返りを行う解析者。
- 維持開発を行う開発者。

## 6. 機能要件
- **REQ-GUI-01**: 4 座席分の捨て牌を同時表示する。
- **REQ-GUI-02**: 標準牌と赤牌を座席ごとの向きで表示する。
- **REQ-GUI-03**: ツモ切りを手出しと区別して見せる。
- **REQ-GUI-04**: 座席ごとに分かりやすい捨て牌領域を持つ。
- **REQ-GUI-05**: 時系列順を保った折り返し表示を行う。
- **REQ-GUI-06**: 更新後も GUI の応答性を維持する。
- **REQ-DATA-01**: 牌 ID とドロー種別を含む捨て牌データを受け付ける。
- **REQ-DATA-02**: 局単位の順序を保持する。
- **REQ-EXT-01**: 外部更新を受けて再描画できる。
- **REQ-OPS-01**: 局開始時にリセットできる。

## 7. 非機能要件
- Windows 10 以降と Python 3.x を対象とする。
- 牌画像は実行物と同梱する。
- 画像や座標定数を調整しやすい構造とする。
