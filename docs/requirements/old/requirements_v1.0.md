# Tenhou Hojo Helper 要件定義書 v1.0

## 1. 目的
- 天鳳の捨て牌を可視化し、対局の振り返りを支援する初期版デスクトップツールの要件を定義する。

## 2. スコープ
- GUI のウィンドウ構成、牌画像の読み込み、回転表示、捨て牌配置を対象とする。
- パケット取得、ネットワーク処理、高度な解析は対象外とする。

## 3. 用語
- **座席**: 自家、下家、対面、上家。
- **`sutehaiLL`**: 座席ごとの捨て牌履歴を保持するコレクション。
- **ドロー種別**: `0` を手出し、`1` をツモ切りとする。

## 4. システム概要
- Python 3.x、`tkinter`、`Pillow` を用いる。
- ローカルに置かれた牌画像 `1.png` ～ `37.png` を読み込む。

## 5. 利用者
- 天鳳対局の振り返りを行う利用者。
- ツールを保守・拡張する開発者。

## 6. 機能要件
- **REQ-GUI-01**: タイトル `Tenhou Helper` の 670x640 ウィンドウを表示する。
- **REQ-GUI-02**: 37 種の牌画像を読み込み、リサイズして保持する。
- **REQ-GUI-03**: 座席ごとに牌画像を回転表示する。
- **REQ-GUI-04**: ツモ切り用の視覚差分画像を生成する。
- **REQ-GUI-05**: 4 つの座席領域に捨て牌を描画する。
- **REQ-GUI-06**: 捨て牌は 6 枚ごとに折り返して表示する。
- **REQ-DATA-01**: `sutehaiLL` は 4 座席分の打牌情報を保持する。
- **REQ-EXT-01**: 外部モジュールから捨て牌情報を受け取れる構造にする。
- **REQ-OPS-01**: 局開始時のリセット手段を用意する。

## 7. 非機能要件
- Windows 10 以降で動作する。
- 画像ロードは起動時に完了する。
- レイアウト定数を変更しやすい構造にする。

## 8. データ要件
- 牌画像一式が揃っていること。
- 捨て牌順が対局進行順と一致すること。
