# AI向け：日本リーチ麻雀（4人）ルール＋進行（開始可能版）＋質問テンプレ

この文書は、本プロジェクト内で麻雀ルール全体を参照するときの基準文書です。
個別ロジックは別文書へ分けつつ、ここではゲーム進行、鳴き、和了、点数、質問テンプレートまでをまとめて扱います。

## 前提
- 追加指定：切り上げ満貫＝採用

## 関連文書
- 鳴き可否とラグ判定は `docs/mahjong/mahjong_call_rules.md`
- 危険度ロジックは `docs/mahjong/mahjong_danger.md`

## A. 用語（席風・相対位置）
- 席風：`east / south / west / north`
- 相対位置（ユーザー視点）：
  - 上家 `kamicha`：あなたの直前（あなたが**チー可能**な相手）
  - 対面 `toimen`：正面
  - 下家 `shimocha`：あなたの次（あなたが**チー不可**な相手）

---

## B. 牌セット（136枚）と表現
- 数牌：`1-9m 1-9p 1-9s`、字牌：`east south west north white green red`
- 各4枚、計136枚
- 赤ドラ：`0m 0p 0s`（=赤5）を採用（各1枚、計3枚）

---

## C. ゲーム開始（局の初期化） ※ここが“開始可能”のための追加仕様
### C1. 山と王牌
- 136枚をシャッフルして牌山を作る。
- 牌山の末尾から **14枚を王牌（dead_wall）** とする。
  - 王牌の内訳：ドラ表示牌/裏ドラ表示牌の位置、嶺上牌（カンツモ牌）の位置を管理する。
- 残りを **通常山（live_wall）** とする。

### C2. ドラ表示牌（初期）
- 局開始時点で **ドラ表示牌を1枚めくる**（`dora_indicators[0]`）。
- 裏ドラ表示牌はリーチ和了時のみ参照するが、位置としては最初から確保される。

### C3. 配牌（13枚）
- 配牌は **東家→南家→西家→北家の順**で行う。
- 各プレイヤーに **13枚**配る（一般的な配牌手順の詳細（4枚×3回＋1枚等）は実装上の内部手順でよい。結果として13枚であれば可）。

### C4. 第1ツモと開始手番
- **東家（親）のツモ番から開始**する。
- 開始時、東家は `live_wall` から1枚ツモし **14枚**になり、最初の打牌を行う。

---

## D. ツモ番の状態遷移（基本ループ）
現在手番のプレイヤー `P` について：
1. `P` が `live_wall` から1枚ツモ（通常は手牌14枚）
2. `P` は以下を任意に宣言できる（合法な場合のみ）：
   - ツモ和了
   - リーチ（条件は後述）
   - カン（暗槓/加槓。明槓は他家捨て牌に反応）
3. `P` は1枚捨てる（手牌13枚へ）
4. 捨て牌に対し、他家はリアクションを宣言できる（優先順位あり）
5. リアクションが無ければ、手番は **次の席風（東→南→西→北→東）** に移る。

---

## E. 捨て牌へのリアクション（ロン/鳴き）と手番の扱い
### E1. 優先順位
同一捨て牌に対する優先順位：
- `ron > minkan > pon > chi`

複数ロン：
- デフォルト：**ダブロン/トリプルロン許可**
- 頭ハネ等が必要なら `needs_user_decision`。

### E2. チーの制約（重要）
- **チーは上家（捨てた相手が自分の上家）からのみ可能**。
- ポン/明槓/ロンは誰の捨て牌からでも可能（ただしフリテン等の制約あり）。

### E3. 鳴き成立時の手番
- チー/ポン/明槓が成立した場合：
  - 鳴いたプレイヤーが **そのまま打牌**する（手番を獲得する）。
  - 以降の手番は、その鳴いたプレイヤーの次席へ進行する。

---

## F. リーチ（立直）
- 条件：門前（副露なし。ただし暗槓は門前扱い）、テンパイ、供託1000点
- リーチ後：原則手替わり不可（ツモ切り扱い）
- 一発：リーチ後、次の自分のツモ番までに **鳴き（ポン/チー/明槓）が入らず** 和了で成立（カン扱いは差分になり得る）

---

## G. カン（槓）と王牌処理（開始可能にするための必須仕様）
- 種類：
  - `ankan`（暗槓）：手牌同一4枚、門前性維持
  - `minkan`（明槓）：捨て牌で同一4枚完成
  - `kakan`（加槓）：ポンに4枚目追加
- カンが成立したら：
  1. `dead_wall` から **嶺上牌（rinshan）** を1枚ツモして手牌に加える
  2. **ドラ表示牌を1枚追加**する（`dora_indicators` に追加）
  3. その後、通常通り1枚捨てる
- 槍槓：加槓に対するロンを採用（役：槍槓）
- 途中流局（四槓散了等）はデフォルト不採用（必要なら分岐）

---

## H. 和了形・役要件・フリテン
- 基本形：4面子+1雀頭
- 特殊形：七対子、国士無双（採用）
- 和了は **役あり（最低1翻）** 必須（ドラのみ不可）
- フリテン：自分の捨て牌にある待ち牌でロン不可（同巡フリテン含む）。ツモは可。

---

## I. 局の終了条件（開始可能にするための必須仕様）
局は以下で終了する：
1. 誰かが和了（ツモ/ロン）
2. `live_wall` が尽きる（荒牌・流局）
   - ノーテン罰符・テンパイ料・親流れ/連荘などはローカル差分になり得るため、必要なら `needs_user_decision` に提示する。
3. （任意）途中流局（九種九牌、四風連打、四槓散了等）はデフォルト不採用。必要なら分岐。

---

## J. ドラ
- ドラ表示牌の次牌がドラ（9→1、字牌は順繰り）
- 字牌循環：
  - 風：`east -> south -> west -> north -> east`
  - 三元：`white -> green -> red -> white`
- 赤ドラはドラ加算
- 裏ドラ：リーチ和了時のみ参照

---

## K. 役（採用セット：標準リーチ麻雀）
（省略せず列挙）
- 1翻：立直、一発、門前清自摸和、平和、断么九（喰いタン採用）、一盃口、役牌（白發中・場風・自風）、嶺上開花、槍槓、海底摸月、河底撈魚
- 2翻：七対子、対々和、三暗刻、三色同順、一気通貫、混全帯么九、三色同刻、三槓子、小三元、混老頭
- 3翻：二盃口、純全帯么九、混一色
- 6翻：清一色
- 役満：国士無双、四暗刻、大三元、字一色、緑一色、清老頭、四槓子、小四喜、大四喜、九蓮宝燈、天和、地和
- ローカル役（流し満貫、人和 等）・ダブル役満・数え役満上限はデフォルト不採用（必要なら分岐）

## L. 符・翻・点数（切り上げ満貫：採用）
### L1. 符（概要）
- 基本符20、七対子は固定25符
- 門前ロン+10符、ツモ+2符（平和ツモ等は一般的処理）
- 面子符：刻子/槓子、么九牌か否か、暗/明で変動
- 待ち符：単騎/嵌張/辺張 +2符
- 符は10符単位に切り上げ

### L2. 翻
- `han_total = yaku_han + dora_han + aka_dora_han + ura_dora_han`
- ドラは翻に加算するが役にはならない

### L3. 点数計算（処理順序固定）
1. `fu` と `han_total` を確定
2. 満貫未満の基本点：`fu * 2^(han_total+2)` を基礎（一般的手順）
3. 親子・ロンツモ別に支払点へ変換
4. 各支払点を100点単位に切り上げ
5. 満貫以上（満貫/跳満/倍満/三倍満/役満）を適用
6. **切り上げ満貫（採用）**：
   - 5の後、満貫未満でも支払点が満貫相当（例：子ロン7700、親ロン11600相当）なら満貫へ切上げ
7. 本場（`honba`）と供託（`riichi_sticks`）を加算

# M. ユーザーが質問を書くための入力テンプレ（必須）
ユーザーは以下のテンプレで局面を記述する。欠落がある場合、AIは勝手に補完せず `assumptions` と `needs_user_decision` を返す。

## M1. 進行・初期化情報（ゲーム開始/再現に必須）
- `seed`: 任意（再現性が必要な場合）
- `you_seat`: east/south/west/north
- `round_wind`: east/south/west/north
- `hand_no`: int
- `honba`: int
- `riichi_sticks`: int
- `dora_indicators`: [ ... ]
- `ura_dora_indicators`: [ ... ]  # 不明なら空
- `dead_wall_known`: bool         # 王牌の具体配列を与えるか
- `wall_tiles_left`: int|null     # 不明ならnull
- `current_turn_seat`: east/south/west/north  # 現在手番（開始直後はeast）

## M2. 席対応（相対位置）
- `seat_map`:
  - `kamicha`: seat
  - `toimen`: seat
  - `shimocha`: seat

## M3. 手牌・河・副露
- `tiles_hand`: [ ... ]           # あなたの手牌（13 or 14）
- `melds`: [ {type, from, tiles, called_tile}, ... ]
- `discards_you`: [ ... ]
- `players`:                      # 他家（分かる範囲で）
  - `east|south|west|north`:
    - `melds`: [...]
    - `discards`: [...]
    - `riichi_state`: "none"|"riichi"|"double_riichi"

## M4. 直近アクション
- `last_action`:
  - `actor`: seat
  - `action`: "start"|"draw"|"discard"|"chi"|"pon"|"ankan"|"minkan"|"kakan"|"riichi"|"ron"|"tsumo"
  - `tile`: "5m" 等（該当時）
  - `from`: seat|null
  - `notes`: "任意"

## M5. 質問
- `question`:
  - `task_type`: "legality"|"agari_check"|"scoring"|"strategy"|"what_if"|"explain_rule"
  - `ask`: "知りたいこと（1〜3文）"
  - `options_considered`: ["..."] # 任意
  - `constraints`: "任意"

---

# N. AIの回答フォーマット（固定）
AIは以下の順で返す：
1. `answer_summary`
2. `rule_basis`（条番号付き）
3. `checklist`
4. `result`
5. `alternatives`（必要ならMarkdown表）
6. `assumptions` / `needs_user_decision`
