- `mahjong_rule.md`: 麻雀ルールの基礎
- `mahjong_call_rules.md`: 鳴き可否やラグ判定
- `mahjong_danger.md`: 危険度ロジック
- `hand_analysis.md`: シャンテン / 待ち牌
- `hand_analysis_terms.md`: 手牌分析用語
- `opponent_tenpai_readiness.md`: 他家読み
- `comparison_trace_reading_engine.md`: 比較痕跡ベースの読み設計
