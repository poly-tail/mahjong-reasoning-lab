# 他家聴牌度合いロジック

この文書は、他家の「いまどれくらい聴牌に近いか」を見るためのロジック方針をまとめる。
ここで直接ほしいのは厳密な `聴牌率` ではなく、まずは `聴牌に近い度合い` や `手牌価値度合い` に近い内部指標である。
実装上の互換 field 名 `tenpai_probability` は `0..100` に正規化した heuristic readiness score を指し、統計的に校正された確率ではない。

## 基本方針

- まずは `一時無筋免除を除いた筋本数` をベースに見る
- ただし、筋本数だけで即 `聴牌率` に変換しない
- 先に `聴牌近い度合い` を作り、最後に人間が `イーシャンテン以上率` や `聴牌率` に読み替える
- さらに、条件戦ではない通常局面では `手牌価値度合い` も別軸で持つ

## 1. ベース指標

### 一時無筋免除を除いた筋本数

- 危険度ロジックで使う筋本数のうち、`一時 safe` による一時的な無筋免除は聴牌度合い側では使わない
- 理由:
  - 一時無筋免除は「今この瞬間に押しやすいか」の材料であり、「手牌がどこまで進んでいるか」とは別だから
  - 他家の進行度を見るときは、より持続的な筋本数減少を見るほうがよい

### 解釈

- 筋本数が減るほど、手牌進行や待ちの整理が進んでいる可能性を上げる
- ただし、筋本数が少ないだけで即テンパイ寄りと断定しない

## 2. 強い偏りは即スコア化せずアラート止まり

筋本数が少なめでも、次のような偏りが強すぎる場合は、まずは `アラート` に留める。

- 手役寄りの進行が強い
- 内外傾向が強すぎる
- 牌効率より役作り・形固定の色が濃い

理由:

- こうしたケースは `テンパイが近い` というより、`手役の都合で河が偏っている` 可能性がある
- この段階で聴牌率へ直接変換すると過大評価しやすい

## 3. ツモ切りと手出しの時間変化

### ツモ切りが増えると緩やかに上げる

- ツモ切りが増えてくると、聴牌近い度合いは緩やかに上げる
- これは `手牌選択の自由度が減ってきた` 可能性を表す

### その後に手出しが入ると、さらに少し上げる

- ツモ切りが続いたあとで手出しが入ると、聴牌近い度合いをもう少しだけ上げる
- これは `形の変化を伴う選択が残っているが、かなり詰まってきた` シグナルとして扱う

## 4. 直接テンパイ率よりも内部スコアを先に作る

いきなり `聴牌率 xx%` を出すより、まずは内部スコアを作る。

候補:

- `tenpai_readiness_score`
  - 聴牌にどれだけ近いか
- `hand_value_score`
  - 条件戦ではない前提での、手牌価値の総合度合い
- `push_alert`
  - 押し気味、または押し返し気味の挙動アラート

## 5. 手牌価値度合い

条件戦っぽくない通常局面では、`手牌価値度合い` を次の 3 軸で見る。

- 打点
- 聴牌度
- 待ちの良さ or 受け入れの良さ

### 聴牌時

- 待ちの良さを重視する

### 非聴牌時

- 受け入れの良さを重視する

## 6. 将来追加する要素

以下は `Coming Soon` として扱う。

- リーチしたかどうか
- 鳴いたかどうか
- 牌理危険度がかなり高い牌を打ったかどうか
- 頑張って押していたが、途中で降りた判定
- 南 2 以降や段ラス目など、条件戦寄りの補正

## 7. 現時点のまとめ

- まず見るのは `一時無筋免除を除いた筋本数`
- そこに `ツモ切り増加` と `ツモ切り後の手出し` の時間変化を重ねる
- 強い役寄り・内外偏りは、まずは `アラート` として別出しする
- 出力の本体は `聴牌率` ではなく、`聴牌近い度合い` や `手牌価値度合い`
