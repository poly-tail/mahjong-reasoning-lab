# 0. 結論サマリ

このチャットの最終結論は、**ベタオリ手詰まりは安全牌ランキングではなく、安全資源の順序最適化として扱うべき**というものです。

| 論点 | 最終結論 |
|---|---|
| 瞬間安全牌 vs 2枚ある牌 | 放銃率差が小さいなら、2枚ある牌の「通れば次巡現物」の価値が強い。 |
| 瞬間安全牌 vs 3枚ある牌 | 3枚ある牌はさらに強いが、瞬間3%牌に対して9%牌を常に先切りできるほど万能ではない。 |
| 脇救済33% | 「脇全体で一巡33%」として扱う。1人あたり33%ではない。 |
| 残り巡数 | 5-8巡では、単純に長いほど無限に3枚有利ではない。特殊資源消費後の尾部リスクも見る。 |
| 最終モデル | 一巡救済率、残り巡数、2枚/3枚資源、fallbackリスクを入れた動的計画法で比較する。 |

最も重要な実戦ラベルは次です。

> **安全牌資源の順序最適化**  
> 目の前の1牌の放銃率ではなく、残り巡目に対して「どのリスクをいつ消費するか」を最適化する。

# 1. 問題設定

対象局面は、2段目最後あたりでベタオリ中に手詰まり気味になり、次のような選択に迷うケースです。

- 1枚だけある瞬間的に安全そうな牌を切る。
- 2枚ある19牌を先に切り、通れば次巡も同じ牌を現物として使う。
- 3枚ある牌を先に切り、通ればさらに2巡分の現物資源を作る。

典型例として、会話では次の比較を扱いました。

| 候補 | 放銃率の例 | 性質 |
|---|---:|---|
| 中筋モロヒッカケ | 4-5% | 瞬間は比較的安全だが1巡資源 |
| 無筋19牌 2枚 | 8-9% | 1枚目が通れば2枚目はリーチ者への現物 |
| 字牌・かなり安全な牌 | 2-3% | 危険牌を後回しにする低コスト保険 |
| 3枚ある牌 | 6-10%程度で比較 | 1枚目が通れば2巡分の現物資源 |

# 2. 変数定義

| 記号 | 意味 |
|---|---|
| `m` | 瞬間安全牌の放銃率 |
| `n` | 2枚/3枚ある牌の1枚目の放銃率 |
| `q` | 一巡救済率。次の自分番までに危険牌を切らずに済む確率 |
| `k` | 残り自分番数 |
| `c` | 同種牌の枚数。2枚または3枚 |
| `g` | 特殊資源を使い切った後のfallback危険牌の放銃率 |

一巡救済率 `q` は、厳密には以下のように分解できます。

```text
q = 1 - (1 - t) * (1 - s) * (1 - d) * (1 - o) * (1 - h)
```

| 記号 | 意味 |
|---|---|
| `t` | リーチ者ツモ和了による局終了率 |
| `s` | 脇の切りで自分の使える安牌が増える確率 |
| `d` | 脇が放銃して局が終わる確率 |
| `o` | 脇が和了して局が終わる確率 |
| `h` | 自分のツモで安牌を引く確率 |

この資料のグラフでは、指示に合わせて **脇救済を脇全体で一巡33%** と固定しています。リーチ者ツモ率は別枠で足していません。

# 3. 会話中のモデル変遷

## 3.1 2巡ローカル比較

最初の比較では、次の2ルートを見ました。

| ルート | 打牌順 | 見ている範囲 |
|---|---|---|
| 瞬間安全牌先 | `m -> n` | 次巡までにnを切らずに済むか |
| 2枚持ち先 | `n -> 現物` | nが通れば2巡凌げる |

このモデルでは、たとえば `m=5%`, `n=8%` なら、瞬間安全牌先が有利になるには、次巡までの救済率が約60.5%以上必要でした。

```text
(1 - m) * { q + (1 - q) * (1 - n) } > 1 - n
```

この時点では、2枚持ち先切りがかなり強く見えます。

## 3.2 3巡順序比較への修正

ただし、残り6-7巡あるなら、2巡で評価を止めるのは不十分です。

比較対象は実際には次です。

| ルート | 打牌順 |
|---|---|
| 瞬間安全牌先 | `m -> n -> 現物` |
| 2枚持ち先 | `n -> 現物 -> m` |

つまり、2枚持ち先切りは2巡凌げますが、その後に瞬間安全牌 `m` を切る局面が残ります。

この修正によって、`m=4%`, `n=9%` のように放銃率差が大きいケースでは、瞬間安全牌先もかなり復権しました。

## 3.3 最終モデル: 動的計画法

さらに、残り5-8巡を扱うには、特殊資源を使い切った後の尾部リスクも必要です。

この資料の最終グラフでは、次の再帰式で評価しました。

```text
V(state, k) = max_action [
  (1 - risk(action)) * { q + (1 - q) * V(next_state, k - 1) }
]
```

`state` には以下を含めています。

- 瞬間安全牌が残っているか。
- 多枚数牌の1枚目がまだ危険か。
- 通過後の現物化コピーが何枚残っているか。
- 特殊資源を使い切った後のfallback牌があるか。

本資料では `q=33%`, `g=12%` としてグラフ化しています。

# 4. 脇救済33%の扱い

会話中で重要だったのは、**33%が脇全体なのか、1人あたりなのか**です。

| 解釈 | 脇全体の救済率 |
|---|---:|
| 脇全体で33% | 33.0% |
| 脇1人あたり33% | `1 - 0.67^2 = 55.1%` |

リーチ者ツモ和了率5%も足す場合は、以下のように合成します。

```text
q_total = 1 - (1 - 0.05) * (1 - q_side)
```

| 前提 | q_total |
|---|---:|
| 脇全体33% + ツモ5% | 36.35% |
| 脇1人33%ずつ + ツモ5% | 57.35% |

この差は非常に大きいため、**脇33%は必ず定義を固定する必要があります**。

# 7. 2枚ある牌 vs 3枚ある牌

3枚ある牌は、2枚ある牌よりも1巡ぶん多く現物資源を作れます。  
ただし、残り巡数が長ければ常に一方的に3枚有利になるわけではありません。追加1巡の価値は、救済抽選、尾部リスク、そこまで生存している確率で割り引かれます。

# 8. 実戦判断ルール

## 8.1 瞬間安全牌が3%級

| 比較 | 判断 |
|---|---|
| 3% vs 2枚持ち8-9% | 基本は3%牌先切り寄り |
| 3% vs 3枚持ち6%前後 | 接戦 |
| 3% vs 3枚持ち8-9% | 基本は3%牌先切り寄り |

会話中では一時的に「3% vs 9%が境界帯」と整理しましたが、これは `m approx q*n` のかなり粗い局所近似です。  
最終DPモデルでは、瞬間3%牌はかなり強く、9%牌を2枚/3枚あるという理由だけで先に切るのは過大評価になりやすいです。

## 8.2 瞬間安全牌が4%級

| 比較 | 判断 |
|---|---|
| 4% vs 2枚持ち8-9% | 2枚持ちも見えるが、まだ接戦 |
| 4% vs 3枚持ち8-9% | かなり接戦 |

4%は「本当に安全」とは言い切れない境界牌です。

## 8.3 瞬間安全牌が5%級

| 比較 | 判断 |
|---|---|
| 5% vs 2枚持ち8%前後 | 2枚持ち先切りがかなり見える |
| 5% vs 3枚持ち9-10% | 3枚持ち先切りが有力になりやすい |

5%牌は、もはや「低コスト保険」とは呼びにくいです。  
この水準になると、多枚数牌の継続安全価値がかなり効きます。

# 9. 捨てるべき誤解

| 誤解 | 正しい理解 |
|---|---|
| 瞬間一番安全牌を常に切ればよい | 残り巡目の安全資源を枯らす可能性がある。 |
| 2枚ある牌は常に強い | 1枚目の放銃率が高すぎると、低リスク牌で後回しにする方がよい。 |
| 3枚ある牌なら9%でも先切りしてよい | 瞬間3%牌相手では過大評価になりやすい。 |
| 脇33%は毎回同じ意味 | 脇全体33%と1人あたり33%は全く違う。 |
| 残り巡数が長いほど3枚牌が無限に強くなる | 追加1巡の価値は効くが、尾部リスクと生存確率で割り引かれる。 |

# 10. 今後の検証論点

このモデルは理論整理としては有効ですが、実戦に投入するには次を検証すべきです。

1. 中筋モロヒ、無筋19、字牌、生牌役牌の実放銃率分布。
2. 脇救済率の実測。特に「脇が安牌を切った」ではなく「自分がその牌を使える」確率。
3. リーチ者ツモ率、脇放銃率、脇和了率の分解。
4. 点棒状況・順位EVを入れた場合の補正。
5. fallbackリスク `g` の妥当値。

# 11. 最終結論

このチャットの最終結論は次です。

> **ベタオリ手詰まりでは、瞬間放銃率だけでなく、残り巡目に対する安全資源の順序最適化を見る。**

特に、

- 放銃率差が小さいなら、2枚/3枚ある牌の価値は上がる。
- 瞬間牌が3%級なら、かなり強い低コスト保険になる。
- 瞬間牌が4-5%に上がると、多枚数牌の価値が一気に強くなる。
- 3枚持ちは2枚持ちより強いが、9%牌を3%牌より常に優先できるほどではない。
- 脇救済33%は毎巡のハザードとして扱うが、独立性と定義に注意する。

以上をまとめると、実戦では次の手順で判断するのがよいです。

```text
1. 瞬間安全牌の放銃率 m を見積もる。
2. 2枚/3枚ある牌の1枚目の放銃率 n を見積もる。
3. 脇救済率 q を、脇全体か1人あたりか明確にする。
4. 残り巡数 k とfallbackリスク g を見る。
5. 境界表・グラフに照らして、どちらを先に切るか決める。
```
