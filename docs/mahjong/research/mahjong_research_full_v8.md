# 1. 全体結論: 麻雀研究を好み論から脱出させる

麻雀判断を「好み」「打ち手の感覚」「どちらもあり」で止めないためには、判断を次の形式で扱う必要がある。

> 観測情報から仮説分布を作り、その仮説分布から結果確率を作り、結果を効用に変換し、選択肢間の差分と不確実性幅で比較する。

麻雀は以下の性質を持つ意思決定問題である。

| 性質 | 内容 | 研究上の意味 |
|---|---|---|
| 不完全情報 | 相手手牌・山・待ち・打点が見えない | ベイズ推定・レンジ推定が必要 |
| 多人数 | 4人の行動が相互干渉する | ポーカーの1対1理論をそのまま使えない |
| 逐次意思決定 | 1打で終わらず、複数巡のルートになる | MDP/POMDP、探索、枝刈りが必要 |
| 離散打点 | 1000、2000、3900、満貫、跳満など | 小さい確率差が段差で大きく効く |
| 順位効用 | 素点と最終価値が非線形 | ptEV、順位期待値、ラス回避が必要 |
| 人間ノイズ | ミス・癖・非標準手順がある | 残差パターン枠が必要 |
| 実戦制約 | 思考時間・再現性・見落としがある | 実行誤差とショートカット化が必要 |

最終的な研究対象は、単なる牌効率でも押し引きでもない。研究対象は、**麻雀判断を観測情報から行動選択へ変換する推論エンジン**である。

# 3. 麻雀判断の意思決定パイプライン

麻雀判断は、次のパイプラインで整理する。

```text
観測情報
  -> 仮説更新
  -> 結果確率更新
  -> 価値評価
  -> 差分比較
  -> インディファ判定
  -> 情報価値評価
  -> 探索制御
  -> 最終選択
```

| 段階 | 内容 | 麻雀例 |
|---|---|---|
| 観測情報 | 見えている事実 | 手牌、河、副露、ドラ、点棒、巡目、ラグ |
| 仮説更新 | 見えない状態を分布で推定 | 待ち候補、打点、テンパイ率、手牌価値 |
| 結果確率更新 | 事象確率を作る | 和了率、放銃率、被ツモ率、流局率 |
| 価値評価 | 結果を効用に変換 | 素点EV、順位EV、段位ptEV |
| 差分比較 | 選択肢間の価値差を見る | リーチとダマ、押しと降り、鳴きとスルー |
| インディファ判定 | 差が不確実性幅を超えるか | 明確優位、微差、判断不能 |
| 情報価値評価 | 追加で読む価値があるか | ブロッカー、山読み、打点読みを足すべきか |
| 探索制御 | 何手先まで見るか | 1手比較、2手ルート、ツモ分岐 |
| 最終選択 | 実戦可能な形に落とす | ショートカット、定石、例外条件 |

重要なのは、読みをいきなり打牌に接続しないことである。読みは、まず仮説分布を動かし、その後に結果確率・価値評価へ伝播する。

# 4. 基本数式: 選択肢価値、効用、差分EV

選択肢 $a$ の価値を簡略化すれば、以下のように置ける。

$$
Q(a)=P_{win}(a)V_{win}-P_{deal}(a)L_{deal}-P_{tsumo}(a)L_{tsumo}+P_{ryukyoku}(a)V_{ryukyoku}+P_{next}(a)V_{next}
$$

順位点・段位ptを使う場合は、順位確率で見る。

$$
Q(a)=\sum_{r=1}^{4}P(r\mid a)\cdot Point(r)
$$

選択肢AとBの差は、

$$
\Delta Q=Q(A)-Q(B)
$$

として見る。最終的には以下の統一形を目指す。

$$
Q(a)=\sum_{o\in O}P(o\mid a,H,E)\cdot U(o)
$$

| 記号 | 意味 | 麻雀例 |
|---|---|---|
| $a$ | 選択肢 | 押し、降り、リーチ、ダマ、鳴き、スルー |
| $E$ | 観測情報 | 河、副露、ドラ、点棒、巡目 |
| $H$ | 仮説分布 | 相手の手牌価値、待ち、打点、山残り |
| $O$ | 結果集合 | 和了、放銃、被ツモ、横移動、流局 |
| $U(o)$ | 結果効用 | 素点、順位点、段位pt、実力差込みEV |
| $Q(a)$ | 選択肢価値 | その行動ルートの期待効用 |

この式の利点は、読み・打点・危険度・順位点を同じ器に入れられることである。

# 5. インディファ帯と不確実性区間

インディファ帯とは、理論上は差があるが、推定誤差・モデル誤差・実行誤差を考えると優劣を断定できない範囲である。

$$
|\Delta Q|\leq \varepsilon
$$

ここで、

$$
\varepsilon=\varepsilon_{estimate}+\varepsilon_{model}+\varepsilon_{execution}+\varepsilon_{strategy}
$$

| 成分 | 内容 | 例 |
|---|---|---|
| 推定誤差 | 確率推定のブレ | 放銃率±3%、和了率±5% |
| モデル誤差 | 評価式のズレ | ptEV近似、NAGA近似、順位EV近似 |
| 実行誤差 | 人間の再現性 | 時間不足、見落とし、読み違い |
| 戦略誤差 | 方針差 | ラス回避、トップ取り、実力差込み方針 |

インディファ帯は「どちらでもよい」ではなく、研究上は最も価値のある領域である。明確優位の局面では細かい読みを足しても結論は変わりにくい。インディファ帯の周辺では、2%から3%の読み差や、1枚のブロッカー、役牌バック/暗刻比率の補正が結論を反転させ得る。

追加要素の作用は3種類に分ける。

| 作用 | 内容 | 例 |
|---|---|---|
| 中心をずらす | 平均DeltaQを動かす | 放銃率+3%で降り寄りになる |
| 幅を狭める | 不確実性を減らす | 待ち候補が絞れて判断が明確化 |
| 幅を広げる | 下側リスクやモデル不確実性を増やす | 高打点仮説が浮上する |

したがって、議論すべきは「押し寄りか降り寄りか」だけではない。平均値が動いたのか、不確実性が減ったのか、下側リスクが増えたのかを分ける必要がある。

# 6. 情報価値と追加検討の採用基準

細かい読みを採用するかは、情報価値で判断する。

$$
VOI=E[\text{判断改善}]-Cost
$$

また、局所証拠価値指数を次で置ける。

$$
D=\frac{|\Delta p\cdot \Delta V|}{\varepsilon}
$$

| $D$ | 扱い |
|---:|---|
| $D>2$ | 強く考慮すべき |
| $1<D\leq2$ | 結論反転候補 |
| $0.3<D\leq1$ | 補助要素 |
| $D\leq0.3$ | 原則無視、またはメモ程度 |

例として、放銃率が3%動き、放銃損失が8000点相当なら、

$$
0.03\times8000=240
$$

つまり240点相当である。インディファ帯が±200点ならかなり重要だが、±800点なら補助要素に落ちる。

情報価値が高い局面は以下である。

| 局面 | 理由 |
|---|---|
| 選択肢差が小さい | 追加情報で結論が反転する |
| ペイオフが大きい | 小確率差でもEV寄与が大きい |
| 仮説空間が狭い | ブロッカーやコンボ差が相対的に効く |
| 終端接近化している | 1牌の結果が即時価値に直結する |
| 読みの信頼性が高い | ノイズではなく情報として使える |

# 7. 階層推論チェーン（多段ロジック）

階層推論チェーンとは、観測情報が中間仮説を経由して結果確率・価値へ伝播する構造である。

```text
観測情報 -> 中間仮説 -> 結果確率 -> 価値評価 -> 選択肢差分
```

例1: 染め読み。

```text
色偏りの河
  -> 染め仮説上昇
  -> 打点分布上側シフト
  -> 放銃損失増加
  -> 危険牌押しEV低下
```

例2: 両面チー。

```text
両面チー
  -> 良形門前価値の放棄
  -> 速度・役確定・打点補助の必要性
  -> 手牌価値レンジ上側の相対増加
  -> テンパイ率・打点レンジ再評価
```

例3: 急所鳴きと役牌バック。

```text
急所鳴き
  -> 仕掛けレンジ拡大
  -> 役牌暗刻率だけでは説明しにくくなる
  -> 役牌バック率が相対上昇
  -> 対象役牌危険度上昇
```

このチェーンを10本以上作ることが、麻雀研究を「読み一覧」から「判断理論」に進める第一歩である。

# 8. 複合証拠統合（読みの重ね合わせ）

読みの重ね合わせという直感語は有効だが、理論的には以下の4処理に分解する。

| 処理 | 内容 | 例 |
|---|---|---|
| 証拠加算 | 独立に近い弱証拠を加算 | 外側牌、ワンチャンス、巡目 |
| 尤度統合 | 仮説確率を乗算的に更新 | 染め河 + 副露 + ドラ色 |
| ゲート発火 | 閾値超えで評価モード切替 | 染め濃厚、高打点濃厚、テンパイ濃厚 |
| 尾部リスク補正 | 低頻度高損失を厚く見る | 親満、跳満、ラス落ち直撃 |

危険なのは、同じ原因から出た証拠を独立として足すことである。例えば、染め河と染め副露は同一原因に由来しやすいため、単純加算では過剰確信になる。依存補正が必要である。

複合証拠統合の基本式は、概念的には以下である。

$$
P(H\mid E_1,E_2,...,E_n)\propto P(H)\prod_i L(E_i\mid H)\cdot C_{dep}
$$

$C_{dep}$ は依存補正であり、同じ情報源を二重カウントしないために使う。

# 9. 特殊条件レンジ（特殊性レンジ）

特殊条件レンジとは、平均的な全体レンジではなく、特定の観測条件で切り出される狭いレンジである。

代表例は以下である。

| 特殊条件 | 何が起きるか | 例 |
|---|---|---|
| 染め河 | 打点・待ち・放銃率が平均から外れる | 色関連牌の危険度上昇 |
| 直撃条件 | 特定相手への放銃価値が非線形化 | オーラスの着順条件 |
| 強い副露 | 手牌価値レンジが上側に寄る | 両面チー、急所鳴き |
| 強い信号の不在 | 高EV側レンジを削る | 押し返しなし、ドラ周辺不自然処理なし |
| 終盤テンパイ濃厚 | 危険度とテンパイ料が支配的 | 流局目前の押し引き |
| ラグ・思考時間複合 | 所持・迷い・鳴き候補が濃くなる | 複数証拠と整合する場合のみ |

平均分析木だけで麻雀を読むと、こうした特殊条件を拾えない。通常レンジから特殊条件レンジへ切り替えるレンジ切替ゲートが必要である。

```text
平均レンジ
  -> 特殊条件の証拠が閾値超え
  -> レンジ切替ゲート発火
  -> 特殊条件レンジで再評価
```

特殊条件レンジは、麻雀における「読みが本当に効く局面」を扱うための中核概念である。

# 10. 手牌価値レンジ理論

手牌価値レンジ理論では、手牌価値を最終EVの前段にある中間状態として扱う。

```text
観測情報
  -> 手牌価値レンジ
  -> 速度・打点・守備余力・成長性
  -> 和了率・放銃率・打点分布
  -> 選択肢EV
```

手牌価値は単なる現在打点ではない。以下の複合状態である。

| 構成要素 | 内容 |
|---|---|
| 速度 | シャンテン数、受け入れ、テンパイ率 |
| 打点 | 現在役、ドラ、赤、役牌、染め、リーチ価値 |
| 成長性 | 手替わり、ドラ引き、赤引き、2飜役、満貫化 |
| 守備余力 | 安牌、危険牌処理、押し返し耐性 |
| ルート幅 | 門前、鳴き、ダマ、リーチ、回し打ち |
| 順位価値 | 局・点棒・親番・供託・本場による効用変換 |

したがって、手牌価値レンジは以下のように書ける。

$$
HV = f(speed, value, growth, defense, flexibility, rank\_utility)
$$

手牌価値レンジは、自分の打牌判断にも、相手の手牌価値推定にも使える。

# 11. 手牌価値レンジを使った読み

手牌価値レンジは、相手読みの中間状態として非常に重要である。特に、強い手牌価値信号の有無がレンジを動かす。

## 11.1 手牌価値レンジ強め信号

| 信号 | 意味 |
|---|---|
| 両面チー | 良形門前価値を捨てて速度を取るため、手牌価値上側信号になりやすい |
| 急所鳴き | 速度・役確定・打点補助への強い意志 |
| ドラ周辺温存 | 打点上昇・高打点ルート維持 |
| 危険牌押し | テンパイまたは高価値手の可能性 |
| 安牌を持たないブクブク | 攻撃価値が守備価値を上回っている可能性 |
| 中EVから鳴かずに育てる | 高EV化を待っている可能性 |

代表例は両面チーである。両面チーは、通常なら価値のある門前良形を捨てる行動である。そのため、速度・役確定・打点補助・局面価値のどれかが一定以上ある可能性を示す。

ただし、両面チーを高打点確定と読むのは雑である。喰いタン、赤あり、親番、供託、局消化、トップ目の局消しなどでは安手速度型も残る。

## 11.2 強い信号の不在による下側シフト

強い手牌価値を持つ相手は、一定確率で強い信号を出す。したがって、その信号が観測されない場合、高EV側レンジを一部削れる。

```text
高EV手なら出やすい信号がない
  -> 高EV側レンジを少し削る
  -> 手牌価値レンジを中央・下側へ補正
```

ただし、観測機会がない場合、門前で静かに高EV化している場合、手出し情報が少ない場合は削りすぎ禁止である。

## 11.3 手牌価値レンジ読みの注意点

| 注意点 | 内容 |
|---|---|
| 単独証拠で決めない | 両面チーだけで高打点確定にしない |
| 局面価値を入れる | 親番・供託・点棒・順位で意味が変わる |
| 信号不在を過大評価しない | 観測機会がないだけのケースがある |
| 人間ノイズを入れる | 雑な鳴き、ミス、好みを残差パターン枠に入れる |

# 12. 手牌EVによる基本方針

手牌EVは、相手干渉・順位点・放銃損失を入れる前の中間評価として扱う。ここでは一人麻雀期待値を基準に、方針を大きく分ける。

| EV帯 | 目安 | 基本方針 | 核心 |
|---|---:|---|---|
| 高EV | 2500以上 | 基本ブクブク | 先制・高打点・和了率を取り切る |
| 中EV | 1000-2500 | 基本ブクブクだが、先切り・安牌持ち・門前育成が絡む | 最も難しく実力差が出る |
| 低EV | 1000未満 | 二極化、ポラー構成 | 高打点ルートか防御ルートへ寄せる |
| 低EV下側 | 800前後 | 高打点ルート > 安牌持ち > その他 | 上振れ種を逃さない |
| 超低EV | 600以下 | 守備・高打点種重視 | 低打点和了を無理に追いすぎない |

## 12.1 高EVの方針

高EVでは、基本的にブクブクが正義である。癖で先切りしすぎるのは普通に損になりやすい。

ただし、以下では安牌保持や先切りの重みが上がる。

| 条件 | 理由 |
|---|---|
| 巡目が進んだ | 相手テンパイ接近で危険牌化する |
| 機能が弱い牌 | 受け入れ・打点上昇に寄与しにくい |
| 形が決まった | 余剰牌の攻撃価値が落ちる |
| 外側牌が押されすぎる | 将来の放銃リスクが上がる |
| 聴牌近い相手に危険 | 先処理の価値が上がる |

## 12.2 中EVの方針

中EVは最も難しい。1000-2500程度の手は、速度・打点・守備・成長性・相手状況のバランスが崩れやすい。

特に重要なのは、鳴き判断である。

```text
中EVの手
  -> 鳴いて速度を取る
  -> ただし門前で育てると高EV化する可能性
  -> 赤・ドラ・2飜役・リーチ・満貫ルートを失う可能性
  -> 上級者同士でも差が出やすい
```

最近の方針として、半荘期待値では高EVがかなり正義であり、中EVの鳴き判断をやや門前寄りにする価値があるという仮説がある [E]。

## 12.3 低EVの方針

低EVでは、低打点・低速度の中途半端な和了を追うより、以下を重く見る。

```text
低EV
  -> 高打点ルート > 安牌持ち > その他
```

低EVから高EV化する代表例は、2飜役、満貫ルート、赤やドラ引きである。低EVでこれらの種を捨てるのは大きな損になり得る。

赤ありでは、低EV時の37と46の価値差が出やすい。46は中央で形・赤・ドラ絡みの上振れ余地を持ちやすく、37も端寄りよりは価値があるが、細部は牌姿依存である。

また、低EVほど数牌安牌2-8の考慮が重要になる。高EVなら攻撃価値で押し切れるが、低EVでは防御資源保持の相対価値が大きい。

# 13. ポーカー理論の麻雀への安全な流用

ポーカー理論から麻雀へ流用できる概念は多い。ただし、ゲーム構造が違うため、直輸入は危険である。

| ポーカー概念 | 麻雀への流用 | 注意点 |
|---|---|---|
| レンジ | 相手の手牌・待ち・打点候補 | 多人数・鳴き・山を考慮する |
| コンボ数 | 役・待ち・形の成立パターン | 候補空間全体で再正規化が必要 |
| ブロッカー | 見え牌による仮説確率補正 | 単純な3/4や2/3ではない |
| ポットオッズ | 押し必要条件 | 放銃・被ツモ・流局・順位点込み |
| インプライドオッズ | 将来和了・供託回収・親継続 | 半荘EVまで見る必要あり |
| リバースインプライド | 将来危険牌を掴む損 | 回し打ち・安全牌枯渇に対応 |
| MDF | 防御頻度の参考 | 麻雀は多人数・順位点で歪む |
| ノードロック | 相手タイプ固定で評価 | 人読み・副露レンジ補正に有効 |
| ICM | 順位点変換 | 段位ptEV、順位期待値に近い |
| CFR/後悔最小化 | 理論上の不完全情報ゲーム解法 | 麻雀全体へ直接適用は重い |

麻雀でまず使うべきは、GTOそのものではなく、レンジ、コンボ、ブロッカー、ノードロック、後悔最小化、終端接近化である。

# 14. Fold / Pot / Stack対応のズレ

ポーカーのFoldを麻雀のベタオリ、Potを和了点、Stackを持ち点と単純対応させると破綻する。

| ポーカー | 雑な麻雀対応 | 正しい麻雀対応 |
|---|---|---|
| Fold | ベタオリ | 防御方策への遷移。終端ではない |
| Pot | 和了点 | 点棒移転 + 供託 + 本場 + 順位効用 |
| Stack | 持ち点 | 支払い上限ではなく順位効用の状態変数 |
| Call | 押し | 将来危険牌込みの攻撃ルート |
| River | 終盤 | 終端接近化。山・流局・他家干渉は残る |

ベタオリはFoldではない。ベタオリ後も局は続き、放銃残存リスク、被ツモ損失、ノーテン罰符、安全牌枯渇が残る。

したがって、麻雀では「降りEV」をゼロにしてはいけない。降りは多くの場合、期待値マイナスだが押しよりマシな防御ルートである。

# 15. 終端接近化（麻雀版リバー化）

終端接近化とは、残り巡目が少なくなり、選択結果が和了・放銃・流局・順位変化に直結しやすくなる状態である。

| 条件 | 内容 |
|---|---|
| 残り巡目が少ない | 将来分岐が少ない |
| 相手テンパイ濃厚 | 放銃イベントが現実的 |
| 自分テンパイ/一向聴 | 和了・テンパイ料が現実的 |
| 回し余地がない | 押し/降り二択に近い |
| 打点・順位変化が大きい | 小確率差が大きく効く |

終端接近化で重要になるのは、単に有効牌差ではない。残りツモが少ないほど、純粋な和了機会はむしろ減る。重要になるのは、即時放銃・即時流局・テンパイ料・直撃条件・順位点変化である。

```text
終端接近化
  -> 将来価値が減る
  -> 終端価値が増える
  -> 局所証拠価値が上がる
  -> インディファ帯周辺の細部が重要になる
```

# 16. ブロッカー理論と候補空間再正規化

ブロッカーは、単純に「4枚中1枚見えたから3/4」「3枚中1枚抑えたから2/3」と処理してはいけない。

理由は、あるパターン空間の中で1枚を抑えると、対象コンボだけでなく、関連する別コンボも同時に削られるためである。

ブロッカー処理は、候補空間再正規化として扱う。

$$
P(H_i\mid E,Blocker)=\frac{w_i C_i(Blocker)}{\sum_j w_j C_j(Blocker)+R}
$$

| 記号 | 意味 |
|---|---|
| $H_i$ | 仮説。例: 両面待ち、愚形、役牌バック |
| $w_i$ | 事前重み・尤度重み |
| $C_i$ | 候補コンボ数 |
| $Blocker$ | 見え牌・自分所持牌・ドラ表示牌など |
| $R$ | 残差パターン枠 |

重要なのは、分子だけでなく分母全体が変わることである。候補空間が狭いほど、1枚のブロッカーは大きく効く。逆に候補空間が広いと、1枚の影響は分散する。

ブロッカーの効き方は、以下の条件で大きくなる。

| 条件 | 理由 |
|---|---|
| 候補レンジが狭い | 1コンボ削減の相対影響が大きい |
| ペイオフが大きい | 小確率差がEVに乗る |
| 終端接近化 | その場の選択結果に直結する |
| インディファ帯周辺 | 小差で結論が動く |
| 例外パターンが少ない | 残差枠に吸収されにくい |

# 17. ドラ枚数予想・打点レンジへのブロッカー

ブロッカーは待ちだけでなく、ドラ枚数予想・打点レンジにも使える。

| ブロッカー情報 | 打点レンジへの作用 |
|---|---|
| 自分がドラを複数持つ | 他家のドラ枚数上側を削る |
| ドラが場に多く見える | 高打点レンジを下側に補正 |
| 赤ドラが見えている | 赤含みの高打点ルートを削る |
| ドラ周辺牌が多く見える | ドラ受け・ドラ絡み形を削る |
| ドラ色が不自然に切られる | ドラ絡みの可能性を下げる場合がある |
| ドラ色の染め・副露 | 逆に高打点レンジを上側に補正 |

ただし、ドラブロッカーも単純ではない。ドラが見えているから高打点なし、ではなく、役・赤・染め・親・供託・本場・リーチ価値を同時に見る必要がある。

ドラ枚数予想は、手牌価値レンジ読みと接続する。

```text
ドラ枚数ブロッカー
  -> 打点レンジ補正
  -> 手牌価値レンジ補正
  -> 押し引きEV補正
```

# 18. コンボ数・候補空間・必要スペース補正

コンボ数近似は有効だが、麻雀では候補集合の広さ・必要スペース・全体の手牌構成制約を考慮しないと歪む。

| 概念 | 意味 |
|---|---|
| 候補集合 | その仮説に属する具体的パターンの集合 |
| 候補空間 | 複数候補集合を含む評価対象空間 |
| 必要スペース | その形を成立させるために必要な手牌スロット |
| コンボ密度 | 必要スペースあたりの成立パターンの濃さ |
| 候補空間再正規化 | ブロッカー後に全候補の比率を再計算すること |

リャンカンや4枚形などは、単純な面子候補数だけでなく、必要スペースの広さが異なる。たとえば、3マスで面子完成に寄与する形と、5マス必要なリャンカンでは、同じ候補数でも手牌全体への圧迫が違う。

仮説的には、以下のような補正が考えられる。

$$
AdjustedCombo \approx RawCombo \times \frac{3}{RequiredSpace}
$$

ただし、この補正が常に正しいわけではない。全体の4面子1雀頭構造、ブロック数、孤立牌、雀頭候補、鳴きルートの有無によりズレる。したがって、現段階ではヒューリスティックであり、牌譜・シミュレーションで検証すべきである。

# 19. 無筋危険度と例外パターン補正

両面無筋の危険度を概算する場合、単純には「残り無筋数」に対して1筋の危険度を見る。しかし、実戦では愚形、ミス、例外手順、非標準手順が混ざる。

そのため、以下のような粗補正が使える。

```text
1つの無筋危険度
  ≈ 1 / (残り両面本線の無筋数 + 例外パターン枠)
```

例外パターン枠は、愚形、変則手順、人間ミス、非効率手順などをまとめて吸収するための残差パターン枠である。

| 補正対象 | 内容 |
|---|---|
| 愚形待ち | 両面本線ではない待ち |
| 人間ミス | 非効率・読みづらい手順 |
| レアケース | 低頻度だがゼロではない形 |
| 変則手順 | 打点・安全度・意図で通常順から外れた手順 |

この補正は精密な統計ではない。しかし、人間の実戦判断では、ゼロ扱いよりは有用な場合がある。

# 20. ブロック読み・関連牌率・内牌外牌手出し

ブロック読みでは、相手の切り順から、孤立牌処理・関連牌処理・ブロック固定を推定する。

一般に、孤立牌価値は以下の順で高い。

```text
19字牌 < 28 < 3-7
```

そのため、通常の牌効率では外側から切られやすい。一方、内牌から外牌への手出しは、関連牌が始まった可能性を示す。

| 手出しパターン | 代表的な意味 |
|---|---|
| 内牌 -> 外牌 | 関連牌処理、面子固定、トイツ固定、両面固定 |
| 外牌 -> 内牌 | 通常の孤立牌処理に近い |
| 3-7残し | 牌効率・手替わり・ドラ受け |
| 28残し | 端寄り安全度・役牌絡み・形維持 |

ただし、内牌から外牌の切りが常に関連牌とは限らない。安全度比較、4枚1ブロックからの面子固定、愚形固定、単なる手順ノイズもある。

関連牌率は、次のように扱うべきである。

```text
関連牌率70%
  -> 残り30%の非関連牌分岐
  -> その30%の中にどの例外があるか
  -> 判断影響が大きい枝だけ評価
```

細かい分岐を全部展開すると実戦不能なので、情報価値の高い枝だけ残す。

# 21. 役牌バックと暗刻読み

役牌バックと役牌暗刻は、仕掛け読みの代表的な特殊条件レンジである。

| 観点 | 役牌バック | 役牌暗刻 |
|---|---|---|
| 必要枚数 | 基本2枚から成立 | 基本3枚必要 |
| 自分が1枚持つ影響 | バックは残り薄くなるがまだあり得る | 暗刻はかなり薄くなる |
| 急所鳴きとの関係 | レンジが広がるため相対的に残りやすい | 暗刻濃厚要素が弱まることがある |
| ブロック狭さ | 役牌バックでも成立しやすい | ブロック狭いほど暗刻もあり得る |

重要なのは、急所鳴きは「役牌バックに寄る」というより、暗刻に寄りそうな要素があっても、仕掛けレンジが広がるため暗刻だけに寄せにくくなる点である。

```text
急所鳴き
  -> 仕掛けレンジ拡大
  -> 暗刻限定読みの信頼度低下
  -> バック・他役・速度型が相対的に残る
```

ここでも、候補空間再正規化が必要である。

# 22. 押し引きEV・防御ルートEV・回し打ち

押し引きは、単純な「押しEV vs 降りEV」ではなく、攻撃ルートと防御ルートの比較である。

$$
Q_{push}=P_{win}V_{win}-P_{deal}L_{deal}-P_{tsumo}L_{tsumo}+P_{ryukyoku}V_{ryukyoku}+V_{future}
$$

降りも以下のようなルート価値を持つ。

$$
Q_{defense}=-P_{deal|def}L_{deal}-P_{tsumo|def}L_{tsumo}+P_{ryukyoku|def}V_{ryukyoku}+V_{next}
$$

防御ルートEVに含めるべきものは以下である。

| 要素 | 内容 |
|---|---|
| 放銃残存リスク | 安全牌不足、複数人危険、筋の不完全性 |
| 被ツモ損失 | 降りても他家がツモる |
| ノーテン罰符 | 終盤でテンパイを崩す価値 |
| 和了機会喪失 | 自分の和了・供託回収を失う |
| 次局条件 | 親流れ、親継続、供託、本場、順位 |
| 横移動依存 | 他家に局を終わらせてもらう価値 |

回し打ちは、攻撃と防御の中間ではなく、探索ルートである。

```text
回し打ち
  -> 現在危険牌を避ける
  -> 受け入れ・テンパイ復帰を残す
  -> 将来安全牌・危険牌の分岐を持つ
```

したがって、回し打ちは1手評価ではなく、2手から3手の探索空間で扱うべきである。

# 23. 期待値と分散・実力差込み半荘EV

麻雀では、局EVだけでなく、半荘EVと分散を同時に見る必要がある。

特に、実力差がある場合、単局ではマイナスに見える低分散選択が、半荘全体では有利になることがある [E]。

考え方は以下である。

```text
実力差がある
  -> 将来局で平均的に取り返せる
  -> 今局の下側リスクを抑える価値が上がる
  -> 分散抑制が半荘EVを改善する場合がある
```

| 状況 | 方針 |
|---|---|
| 自分が明確に強い | 無理な高分散勝負を避け、将来EVを活かす |
| 相手が強い | 期待値が少し低くても高分散ルートが必要な場合がある |
| ラス回避重視 | 下側リスク・CVaRを重く見る |
| トップ取り重視 | 上振れ分布・直撃条件を重く見る |

分散を扱う場合、平均EVだけでなく、下側リスクを評価する。

$$
Utility \approx EV - \lambda \cdot Risk
$$

ここで $\lambda$ はリスク回避度である。段位戦や実力差込み半荘EVでは、$\lambda$ が局面により変化する。

# 24. 巡目・残りツモ回数・ポアソン近似

残りツモ回数 $t$、1回あたり成功確率 $p$ のとき、少なくとも1回起こる確率は、

$$
P(X\geq1)=1-(1-p)^t
$$

$p$ が小さく、$\lambda=pt$ と置けるとき、ポアソン近似で、

$$
P(X\geq1)\approx1-e^{-\lambda}
$$

となる。

| $\lambda$ | $1-e^{-\lambda}$ |
|---:|---:|
| 0.1 | 9.5% |
| 0.2 | 18.1% |
| 0.3 | 25.9% |
| 0.5 | 39.3% |
| 0.7 | 50.3% |
| 1.0 | 63.2% |
| 1.5 | 77.7% |
| 2.0 | 86.5% |
| 3.0 | 95.0% |

麻雀での用途は以下である。

| 用途 | 例 |
|---|---|
| 有効牌を引く確率 | 残り数巡で有効牌を引けるか |
| 放銃イベント累積 | 毎巡数%の危険が何巡続くか |
| 他家ツモ率概算 | 残り巡目でツモられる確率 |
| レアケース混入 | 低頻度事象をゼロ扱いしない |

厳密には山の無作為抽出は独立試行ではないため、超幾何分布が正しい。ただし、実戦中の概算ではポアソン近似や指数近似が有用である。

# 25. 手替わり待ち・待ち取り選択

手替わりを含めた待ち取りでは、現在の待ち枚数だけでなく、将来の良化ルートを評価する。

例として、`xx 335678` のような形では、シャンポンに取るか、間4に取るかで手替わり種が変わる。

| 取り方 | 良化種 | 特徴 |
|---|---|---|
| シャンポン | 3周りとx周り | xが良い牌なら強い |
| 間4 | 2679など | 両面化・良形化が見込める |

暗刻や槓子がある場合も、待ち取りと手替わり評価は変わる。

| 要素 | 影響 |
|---|---|
| 暗刻 | 雀頭候補・シャンポン候補・安全度に影響 |
| 槓子 | 山残り・ドラ・安全度・符に影響 |
| 役あり/役なし | ダマ/リーチ/鳴きの価値に影響 |
| 打点上昇 | 手替わり待ちの価値を上げる |
| 巡目 | 残り手替わり機会を減らす |

手替わり待ちは、現在EVと将来EVの比較である。

$$
Q_{wait}=Q_{current}+P_{improve}\cdot \Delta V_{improve}-P_{loss}\cdot L_{delay}
$$

# 26. NAGA順位確率・ptEV近似・データ分析

NAGA段位ポイントアナライザや順位確率データは、麻雀判断理論を検証するための重要な外部評価軸である。

重点はptそのものよりも、順位確率である。

| 分析対象 | 目的 |
|---|---|
| 局ごとの順位確率 | 東1から南3までの点棒価値を近似する |
| 打点別順位上昇 | 1000、2000、3900、満貫の順位影響を見る |
| リー棒・本場 | 離散価値の補正を見る |
| 南2・南3 | 順位確率変動が大きい局面を重点分析 |
| オーラス | 別モデルにする。条件戦で通常式と異なる |

基本形は以下である。

$$
ptEV=\sum_{r=1}^{4}P(r)\cdot pt(r)
$$

研究上は、以下の近似式が欲しい。

```text
順位確率変化 = f(局, 点棒差, 親番, 供託, 本場, 和了点, 放銃相手)
```

局横断よりも、局ごとの近似が重要である。南2が多くてもよく、局ごとの順位確率変動を高精度に取る方が実用的である。

# 32. 確率概算ツールボックス

麻雀研究では、厳密計算よりも、まず概算で判断影響を掴むことが重要である。フェルミ推定・ポアソン近似・超幾何分布・線形近似・中心極限定理を、使い分ける必要がある。

## 32.1 基本分類

| 手法 | 使う場面 | 強み | 注意点 |
|---|---|---|---|
| フェルミ推定 | データがない未知量 | 仮の入力値を作れる | バイアスが大きい |
| 線形近似 | 小さい確率を少数回見る | 暗算しやすい | p*tが大きいと過大評価 |
| ポアソン近似 | 低確率事象の累積 | 少なくとも1回を概算しやすい | 独立性が弱いとズレる |
| 超幾何分布 | 山から牌を引く確率 | 厳密性が高い | 実戦暗算には重い |
| 正規近似/CLT | 試行回数が多い合計量 | 分布全体を近似できる | 麻雀の局面単位では条件が厳しい |

## 32.2 少なくとも1回起こる確率

独立近似なら、1回あたり確率 $p$、試行回数 $t$ のとき、

$$
P(X\geq1)=1-(1-p)^t
$$

$p$ が小さければ、$\lambda=pt$ として、

$$
P(X\geq1)\approx1-e^{-\lambda}
$$

さらに $pt$ が十分小さいなら、

$$
P(X\geq1)\approx pt
$$

となる。

| $pt$ | 線形近似 | ポアソン近似 | 差 |
|---:|---:|---:|---:|
| 0.1 | 10.0% | 9.5% | 小 |
| 0.3 | 30.0% | 25.9% | やや大 |
| 0.5 | 50.0% | 39.3% | 大 |
| 1.0 | 100.0% | 63.2% | 線形近似は破綻 |

実戦では、$pt$ が0.2以下なら線形近似でも大きく外れにくい。0.3を超えたらポアソン近似、さらに精密に必要なら超幾何分布に切り替える。

## 32.3 特定牌の平均所持枚数

特定の1種4枚について、見えていない山から $n$ 枚抽選されるとき、期待所持枚数は、

$$
E[X]=n\cdot\frac{4}{N}
$$

で概算できる。特定2種なら、

$$
E[X]=n\cdot\frac{8}{N}
$$

である。これは期待値の話であり、0枚・1枚・2枚以上の分布は超幾何で見る。

麻雀読みでは「平均0.6枚持っていそう」などの感覚を、こうした期待枚数で補正できる。特定牌1種と2種の比較は、ブロッカー・待ち候補・役牌所持読みの基礎になる。

## 32.4 確率概算を判断へ接続する

確率を出すだけでは足りない。必ずEV寄与に変換する。

$$
EV\ contribution=\Delta p\cdot\Delta V
$$

| 概算対象 | 判断への接続 |
|---|---|
| 有効牌を引く確率 | 和了率・手替わり価値 |
| 危険牌を通す確率 | 放銃率・防御ルートEV |
| 相手が特定牌を持つ確率 | ブロッカー・役牌バック/暗刻読み |
| レアケース発生率 | 残差パターン枠 |
| 他家ツモ確率 | 降りEV・横移動依存 |

確率計算は、意思決定の入力であり、最終結論ではない。

# 33. 複数安全牌・残り巡目・脇救済モデル

押し引き・ベタオリ判断では、安全牌を何枚持っているか、残り巡目が何巡か、脇が和了・放銃・横移動してくれる確率がどれくらいかが重要である。

## 33.1 2枚安全牌と3枚安全牌の価値

1枚の牌を毎巡切るだけなら、瞬間放銃率で比較しやすい。しかし、同じ種類の安全牌が2枚・3枚ある場合、複数巡を凌げるため、防御ルート全体の価値が変わる。

```text
1枚安全牌
  -> 1巡だけ安全
2枚安全牌
  -> 2巡分の安全資源
3枚安全牌
  -> 3巡分の安全資源 + 脇救済を待つ時間
```

残り巡目が多いほど、3枚安全牌で凌ぐ間に、脇が和了・放銃・横移動して局が終わる確率が蓄積される。そのため、瞬間放銃率だけではなく、**防御ルートの継続価値**として見るべきである。

## 33.2 脇救済率の扱い

脇救済率とは、自分が安全に凌いでいる間に、脇が局を終わらせてくれる確率である。

| 救済パターン | 内容 |
|---|---|
| 脇の和了 | 自分が放銃せずに局が終わる |
| 脇の放銃 | 自分以外への横移動で局が終わる |
| 流局 | テンパイ/ノーテン価値へ移る |
| 親流れ | 局・順位条件が変わる |

脇救済率を1人あたりではなく、脇全体で設定する場合、モデル上は以下のように扱う。

$$
P_{rescue}(t)=1-(1-r)^t
$$

ここで $r$ は1巡あたりの脇全体救済率、$t$ は凌げる巡数である。

## 33.3 防御資源としての安牌

安牌は単なる現在の安全度ではなく、防御資源である。

| 安牌状態 | 意味 |
|---|---|
| 完全安全牌1枚 | 1巡の安全 |
| 複数枚安全牌 | 複数巡の防御ルート確保 |
| 中筋・片筋 | 瞬間安全度はあるが完全ではない |
| 複数人共通安牌 | 価値が高い |
| 一人だけ通る牌 | 他家リーチ・副露に弱い |

防御ルートEVでは、安全牌枚数、共通安全度、残り巡目、脇救済率をまとめて評価する必要がある。

# 34. 思考時間読み・動作読み・ラグ読み

麻雀では、思考時間・動作・ラグも読み材料になる。ただし、これらはノイズが大きく、扱いを間違えると過剰読みになる。

## 34.1 ポーカーのテルとの比較

ポーカーのテルは、相手が情報を隠そうとする前提で分析される。一方、麻雀は打牌数が多く、同調圧力により早打ちが求められ、基本的にはタイムテルを完全には防げない。

| 観点 | ポーカー | 麻雀 |
|---|---|---|
| 行動回数 | 少ない | 多い |
| 時間圧 | 場合による | 常にある程度ある |
| テル防止 | 意識されやすい | 完全防止は難しい |
| 情報の粒度 | ベットサイズ・間 | 打牌選択・鳴き・ラグ・手出し |
| ノイズ | 演技・バランス | 端末差・通信・考え事・初心者ミス |

## 34.2 思考時間読みの使い方

思考時間読みは、単独証拠ではなく、複合証拠統合の補助証拠にする。

| 思考時間 | あり得る意味 | 注意点 |
|---|---|---|
| 長考後手出し | 形選択・危険牌処理・鳴き判断 | 単なる迷いもある |
| 即切り | 孤立牌、ツモ切り、方針固定 | 早打ち癖もある |
| 鳴きラグ | 所持・鳴き候補 | 偽ラグ・通信差あり |
| 終盤長考 | テンパイ/押し引き分岐 | 重要度が上がりやすい |

## 34.3 ラグ読みの扱い

ラグ読みは、仕様・環境・相手癖に依存する。信頼性が低い場合は、重みを下げる。

```text
ラグ
  -> 所持・鳴き候補の弱証拠
  -> 他証拠と一致すれば尤度上昇
  -> 単独では過信しない
```

ラグ・思考時間・動作は、残差パターン枠を必ず残すべき領域である。

# 35. 鳴き速度・手牌空間・候補空間の近似

鳴き判断は、門前と比較して非常に難しい。理由は、1回鳴くと、以後は上家チー・ポン・他家からの鳴きが開き、ルート空間が大きく変わるためである。

## 35.1 鳴きによる選択肢空間の変化

| 鳴き前 | 鳴き後 |
|---|---|
| 主にツモによる進行 | ツモ + 鳴きによる進行 |
| 門前打点・リーチ・裏ドラあり | リーチ価値喪失、役確定が必要 |
| 守備力比較的高い | 手牌が短くなり守備力低下 |
| 将来選択肢が広い | 速度は上がるがルートが固定化 |

鳴きは、速度を上げるだけでなく、手牌価値レンジを変える。中EVの鳴き判断が難しい理由は、鳴くことで中EVのまま速度を取るか、鳴かずに高EV化するかの比較になるからである。

## 35.2 近似モデルの考え方

鳴き速度は、以下のように分解できる。

$$
Q_{call}=SpeedGain+ValueChange-DefenseLoss-FutureOptionLoss
$$

| 成分 | 内容 |
|---|---|
| SpeedGain | テンパイ率・和了率の上昇 |
| ValueChange | 打点上昇/低下、役確定 |
| DefenseLoss | 安牌喪失、手牌短縮 |
| FutureOptionLoss | リーチ・裏ドラ・高EV化ルート喪失 |

赤ありでは、リーチに裏ドラがあり、満貫未満では平均打点を引き上げる。リーチ後の裏ドラ期待を、出アガリ打点のざっくり1.3倍のように扱う近似もあり得る [E]。

---

# 36. ポーカーMDF・分岐拒否・巡目戦略の流用

ポーカーでは、リバーに近づくほど将来カードがなくなり、エクイティが確定し、MDFやポットオッズの判断が明確になりやすい。

麻雀では、巡目が進むほど終端接近化するが、完全にポーカーのリバーにはならない。山・他家・流局・テンパイ料が残る。

## 36.1 分岐拒否の発想

ポーカーのフロップでオーバーフォールドしすぎると、将来分岐を自分から捨てる。麻雀でも、中盤で早く降りすぎると、将来の和了・テンパイ・回し打ちルートを捨てることがある。

```text
中盤の過剰降り
  -> 将来分岐を放棄
  -> 和了率・テンパイ率・横移動制御を失う
  -> 長期EVで損する場合がある
```

一方、終盤では将来分岐が少ないため、オーバーフォールドに近い選択が正当化される場合がある。

## 36.2 MDFの麻雀対応

MDFはそのまま麻雀に使えないが、防御頻度や押し返し頻度の参考にはなる。

| ポーカーMDF | 麻雀版の考え方 |
|---|---|
| 相手のブラフを利させすぎない防御頻度 | 相手リーチ・副露に対する押し返し頻度の基準 |
| ポットオッズで決まる | 放銃率・和了率・被ツモ・流局・順位点で歪む |
| 1対1が基本 | 麻雀は4人で横移動がある |

麻雀では、均衡補助・牽制補助は主役ではなく、スパイス程度に置くのが妥当である [E]。4人ゲームであり、細かいexploitの効果がポーカーほど直撃しにくいからである。

# 37. NAGA逆再生解析・牌譜大量投入の使い方

NAGA逆再生解析は、現在の捨て牌から、どのような手牌パターンがその捨て牌になり得るかを逆方向に抽出する考え方である。

## 37.1 使い道

| 使い道 | 内容 |
|---|---|
| 読み候補の洗い出し | 人間が見落とす枝を発見する |
| 消去理由の発見 | なぜこのパターンが薄いのかを考える |
| レアケース確認 | あり得るが低頻度の枝を残す |
| 人間との差分分析 | NAGAモデルと人間の読みのズレを見る |
| 教育用素材 | 読みの分岐を可視化する |

## 37.2 限界

NAGAのモデルは人間と完全一致しない。人間はミスをするし、NAGAモデル間にも選択差がある。そのため、NAGA逆再生は「真実」ではなく、候補空間の補助生成器として使うべきである。

```text
NAGA逆再生
  -> 候補空間の洗い出し
  -> 人間読みの漏れ確認
  -> ただし人間ノイズ・癖・ミスは別途残差枠へ
```

牌譜大量投入による整理では、単にAIに「読ませる」のではなく、読み要素、適用範囲、反例、寄与度にラベル付けする必要がある。

# 45. まとめ

本プロジェクトの核心は、麻雀判断を感覚論から、意思決定論・ベイズ推定・ポーカー理論・探索理論・順位効用・人間再現性を統合した判断モデルへ引き上げることである。

特に重要なのは以下である。

1. 読みは、打牌へ直接接続せず、仮説分布を動かすものとして扱う。  
2. インディファ帯は逃げではなく、細かい読みが最も効く研究領域である。  
3. ブロッカーは単純な枚数比ではなく、候補空間再正規化として扱う。  
4. 手牌価値レンジは、最終EV前の中間状態として、自分の判断にも相手読みにも使える。  
5. 中EVの鳴き判断・門前育成・高EV化は、実力差が出る重要領域である。  
6. 低EVでは、低打点和了よりも、高打点ルートと防御ルートを厚く見るポラー構成が重要である。  
7. ポーカー理論は有効だが、Fold/Pot/Stackを麻雀に直訳してはいけない。  
8. 麻雀AI/xAIでは、特徴量寄与度より、判断要素寄与度・選択肢比較寄与度・推論経路寄与度が重要である。  
9. 教育UIでは、DeltaQ、epsilon、特殊条件レンジ、下側リスク、残差パターン枠を可視化するべきである。  
10. 最終的には、麻雀判断を観測情報から行動選択へ変換する推論エンジンとして実装する。  

現時点では、多くの式・閾値・分類は仮説である。しかし、仮説を明示し、DeltaQ・epsilon・候補空間・特殊条件レンジ・情報価値として分解できた時点で、すでに「好み論」からはかなり脱出している。

次の段階は、具体局面10個でこの理論を実際に回し、NAGA・牌譜・シミュレーション・人間解説との差分を見て、重みと適用範囲を調整することである。
