## 1. 全体結論

麻雀を理論的に研究するには、単なる牌効率・押し引き・読みの個別論では足りない。

必要なのは、麻雀を以下の問題として扱うことである。

> 麻雀は、不完全情報・多人数・逐次意思決定・順位点効用・離散打点・終端リスク・人間ノイズを持つ意思決定問題である。

したがって、研究に必要な理論群は以下になる。

| 理論領域 | 麻雀での役割 |
|---|---|
| 意思決定論 | 選択肢比較、期待効用、インディファ帯、後悔最小化 |
| ベイズ推定 | 読み、仮説更新、見えない手牌・待ち・打点の推定 |
| 感度分析 | どの変数が結論を動かすかの特定 |
| 情報価値 | 追加で読む価値、長考する価値、データ取得する価値 |
| 探索理論 | 2〜3手先、分岐、枝刈り、探索空間制御 |
| 強化学習 / MDP / POMDP | 半荘単位・局面遷移・長期価値 |
| ポーカー理論 | レンジ、コンボ、ブロッカー、ノードロック、後悔最小化 |
| ロバスト意思決定 | 推定が不確かな状況で壊れにくい判断 |
| 人間モデル | ミス、非標準手順、思考時間、動作、ラグ、再現性 |

## 2. 用語体系: 直感語から理論語への変換

v6では、直感的に分かりやすい語句を残しつつ、PDF・AI仕様・可視化ツールに転用しやすい理論語を主語にする。
基本方針は「理論語（直感語）」で初出し、以後は理論語を中心に使う。

| 直感語 | 理論語 | 実装ラベル例 | 意味 |
|---|---|---|---|
| 多段ロジック | 階層推論チェーン | `inference_chain` | 観測 -> 仮説 -> 結果 -> 価値の段階的な推論経路 |
| 多段ロジックの重み付け | 推論経路の寄与度設計 | `chain_contribution` | 各推論経路が最終EV差に与える影響を設計すること |
| 読みの重ね合わせ | 複合証拠統合 | `evidence_fusion` | 複数の読み材料を、加算・尤度統合・ゲート・プルーニングで統合すること |
| 特殊性レンジ | 特殊条件レンジ | `conditional_subrange` | 平均レンジではなく、特定条件で切り出される狭いレンジ |
| 特殊性ゲート | レンジ切替ゲート | `range_switch_gate` | 通常レンジから特殊条件レンジへ評価モードを切り替える閾値ノード |
| パターン空間補正 | 候補空間再正規化 | `candidate_space_renormalization` | ブロッカーで候補集合全体を再計算する処理 |
| 残差ノイズ枠 | 残差パターン枠 | `residual_pattern_bucket` | 人間ミス・例外手順・愚形混入を吸収する補正枠 |
| レアケース1パターン加算 | 例外パターン補正 | `exception_pattern_adjustment` | 主要パターン以外をゼロ扱いしないための低頻度補正 |
| リバー化 | 終端接近化 | `terminality_index` | 残り巡目が少なく、選択結果が終端価値に直結しやすい状態 |
| 細部重要度指数 | 局所証拠価値指数 | `local_evidence_value` | 小さな読み差がインディファ帯に対してどれだけ大きいかを見る指標 |

この用語整理の目的は、単なる言い換えではない。
麻雀判断を、会話・研究ノート・AI仕様・UI表示・DB項目へ一貫して接続するためである。

## 3. 麻雀判断の基本パイプライン

麻雀判断は、以下の流れで整理する。

```text
観測情報
  -> 仮説更新
  -> 結果確率更新
  -> 価値評価
  -> 差分比較
  -> インディファ判定
  -> 追加検討・探索制御
  -> 最終選択
```

| 段階 | 内容 | 麻雀での例 |
|---|---|---|
| 観測情報 | 見えている事実 | 手牌、河、副露、ドラ、点棒、巡目、ラグ、思考時間 |
| 仮説更新 | 見えない状態の確率を変える | 相手の待ち、打点、速度、役候補、山残り |
| 結果確率更新 | 起こり得る結果の確率を変える | 和了率、放銃率、被ツモ率、流局率 |
| 価値評価 | 結果を点棒・順位点・ptEVに変換 | 満貫放銃、3900和了、テンパイ料、直撃条件 |
| 差分比較 | 選択肢間の価値差を見る | 押しEV - 降りEV、リーチEV - ダマEV |
| インディファ判定 | 差が不確実性より大きいか見る | 明確押し、明確降り、微差、判断不能 |
| 追加検討 | どの追加情報で結論が動くか見る | ブロッカー、役読み、山読み、ドラ枚数予想 |
| 探索制御 | 何手先まで読むか決める | 1手比較、2手ルート、ツモ分岐、枝刈り |

## 4. 基本数式

選択肢 $a$ の価値は、簡略化すれば以下で置ける。

$$
Q(a)=P_{\mathrm{win}}(a)V_{\mathrm{win}}
-P_{\mathrm{deal}}(a)L_{\mathrm{deal}}
-P_{\mathrm{tsumo}}(a)L_{\mathrm{tsumo}}
+P_{\mathrm{ryukyoku}}(a)V_{\mathrm{ryukyoku}}
+P_{\mathrm{next}}(a)V_{\mathrm{next}}
$$

順位点・段位ptを使う場合は、以下の形になる。

$$
Q(a)=\sum_{r=1}^{4}P(r\mid a)\,\mathrm{Point}(r)
$$

選択肢AとBの比較は差分で見る。

$$
\Delta Q=Q(A)-Q(B)
$$

最終的には以下の統一形を目指す。

$$
Q(a)=\sum_{o\in O}P(o\mid a,H,E)\,U(o)
$$

ここで、$E$ は観測情報、$H$ は仮説分布、$O$ は結果集合、$U(o)$ は効用である。

## 5. インディファ帯

インディファ帯とは、理論上は差があるが、推定誤差・モデル誤差・実行誤差・戦略方針差を考えると、実質的に優劣を断定できない範囲である。

$$
|\Delta Q|\leq \varepsilon
$$

ここで、

$$
\varepsilon
=
\varepsilon_{\mathrm{estimate}}
+\varepsilon_{\mathrm{model}}
+\varepsilon_{\mathrm{execution}}
+\varepsilon_{\mathrm{strategy}}
$$

| 誤差成分 | 内容 | 麻雀での例 |
|---|---|---|
| 推定誤差 | 確率推定のブレ | 放銃率±3%、和了率±5% |
| モデル誤差 | 評価式や近似のズレ | NAGA近似、ptEV近似、順位EV近似 |
| 実行誤差 | 人間の再現性 | 時間不足、見落とし、読み違い |
| 戦略誤差 | 方針差 | ラス回避寄り、トップ取り寄り、実力差考慮 |

インディファ帯は「どちらでもよい」ではない。  
むしろ、追加要素・読み・感度分析・情報価値が最も意味を持つ領域である。

| 状態 | 意味 | 研究上の扱い |
|---|---|---|
| 明確優位 | $\Delta Q$ が $\varepsilon$ を大きく超える | 定石化する |
| インディファ帯 | 差分が誤差に埋もれる | 追加特徴量・条件分岐を探す |
| 不確実性優位 | 平均差は小さいが下側リスクが大きい | CVaR・後悔基準で比較 |
| 情報不足 | $\varepsilon$ が大きすぎる | 追加観測・推定モデルを作る |
| 実行不能 | 理論上よいが人間が再現困難 | ショートカット化する |

## 6. 読みの有効性

読みの有効性は、単に「当たるかどうか」ではなく、意思決定にどれだけ寄与するかで評価する。

$$
\mathrm{Value(Read)}
=
\Delta p\cdot \Delta V\cdot \mathrm{Reliability}
-\mathrm{Cost}
$$

| 記号 | 意味 |
|---|---|
| $\Delta p$ | 読みによる確率変化 |
| $\Delta V$ | その事象の価値差 |
| Reliability | 読みの信頼性・再現性 |
| Cost | 思考負荷・誤認・過剰適用コスト |

例: 読みによって高打点放銃率が3%上がり、放銃損失が12000点相当なら、

$$
0.03\times 12000=360
$$

この読みのEV寄与は約360点。インディファ帯が±200点なら重要、±800点なら補助要素に落ちる。

## 7. 階層推論チェーン（多段ロジック）の整理

階層推論チェーン（多段ロジック）は、単純な点数加算ではなく、観測から価値までの因果チェーンとして整理する。

```text
観測情報
  -> 中間仮説
  -> 結果確率
  -> 価値分布
  -> 選択肢価値
```

例:

```text
急所鳴き
  -> 仕掛けレンジ拡大
  -> 役牌暗刻率の相対低下
  -> 役牌バック率の相対上昇
  -> 特定字牌危険度上昇
  -> 押しEV低下
  -> インディファ帯から降り側へ移動
```

| レイヤ | 変数 | 例 |
|---|---|---|
| 観測レイヤ | 見えている事実 | 2副露、ドラ色、6巡目手出し |
| 中間仮説レイヤ | 見えない状態 | 染め率、役牌バック率、テンパイ率 |
| 結果確率レイヤ | 事象確率 | 放銃率、和了率、被ツモ率 |
| 価値レイヤ | 損益 | 放銃点、順位変化、供託回収 |
| 判断レイヤ | 選択価値 | 押しEV、降りEV、回しEV |

## 8. 推論経路の寄与度設計（多段ロジックの重み付け）

重み付けには少なくとも4種類がある。

| 重み付け | 意味 | 例 |
|---|---|---|
| 尤度重み | 仮説確率を動かす | この副露なら染め率が上がる |
| 感度重み | 結論への影響度 | 放銃率1%の価値が大きい局面 |
| 信頼性重み | 証拠の再現性 | ラグ読みは仕様不安なら弱める |
| 依存補正 | 重複カウントを防ぐ | 染め河と染め副露を二重加算しない |

ベイズ的には以下の形で整理できる。

$$
P(H\mid E)\propto P(H)\,P(E\mid H)
$$

複数証拠が独立に近いなら尤度比を掛けられるが、同じ原因から出ている証拠は依存補正が必要になる。

## 9. 手牌価値レンジ理論: 中間状態としての手牌価値

これまでの整理では、観測情報から最終的な選択肢価値 $Q(a)$ へ進む流れを中心に置いていた。
ただし、麻雀ではその間に「手牌価値」という中間状態を置いた方がよい。

> 手牌価値レンジ = 現在の手牌が、将来どの程度の和了率・打点・守備余地・形の成長性を持つかを、点推定ではなくレンジまたは分布として表したもの。

これは最終EVそのものではない。
最終EVに変換される前段の中間状態である。

```text
観測情報
  -> 手牌価値レンジ
  -> 結果確率
  -> 点棒・順位効用
  -> 選択肢価値 Q(a)
```

### 9.1 なぜ中間状態が必要か

手牌をいきなりEVに変換すると、以下が混ざる。

| 混ざる要素 | 内容 |
|---|---|
| 現在速度 | シャンテン数、テンパイ率、受け入れ枚数 |
| 現在打点 | 役、ドラ、赤、符、親子 |
| 成長価値 | 手替わり、良形変化、打点上昇、裏ドラ期待 |
| 守備価値 | 安牌枚数、回し打ち余地、降りやすさ |
| 分岐価値 | 有力ルート数、鳴きルート、リーチ/ダマ選択 |
| 再現性 | 人間が実戦で扱えるか、ミスしやすいか |

したがって、手牌価値は単一スカラーではなく、少なくともベクトルまたはレンジとして扱うべきである。

$$
HV(s)
=
\left[
Speed(s),
Value(s),
Growth(s),
Defense(s),
Branch(s),
Reliability(s)
\right]
$$

ここで $HV(s)$ は状態 $s$ の手牌価値ベクトルである。

### 9.2 手牌価値レンジの基本形

打牌候補 $a$ 後の手牌価値レンジを以下で置く。

$$
R_{HV}(a)
=
\left[
HV_{low}(a),
HV_{mid}(a),
HV_{high}(a)
\right]
$$

| 成分 | 意味 | 麻雀での例 |
|---|---|---|
| $HV_{low}$ | 悪い側の手牌価値 | 良形変化せず、安手、危険牌を掴む |
| $HV_{mid}$ | 中央的な手牌価値 | 平均的なツモ・平均的な打点 |
| $HV_{high}$ | 良い側の手牌価値 | 良形化、ドラ引き、満貫化、先制テンパイ |

このレンジを使うと、「この打牌は今の受け入れは少ないが、上振れレンジが厚い」「この打牌は即効性は高いが、守備レンジが薄い」といった判断を分離できる。

### 9.3 手牌価値から選択肢価値への変換

最終的な選択肢価値は、手牌価値レンジを結果確率と効用へ通して計算する。

$$
Q(a)
=
\mathbb{E}_{h\sim R_{HV}(a)}
\left[
V(h, E, H)
\right]
$$

より実装寄りには、以下のように分ける。

```text
打牌候補 a
  -> 手牌価値レンジ R_HV(a)
  -> 和了率・放銃率・流局率
  -> 和了打点・放銃損失・順位点
  -> Q(a)
```

| 判断例 | 手牌価値レンジで見るべき点 |
|---|---|
| リーチかダマか | 現在打点、上振れ、出和了率、守備不能化 |
| 鳴くかスルーか | 速度上昇、打点低下、守備低下、以後の鳴きルート |
| 危険牌を押すか | 現在手牌価値が放銃損失に見合うか |
| 聴牌外しか | 現在価値を捨てて、上振れレンジを取りに行く価値があるか |
| 回し打ちかベタオリか | 手牌価値レンジがまだ残るか、守備ルートEVへ移るか |

### 9.4 インディファ帯との関係

手牌価値レンジは、インディファ帯を動かす。

| 作用 | 内容 | 例 |
|---|---|---|
| 中心を動かす | 平均手牌価値が上がる/下がる | 受け入れ増、打点増、良形化 |
| 幅を広げる | 上振れ/下振れが大きくなる | ドラ受け、危険牌含み、役依存 |
| 幅を狭める | 結果が読みやすくなる | 形固定、打点固定、流局目前 |
| 尾を厚くする | 低頻度高損失/高利益が増える | 親満放銃、裏ドラ、直撃条件 |

したがって、手牌価値レンジ理論は、インディファ帯の議論を補強する。
「今の手牌価値が高いから押し」ではなく、
「手牌価値レンジの下側・中央・上側を通しても押しがインディファ帯を抜けるか」を見る。

### 9.5 手牌価値レンジを使った読み: 強化信号・信号不在・両面チー

手牌価値レンジは、自分の打牌評価だけでなく、相手の手牌価値推定にも使える。
相手の行動は、相手の手牌価値レンジを上側・中央・下側へ動かす信号として読む。

> 手牌価値レンジ読み = 相手の行動・河・副露・押し引きから、相手手牌の速度・打点・成長性・守備余地の分布を推定する読み。

重要なのは、「強い信号が出たとき」だけでなく、「強い信号が出ていないとき」も情報になる点である。
ただし、これはその信号が本来観測されやすい局面に限る。

$$
P(HV_{high}\mid \lnot S)
\propto
P(\lnot S\mid HV_{high})P(HV_{high})
$$

ここで、$S$ は手牌価値が強いときに出やすい信号である。
もし $P(S\mid HV_{high})$ が高いなら、$S$ が観測されないことは、相手の手牌価値レンジを下側へ寄せる弱い根拠になる。

| 観測 | 手牌価値レンジへの作用 | 注意点 |
|---|---|---|
| 両面チー | 手牌価値レンジ強め、特に速度・役確定・打点補助がある側へ寄る | 喰いタン赤あり、親番、局消化目的では安手速度も残る |
| 強い副露後の継続押し | 高速・高打点・テンパイ濃厚側へ寄る | 押しすぎる人間ノイズを残差パターン枠に入れる |
| ドラ色・染め色の一貫性 | 打点レンジ上側へ寄る | 染めに見せた安手・役牌のみも残す |
| 役牌・ドラ周辺の不自然な温存 | 打点・構想レンジ上側へ寄る | 安牌保持・孤立牌温存との識別が必要 |
| 良形を鳴いて速度を取る | 門前価値放棄に見合う手牌価値がある可能性 | 低打点スピード型との分離が必要 |
| 強化信号が少ない | 強い手牌価値レンジが削られ、下側・中央寄りになる | 信号が観測可能な局面だった場合に限る |

#### 両面チーを代表例として見る

両面チーは、手牌価値レンジ強めの代表的な信号になりやすい。
理由は、良形面子候補を鳴いて門前価値・リーチ価値・守備余地を一部放棄するため、そのコストを補うだけの速度価値・役確定価値・打点価値が必要になりやすいからである。

```text
両面チー
  -> 良形門前価値の放棄
  -> 速度・役確定・打点補助の必要性
  -> 手牌価値レンジ上側の相対増加
  -> テンパイ率・打点レンジ・押し返しレンジの再評価
```

ただし、両面チーを常に高打点信号として扱うのは危険である。
特に赤あり・喰いタンあり・親番・供託多め・局消化目的・ラス回避速度戦では、両面チーが中EV以下の速度ルートとしても出る。
したがって両面チーは、単独証拠ではなく、以下の複合証拠統合で評価する。

| 補助証拠 | 両面チーの解釈 |
|---|---|
| ドラ・赤が絡む | 高EV・高打点寄りへ補正 |
| 役が明確 | 速度価値と和了率が上がる |
| 染め色・ドラ色と一致 | 特殊条件レンジへ切替候補 |
| 副露後に危険牌を押す | テンパイ率・手牌価値レンジ上側へ補正 |
| 安そうな鳴き・端牌処理が多い | 安手速度ルートを残す |
| 強い打点信号が追加で出ない | 高打点上側レンジを削り、中EV速度型へ寄せる |

#### 強い信号の不在は「弱い負の証拠」になる

手牌価値が高い相手は、一定確率で以下のような信号を出す。

| 強い手牌価値信号 | 例 |
|---|---|
| 速度信号 | 両面チー、急所鳴き、押し返し、テンパイ濃厚手順 |
| 打点信号 | ドラ周辺温存、染め、役牌・赤・ドラ絡み、親の強い押し |
| 成長信号 | 門前維持、鳴かずに育てる、中EVから高EVへの手替わり待ち |
| 防御放棄信号 | 安牌を持たずにブクブク、危険牌プッシュ |

これらが観測されない場合、強い手牌価値レンジは一定程度削られる。
ただし、門前で静かに高EVになっているケース、手出し情報が少ないケース、観測機会が少ないケースでは、削りすぎてはいけない。

実装上は以下のように扱う。

```text
手牌価値強化信号あり
  -> HV_high を増やす
  -> 打点・速度・テンパイ率の上側を厚くする

手牌価値強化信号なし
  -> HV_high を少し削る
  -> HV_low/HV_mid に再配分する
  -> ただし未観測・門前高EV・人間ノイズを残差パターン枠に残す
```

この読みは、平均レンジではなく特殊条件レンジと相性がよい。
例えば染め河では、打点レンジと放銃率レンジが通常より狭く推定できるため、手牌価値レンジの上側・下側が通常局面より明確に分かれやすい。

### 9.6 手牌EVによる基本方針

ここでいう手牌EVは、相手の干渉や順位点を完全に入れる前の、一人麻雀期待値に近い中間評価である。
最終判断は点棒状況・親子・局・相手速度・放銃損失・順位EVで上書きされるが、基本方針の初期値として非常に有用である。

#### 9.6.1 方針の全体像

| 手牌EV帯 | 目安 | 基本方針 | 主な狙い | 最大の罠 |
|---|---:|---|---|---|
| 高EV | 2500以上 | 基本ブクブク | 高和了率・高打点・先制価値を取り切る | 癖で先切りしすぎてEVを落とす |
| 中EV | 1000-2500 | 基本ブクブクだが、打点上昇しない28牌は先切り候補 | 高EV化・速度・守備のバランス | 方針が最も難しく、実力差が出る |
| 低EV | 1000未満 | 二極化（ポラー）で組む | 高打点ルートかベタオリルートへ寄せる | 低EVから高EV化するルートを逃す |
| 低EV下側 | 800前後 | 高打点ルート > 安牌持ち > その他 | 価値ある上振れを残しつつ守備余地確保 | 中途半端な速度ルートに寄せる |
| 超低EV | 600以下 | より守備・高打点種を重視 | 無理な低打点和了より、上振れと防御 | 何も残らない打牌を選ぶ |

この分類は厳密な絶対基準ではなく、判断の初期プロファイルである。
しかし、選択差が大きく出やすいスポットを見つけるには有効である。

#### 9.6.2 高EV: 基本ブクブク

高EV（一人麻雀期待値2500以上）は、基本的にブクブクに構える。
高EVの手牌は、和了率・打点・先制テンパイ価値が大きいため、安易な先切りや安牌保持で手牌価値を落とすのは普通に損になりやすい。

```text
高EV
  -> 高い和了・打点・先制価値
  -> ブクブクで最大値を取り切る
  -> ただし巡目進行・機能低下牌・形固定時は安牌保持の重み上昇
```

| 高EVでブクブク継続 | 高EVでも先切り・安牌保持を考える |
|---|---|
| 受け入れ差が大きい | 巡目が進んだ |
| 打点上昇・良形化が残る | 機能が弱い牌が残っている |
| 自分が先制しやすい | 形がほぼ決まった |
| 相手の速度がまだ低い | 聴牌近い相手にかなり危険になる外側牌 |
| 押し返し価値が高い | 外側牌が押されすぎて危険度が上がっている |

高EVで癖のように先切りしすぎるのは、基本的には損である。
ただし、外側牌が押されすぎる、あるいは聴牌近い相手に対して結構な危険牌になるなら、先切りは成立する。

#### 9.6.3 中EV: 最も難しい領域

中EV（1000-2500）は、基本はブクブクだが、打点上昇に貢献しない28牌まで先切り候補になる。
この帯は、相手状況、自分の実力、相手の実力、卓の速度、点棒状況で方針が大きく揺れる。

| 中EVの判断軸 | 内容 |
|---|---|
| 高EV化可能性 | 鳴かずに育てる、門前維持、手替わり待ち |
| 速度価値 | 鳴きで中EVを和了に寄せる価値 |
| 守備価値 | 28牌先切り、安牌保持、回し余地 |
| 相手速度 | 先制できるか、追いつかれるか |
| 実力差 | 自分が後続判断でEVを出せるなら門前寄りが強くなる |

中EVは選択のロジックの実力差が一番出やすく、上級者同士でも期待値差を出しやすいスポットである。
特に、中EVから高EVへの代表的なルートが「鳴かないで育てること」である。
鳴き判断において、鳴けば速度は上がるが、高EV化の上側レンジを失うことがある。

```text
中EV
  -> 鳴けば速度上昇
  -> ただし門前成長・リーチ・打点上昇レンジを失う
  -> 中EV -> 高EV の上側レンジを残すかが核心
```

最近の方針としては、高EVは半荘期待値上かなり正義であるため、中EVの鳴き判断をやや門前寄りにする発想は合理性がある。
ただし、これは相手速度・点棒状況・親番・供託・打点条件で簡単に反転する。

#### 9.6.4 低EV: 二極化（ポラー）で組む

低EVは、薄い低打点和了を追うより、以下の二極に寄せる。

1. 高打点ルート
2. ベタオリ・守備ルート

基本優先度は以下。

```text
高打点ルート > 安牌持ち > その他
```

低EVで最も損になりやすいのは、低EVから高EVへ化けるルートを逃すことである。
代表例は以下。

| 低EV -> 高EVの代表 | 内容 |
|---|---|
| 2飜役 | 役牌、タンヤオ、三色、一通、チャンタ系など |
| 満貫ルート | ドラ・赤・染め・役絡みで一気に打点上昇 |
| 赤・ドラ引き | 低EV手が一気に押し返し可能になる |
| 良形化 + 打点 | 速度と打点が同時に改善 |

低EVで中途半端に低打点速度へ寄せると、手牌価値の上側レンジも守備レンジも失いやすい。
したがって、低EVでは「高打点種を残す」「安牌を持つ」「どうにもならない中間牌を整理する」の優先度が上がる。

#### 9.6.5 赤あり低EVにおける37と46の差

赤ありでは、低EV時に37と46の価値差が無視できない。
理由は、5周辺の受け・赤5接続・タンヤオ/ドラ絡みへの接続性が変わるためである。

| 牌・形 | 低EV時の意味 |
|---|---|
| 37 | 5周辺・赤5接続・良形化に絡みやすく、上振れレンジを残しやすい |
| 46 | 5への接続は強いが、形や周辺牌次第で価値が変わる |
| 28 | 打点上昇に寄与しにくい場合、先切り・安全度確保の候補 |
| 数牌安牌2-8 | 低EVほど、単なる不要牌ではなく守備資産として重要になる |

低EVほど数牌安牌2-8の考慮は重要になる。
理由は、和了価値が薄いとき、将来の安全度・回し打ち余地・ベタオリ成功率の価値が相対的に上がるからである。

#### 9.6.6 手牌EV方針とインディファ帯

手牌EVによる基本方針は、インディファ帯の中心と幅を動かす。

| 手牌EV帯 | インディファ帯への作用 |
|---|---|
| 高EV | 押し側・ブクブク側へ中心が寄る。先切りの許容幅は狭くなる |
| 中EV | 幅が広くなる。相手状況・実力差・成長性で結論が動きやすい |
| 低EV | 高打点ルートと守備ルートへ二極化し、中途半端な選択の評価が下がる |

要するに、手牌EVは単なる手牌評価ではなく、判断方針の初期分布である。
その上に、相手速度、放銃率、打点、順位点、巡目、供託、本場、親子、実力差を重ねる。

## 10. ポアソン近似による確率概算

麻雀では、厳密な超幾何分布を毎回計算するより、低確率事象を粗く見積もる方が実戦的な場面がある。
このとき使えるのがポアソン近似である。

基本形は以下。

$$
P(X\geq 1)
\approx
1-e^{-\lambda}
$$

ここで、

$$
\lambda = p\times t
$$

である。$p$ は1回あたりの発生確率、$t$ は試行回数である。

### 10.1 麻雀での使いどころ

| 用途 | 例 | 近似の考え方 |
|---|---|---|
| 有効牌を少なくとも1回引く | 残りツモ $t$ 回で有効牌を引く | $p=k/U$, $\lambda=pt$ |
| 危険イベント発生 | 数巡以内に危険牌を掴む | 1巡あたり危険牌率を $p$ と置く |
| レアケース混入 | 愚形・ミス・例外手順が混じる | 低頻度事象を残差パターン枠で近似 |
| 読みの発火 | 複数弱証拠が1回以上出る | 弱証拠の発生率を束ねる |
| 鳴き機会 | 数巡以内に鳴ける牌が出る | 他家打牌機会を試行回数にする |

厳密な有効牌抽選は以下である。

$$
P(\mathrm{hit})
=
1-
\frac{\binom{U-k}{t}}{\binom{U}{t}}
$$

ただし、$k/U$ が小さく、$t$ が大きすぎないなら、

$$
P(\mathrm{hit})
\approx
1-e^{-tk/U}
$$

で概算できる。

### 10.2 使える条件

| 条件 | 判断 |
|---|---|
| $p$ が小さい | 使いやすい。目安として $p$ が数%程度ならかなり扱いやすい |
| $\lambda=pt$ が小さい | $P\approx \lambda$ の線形近似も使える |
| $\lambda\leq 1$ | 実戦概算として扱いやすい |
| $\lambda\leq 3$ | $1-e^{-\lambda}$ の表を使うなら粗い判断に使える |
| 山・見え牌の偏りが強い | 超幾何分布や候補空間再正規化を優先する |
| 事象が独立でない | 依存補正が必要。単純な $pt$ は危険 |

### 10.3 ポアソン近似早見表

| $\lambda$ | $1-e^{-\lambda}$ | $\lambda$ | $1-e^{-\lambda}$ | $\lambda$ | $1-e^{-\lambda}$ |
|---:|---:|---:|---:|---:|---:|
| 0.1 | 9.5% | 1.1 | 66.7% | 2.1 | 87.8% |
| 0.2 | 18.1% | 1.2 | 69.9% | 2.2 | 88.9% |
| 0.3 | 25.9% | 1.3 | 72.7% | 2.3 | 90.0% |
| 0.4 | 33.0% | 1.4 | 75.3% | 2.4 | 90.9% |
| 0.5 | 39.3% | 1.5 | 77.7% | 2.5 | 91.8% |
| 0.6 | 45.1% | 1.6 | 79.8% | 2.6 | 92.6% |
| 0.7 | 50.3% | 1.7 | 81.7% | 2.7 | 93.3% |
| 0.8 | 55.1% | 1.8 | 83.5% | 2.8 | 93.9% |
| 0.9 | 59.3% | 1.9 | 85.0% | 2.9 | 94.5% |
| 1.0 | 63.2% | 2.0 | 86.5% | 3.0 | 95.0% |

### 10.4 意思決定での使い方

ポアソン近似は、最終判断の厳密式ではなく、フェルミ推定寄りの入力生成に向いている。

```text
低頻度事象の概算
  -> 結果確率の仮置き
  -> 感度分析
  -> インディファ帯を抜けるか確認
```

例えば、ある危険イベントの1巡あたり発生率を3%、残り5巡と置くなら、

$$
\lambda=0.03\times 5=0.15
$$

$$
P(X\geq 1)\approx 1-e^{-0.15}\approx 13.9\%
$$

このように、ざっくりした確率を置き、
その確率が $\Delta p\times \Delta V$ として意思決定差に乗るかを見る。

## 11. ポーカー理論の麻雀への安全な流用

ポーカー理論は強力だが、麻雀にそのまま貼ると破綻する。流用すべきは単語ではなく構造である。

| ポーカー概念 | 麻雀への流用 | 注意点 |
|---|---|---|
| レンジ | 相手の手牌・待ち・打点候補 | 多人数・副露・山・流局が絡む |
| コンボ数 | 役・待ち・牌姿の成立パターン数 | 4面子1雀頭制約、選択済みバイアスがある |
| ブロッカー | 見え牌による候補削減 | 単純枚数比ではなく候補空間再正規化 |
| ポットオッズ | 押しに必要な和了率・通過率 | 放銃・被ツモ・流局・テンパイ料込み |
| リバー | 終盤・流局目前・終端局面 | 山・他家・横移動が残る |
| ICM | 順位点・段位ptEV変換 | 点棒価値が非線形になる |
| ノードロック | 相手タイプ別レンジ補正 | 人間のミス・癖・副露レンジに使える |

## 12. フォールド・ポット・スタック対応のズレ

麻雀への雑な流用で最も危険なのは、以下の一対一対応である。

| ポーカー | 雑な置換 | 正しい麻雀版 |
|---|---|---|
| Fold | ベタオリ | 防御ルート開始。終端ではない |
| Pot | 和了点 | 点棒移転 + 供託 + 本場 + 順位効用 |
| Stack | 持ち点 | 支払い上限ではなく順位効用の状態変数 |
| Call | 押し | 危険牌通過 + 将来分岐継続 |
| River decision | 終盤押し引き | 残りツモ・流局・テンパイ料込みの終端接近判断 |

ベタオリはフォールドではない。ポーカーのフォールドは基本的にその時点で追加損失が止まるが、麻雀のベタオリは以下を残す。

| ベタオリ後の損失 | 内容 |
|---|---|
| 放銃残存リスク | 安全牌不足、複数人危険、筋は完全安全ではない |
| 被ツモ損失 | 自分が降りても他家がツモる |
| ノーテン罰符 | 終盤でテンパイを崩すと罰符を払う |
| 和了機会損失 | 自分の和了・供託回収・局消化機会を失う |
| 次局条件悪化 | 親流れ、着順条件悪化、リー棒損失 |

したがって、麻雀の「降り」はゼロEVではなく、防御方策の期待値である。

## 13. 終端接近化（リバー化）・巡目・終端価値

共通ラベル:

> 終端接近化（リバー化） = 残りツモ回数が少なく、仮説空間が狭まり、選択結果が和了・放銃・流局・順位変化に直結しやすくなる状態。

残り未知牌を $U$、有効牌を $k$、残り自分ツモ回数を $t$ とすると、少なくとも1枚引く確率は以下で近似できる。

$$
P(\mathrm{hit})=
1-\frac{\binom{U-k}{t}}{\binom{U}{t}}
$$

粗くは以下。

$$
P(\mathrm{hit})\approx 1-\left(1-\frac{k}{U}\right)^t
$$

ただし、終盤ほど「細かい読みが常に大きくなる」わけではない。重要度は以下で見る。

$$
\mathrm{Importance}(x,t)
=
\frac{|\Delta p_x(t)\cdot \Delta V(t)|}{\varepsilon(t)}
$$

終盤で大きくなりやすいのは、未来の和了抽選価値というより、現在選択の終端リスク・終端リターンである。

## 14. ブロッカー理論: 候補空間再正規化として扱う

ポーカーのブロッカーは、相手レンジ内の特定コンボを削ることで価値を持つ。  
麻雀でも、見えている牌によって特定の待ち・役・形の成立パターン数が削れる。

ただし、麻雀のブロッカーを以下のように単純化してはいけない。

```text
4枚中1枚見えたから 3/4
3枚中1枚抑えたから 2/3
```

プロジェクト内で作成したブロッカーグラフの議論でも問題になった通り、あるパターン空間の中で1枚を抑えると、対象コンボだけでなく周辺形・複合形・競合形のコンボ数も同時に削られる。

基本形は以下。

$$
P(H_i\mid E)
=
\frac{\pi_i L(E\mid H_i) C_i(E)}
{\sum_j \pi_j L(E\mid H_j) C_j(E)}
$$

| 記号 | 意味 |
|---|---|
| $H_i$ | 仮説。例: 両面47待ち、役牌バック、暗刻、染め高打点 |
| $\pi_i$ | 事前確率 |
| $L(E\mid H_i)$ | 観測情報の尤度 |
| $C_i(E)$ | 見え牌・自分の保持牌・河・副露を反映した有効コンボ数 |

つまり、ある牌を1枚抑えた効果は、対象仮説のコンボ減少率だけでなく、他仮説のコンボ減少率との差で決まる。

| 問題 | 内容 | 例 |
|---|---|---|
| 周辺形も削れる | 対象形だけでなく隣接複合形も減る | 223、224、234、244など |
| 競合仮説も削れる | 本命以外の待ち・役も同時に減る | バック、暗刻、対子、複合ブロック |
| 母空間が変わる | 候補集合全体が縮む | 20->15 と 10->6 では相対確率が変わる |
| 選択済みバイアス | 相手は牌効率・安全度・打点で選んでいる | 終盤ほどランダム手牌から乖離 |
| 全体制約 | 4面子1雀頭制約がある | 1ブロック散布図だけでは不十分 |

共通ラベル:

> 候補空間再正規化（パターン空間補正） = 見え牌・保持牌によるコンボ削減を、単一パターンではなく、競合する候補集合全体の再正規化として扱う補正。

## 15. ドラ枚数予想におけるブロッカー

ドラ枚数予想にもブロッカー理論は使える。  
ただし、ここでも「ドラが1枚見えたから単純に残り枚数が減る」だけでは不十分である。

ドラ枚数予想で見るべきものは、少なくとも以下である。

| ブロッカー要素 | 削るレンジ | 具体例 |
|---|---|---|
| ドラそのものの見え | 相手のドラ所持枚数 | ドラが2枚見えなら相手のドラ2枚以上レンジがかなり減る |
| 自分のドラ保持 | 他家の高打点レンジ | 自分がドラを抱えるほど他家のドラ絡み打点は下がる |
| ドラ周辺牌の見え | ドラ受け・ドラ固定・ドラ周辺メンツ | ドラが5なら 345/456/567 系の実現性が変わる |
| 赤ドラ見え | 赤込み打点レンジ | 赤5m/赤5p/赤5sが見えると他家の赤打点期待が下がる |
| ドラ色の河 | 染め・混一・ドラ色寄せ | ドラ色を厚く残しているかで打点レンジが変わる |
| ドラ切りタイミング | 打点不要/手牌価値/安全度 | 早切り・中盤切り・リーチ宣言牌で意味が違う |
| 副露とドラ | 鳴き手の打点レンジ | ドラ色副露、ドラ周辺チー、役牌副露との複合 |

ドラ枚数仮説 $D_m$ を「相手がドラを $m$ 枚持つ」という仮説とすると、

$$
P(D_m\mid E)
\propto
P(D_m)\,L(E\mid D_m)\,C_D(m,E)
$$

ここで $C_D(m,E)$ は、見えドラ・赤ドラ・ドラ周辺牌・副露・河・自分の保持牌を反映したドラ関連コンボ数である。

重要なのは、ドラ枚数予想は単独ではなく、打点分布へ接続する点である。

```text
ドラ枚数予想
  -> 打点レンジ
  -> 放銃損失分布
  -> 押し引きEV
  -> インディファ帯の中心・幅・下側リスク
```

特に染め河・役牌副露・ドラ色寄せが重なると、ドラ枚数予想は特殊条件レンジ（特殊性レンジ）のゲートにもなる。

## 16. 特殊条件レンジ（特殊性レンジ）と平均分析木の限界

同プロジェクト内の「読みの特殊性理論」で重要だったのは、通常の平均レンジだけではなく、今の状況の特殊な部分を起点に仮説を立て、矛盾するものを消去し、残った仮説やレアケースの濃度を上げる考え方である。

共通ラベル:

> 特殊条件レンジ（特殊性レンジ） = 特定の観測情報の組み合わせにより、通常レンジより狭い範囲で放銃率・打点・待ち・速度を推定できる局面集合。

通常の分析木は以下のように平均的に分けがちである。

```text
副露あり
  -> 高打点
  -> 中打点
  -> 安手
```

しかし、染め河・ドラ色・切り順・副露タイミングが揃った場合は、平均副露レンジではなく特殊条件レンジ（特殊性レンジ）へゲートする方がよい。

```text
副露あり
  -> 染めレンジ切替ゲート（特殊性ゲート）
       -> 特殊性あり: 染め高打点レンジで評価
       -> 特殊性なし: 通常副露レンジで評価
```

| 特殊性 | 何が狭まるか | 判断への影響 |
|---|---|---|
| 染め河 + 副露 + ドラ色 | 打点レンジ、色待ち、字牌危険度 | 放銃損失分布が厚くなり、押しEVが急落 |
| 役牌未処理 + 急所鳴き | 役牌バック/暗刻/他役の比率 | 特定字牌の危険度が上がる |
| 終盤手出し + 安牌手出し | テンパイ率、待ち固定度 | 危険牌1枚の通過価値が大きくなる |
| ラグ + 見え牌 + 副露文脈 | 所持・鳴き候補・待ち候補 | 単体では弱い情報が重なると強くなる |
| オーラス直撃条件 | 放銃相手別の価値 | 同じ放銃率でもptEV影響が激変 |
| ドラ色副露 + ドラ周辺残し | 打点・色・ドラ枚数 | 高打点仮説が急に濃くなる |

「特殊性のないもの」は、平均分布や広めの通常レンジで推定する。  
「特殊性のあるもの」は、平均レンジの一部として薄く混ぜるより、別モードとして扱う方がよい局面がある。

## 17. 複合証拠統合（読みの重ね合わせ）とレンジ切替ゲート

複数の読みが重なったとき、単純な加算だけでは足りない場合がある。

| 処理 | 使う場面 | 例 |
|---|---|---|
| 加算 | 弱証拠が独立に近い | 外側牌、軽いワンチャンス |
| 乗算/尤度比 | 証拠が仮説確率を連続的に動かす | 河の色偏り + 副露 |
| ゲート | 閾値超えで評価モデルを切り替える | 染め濃厚、高打点濃厚 |
| プルーニング | ほぼ消せる仮説を落とす | 物理的に薄い待ち、役なし確定に近い形 |
| 下側リスク補正 | 悪い尾だけ厚くする | 親満放銃、ラス落ち直撃 |
| 残差パターン混入 | ミス・例外・人間手順を吸収 | 愚形混入、謎手順、例外的ドラ保持 |

複合証拠統合（読みの重ね合わせ）は以下のように扱う。

```text
弱証拠の足し算
  -> 閾値超え
  -> レンジ切替ゲート（特殊性ゲート）発火
  -> 通常レンジから特殊条件レンジ（特殊性レンジ）へ切替
  -> 放銃率・打点・インディファ帯を再評価
```

ここで重要なのは、レンジ切替ゲート（特殊性ゲート）が発火すると、単に中心EVが動くだけではない点である。

| 作用 | 内容 | 例 |
|---|---|---|
| 中心を動かす | 平均EVが押し/降りの片側へ寄る | 染め高打点濃厚で押しEVが下がる |
| 幅を狭める | 打点・待ち・役が限定される | 色待ち・字牌待ちに絞れる |
| 尾を厚くする | 低頻度でも高損失のケースが増える | 親満・跳満・直撃ラス落ち |
| モードを切替える | 通常レンジから特殊レンジに移る | 平均副露ではなく染め副露として扱う |

## 18. 残差パターン枠と例外パターン補正

麻雀では、主要パターンだけで危険度を構成すると、人間のミス・例外手順・レアケースを過小評価する。

そこで、精密に分解できない例外を「その他1パターン」「残差パターン」として加える方法がある。

共通ラベル:

> 残差パターン枠（残差ノイズ枠） = 主要な読み・牌理パターンでは説明しきれない、人間のミス・例外手順・レアケースを吸収するための補正枠。

抽象形は以下。

$$
\mathrm{Risk}(x)
\approx
\frac{C_{\mathrm{main}}(x)+C_{\mathrm{residual}}(x)}
{\sum_k C_{\mathrm{main}}(k)+C_{\mathrm{residual,total}}}
\cdot \mathrm{Payoff}(x)
$$

| 項目 | 意味 |
|---|---|
| $C_{\mathrm{main}}$ | 両面・役・染め・明確な牌理で説明できる主要パターン |
| $C_{\mathrm{residual}}$ | 愚形、ミス、例外手順、読み漏れを吸収する補正枠 |
| $C_{\mathrm{residual,total}}$ | 全体に混入させるノイズ総量 |
| Payoff | 放銃打点・順位点・直撃価値 |

この補正の利点は、レアケースをゼロ扱いしないことにある。  
ただし、濫用すると何でもありになり、本線読みの鋭さが消える。

## 19. 無筋危険度への応用

両面無筋の危険度を見る場合、1つの筋の危険度を「全部の無筋数」だけで割ると、愚形・ミス・例外手順が落ちる。

粗い補正として、以下のように考える。

$$
\mathrm{Risk}_{\mathrm{suji}}(x)
\approx
\frac{1+\lambda_{\mathrm{badshape}}+\lambda_{\mathrm{noise}}}
{N_{\mathrm{musuji}}+\Lambda_{\mathrm{residual}}}
\cdot
\mathrm{Payoff}(x)
$$

| 記号 | 意味 |
|---|---|
| $N_{\mathrm{musuji}}$ | 残り無筋本数 |
| $\lambda_{\mathrm{badshape}}$ | 愚形混入補正 |
| $\lambda_{\mathrm{noise}}$ | 人間ミス・例外手順補正 |
| $\Lambda_{\mathrm{residual}}$ | 全体の残差パターン総量 |

この式は厳密式ではなく、人間用の粗補正である。  
目的は、主要両面パターン以外をゼロにしないことと、残差パターンを明示的に管理することにある。

## 20. 情報価値: 追加証拠を採用すべきか

細かい読みを足すべきかは、情報価値で判断する。

$$
\mathrm{VOI}
=
\mathbb{E}[\mathrm{Gain}]
-
\mathrm{Cost}
$$

| 読みの種類 | 情報価値が高い局面 |
|---|---|
| ブロッカー確認 | 待ち候補が少ない終盤 |
| 役読み | 放銃打点差が大きい局面 |
| 山読み | 和了率とテンパイ料が拮抗する局面 |
| ラグ読み | 候補牌が限定され、仕様が信頼できる局面 |
| 思考時間読み | 他証拠と整合し、仮説空間を狭める局面 |
| ドラ枚数予想 | 打点レンジが結論を大きく動かす局面 |
| レンジ切替ゲート（特殊性ゲート）確認 | 通常レンジと特殊条件レンジ（特殊性レンジ）で判断が反転する局面 |

細かい読みは、明確押し・明確降りの局面ではなく、インディファ帯周辺で最も価値が高い。

## 24. まとめ

このメモの中心結論は以下である。

> 麻雀研究を本当に理論化するには、読み・押し引き・ポーカー流用・インディファ帯・階層推論チェーン・手牌価値レンジを別々に語るのではなく、観測情報を仮説分布へ変換し、その仮説分布を結果確率と効用へ変換し、選択肢間の差分と不確実性で比較する統一モデルが必要である。

v6で特に強調した補正は以下。

- ブロッカーは単純な枚数比ではなく、パターン空間全体の再正規化で扱う。
- ドラ枚数予想もブロッカーによって打点レンジを削れる。
- 染め河・直撃条件・複合証拠統合（読みの重ね合わせ）などは、通常レンジではなく特殊条件レンジ（特殊性レンジ）へゲートする。
- 人間のミス・レアケース・愚形混入は、残差パターン枠（残差ノイズ枠）として明示的に扱う。
- インディファ帯は、中心・幅・尾・レンジ切替ゲート（特殊性ゲート）の発火で動く。
