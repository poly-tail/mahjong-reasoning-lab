# ポーカー判断から麻雀判断への転用整理

作成日: 2026-05-05

本資料は、会話で整理した内容を再構成したものです。主眼は、**判断要素の全列挙ではなく、上位の判断方針・推定レジーム・補正原理の整理**にあります。

---

## 1. 要約

### 結論

- 麻雀では、ポーカーのような単純な「均衡戦略 vs エクスプロイト戦略」の2分法だけでは整理が足りない。
- ただし、麻雀でもポーカーでも、上位整理では **戦略レジーム / 評価原理 / 目的関数** を分けると見通しがよくなる。
- 麻雀における本件の中心は、**危険度をどう推定するか** であり、主要には次の2レジームがある。
  - **ベースレート/コンボ近似レジーム**
  - **仮説分岐/推論木レジーム**
- さらにその外側に、
  - **均衡補助/牽制補助レイヤ**
  がある。
- 実戦上は、
  - 推論木がベースレートから大きく乖離したとき
  - 推論木の結論が ID 帯（インディファレント帯）近傍にあるとき
  は、**筋本数・コンボ数近似側へ収縮補正する** という整理が有力である。

---

## 2. 用語の階層整理

### 2.1 戦略レジーム

ここでいう戦略レジームとは、**どういう情報処理様式で危険度や判断を組み立てるか** を指す。

### 2.2 評価原理

評価原理とは、**何を根拠にアクション価値を比較するか** である。単なる判断要素列挙ではなく、価値比較軸に近い。

例:
- 危険度
- 受け入れ
- 良形変化
- 打点価値
- 速度価値
- 巡目価値
- 安全牌保持価値
- 他家速度
- 放銃時損失

### 2.3 目的関数

目的関数とは、**何を最大化するか** である。

麻雀では概ね以下の3層に分けると扱いやすい。

| レイヤ | 内容 | 主な役割 |
|---|---|---|
| 1 | 局収支EV | 通常局面の基礎判断 |
| 2 | 半荘順位EV | 南場・点況・残り局数で比重上昇 |
| 3 | 分散制御補正 | 実力差、段位pt、制度適応 |

補足として、実戦感覚では「東場は局収支寄り、南場は半荘収支寄り」という把握は概ね有効だが、理論的には **残り局数 × 点差 × 親子 × ルール** でウェイトが変わると捉えた方が精密である。

---

## 3. 麻雀における主要レジーム

## 3.1 ベースレート/コンボ近似レジーム

### 定義

- 牌理上・場況上、削りやすい部分だけを限定的に削る。
- その後は、残存する待ち・形・構造的頻度・筋本数・コンボ数に精度を委ねる。
- 深い仮説分岐は明示的には持ち込みすぎない。

### 本質

これは単なる「筋本数読み」ではなく、
**限定的な前処理の後、構造的な組合せ量に危険度推定を委ねるベースレート推定** である。

### 特徴

| 項目 | 内容 |
|---|---|
| 主目的 | 危険度推定 |
| 主手法 | 限定的削減 + 残存組合せ量 |
| 読みの使い方 | 前処理として軽く使う |
| 相手傾向の扱い | 基本弱い、限定的 |
| 分岐の明示化 | 弱い |
| 長所 | 頑健、読み漏れ耐性がある |
| 短所 | 粗い、局所精度は低め |

---

## 3.2 仮説分岐/推論木レジーム

### 定義

- 相手手牌や待ちの仮説を木構造またはネットワーク状に分岐させる。
- 相手傾向、牌理理解度、選択傾向、河の整合性などで枝重みを変える。
- 分岐ごとの濃度・発生確率・パターンを整理し、最終的に危険度を推定する。
- 副次的に打点推測や待ち質推測も扱いうる。

### 本質

推論自体が目的ではなく、**推論は危険度推定器の内部機構** である。

### 特徴

| 項目 | 内容 |
|---|---|
| 主目的 | 危険度推定 |
| 主手法 | 仮説分岐 + 枝重み更新 |
| 読みの使い方 | 中核エンジンとして使う |
| 相手傾向の扱い | 強く扱う |
| 分岐の明示化 | 強い |
| 長所 | 高分解能、高精度を狙える |
| 短所 | 読み漏れ・枝不足・レアケース見落としで不安定化しやすい |

---

## 3.3 均衡補助/牽制補助レイヤ

### 定義

- オーバーフォールド防止
- 読まれ対策
- 押し頻度維持
- 牽制効果の維持

など、危険度推定の外側から**意思決定閾値を微修正する補助レイヤ**である。

### 位置づけ

麻雀では、これは主たる危険度推定器ではなく、
**スパイス・補助・閾値補正** の性質が強い。

### 理由

- 4人戦で局所的エクスプロイトの利得が薄まりやすい。
- 個別読みや細かい頻度調整のインパクトが、ポーカーほど一撃で局面を支配しにくい。
- 行動自由度が低く、GTO的周波数設計をそのまま持ち込みにくい。

### ただし例外

以下では比重が多少上がる。

- 相手が明確にこちらへ適応してくる長期反復卓
- リーチ判断や副露判断で牽制効果が比較的効く場面
- 実力差が大きく、頻度の偏りが exploit されやすい環境

---

## 4. レジーム間の関係

### 4.1 上位構造

| 上位区分 | 下位 |
|---|---|
| 危険度推定系 | ベースレート/コンボ近似、仮説分岐/推論木 |
| 閾値補正系 | 均衡補助/牽制補助 |

### 4.2 実戦での基本構図

- **基準アンカー**: ベースレート/コンボ近似
- **高分解能補正器**: 仮説分岐/推論木
- **微修正レイヤ**: 均衡補助/牽制補助

この整理は、

- 推論木は高分解能だが不安定
- コンボ近似は低分解能だが頑健
- 均衡補助は補助的

という関係を表している。

---

## 5. なぜ推論木をそのまま信じないのか

麻雀では、

- パターン数が多すぎる
- 人間は全分岐を洗い出し切れない
- 主要線だけを使った読みになりやすい
- レアケースや例外形の拾い漏れが起こる
- 4人戦なので局所読みの価値が薄まる局面がある

ため、**推論木は高精度を狙えるが、同時に高分散推定器になりやすい**。

そのため、ベースレート/コンボ近似をアンカーとして持ち、
必要に応じて推論木の結論を収縮補正するという発想が重要になる。

---

## 6. 収縮補正の考え方

## 6.1 乖離補正

### 定義

**推論木の評価結果とコンボ近似の評価結果が大きくズレたとき、後者へ寄せる補正**。

### 背景

推論木が極端な結論を出していても、それが
- 読み漏れ
- 過剰物語化
- 枝不足
- 重み付け誤差

に起因する可能性があるため、粗いが安定した推定器へ回帰する。

### 要点

> 推論木がベースレートから大きく乖離した場合、推論木の読み漏れリスクを考慮してコンボ近似側への補正を検討する。

---

## 6.2 境界補正

### 定義

**推論木の出力が ID 帯（インディファレント帯）近傍にあるとき、筋本数・コンボ数近似をより重視する補正**。

### 本質

ここで重要なのは、ID帯が単なる「あいまい地帯」ではなく、
**微小誤差で結論反転が起こりやすい高感度領域** だという点である。

### 境界不安定性

共通ラベルとして、以下を置ける。

- **境界不安定性**: 判断境界に近いとき、細かい推論誤差や枝漏れで結論が反転しやすい性質。

### 要点

> 推論木側が ID 帯に近いなら、推論木特有の読み誤差・枝漏れ・重み付け誤差の影響を考え、より頑健な筋本数・コンボ数近似へ寄せてよい。

---

## 6.3 乖離補正と境界補正の違い

| 補正条件 | 何が起きているか | 推奨対応 |
|---|---|---|
| 推論木とコンボ近似が大きく乖離 | 2つの評価器が対立 | コンボ近似側に収縮補正 |
| 推論木が ID 帯近傍 | 小さな誤差で結論反転しやすい | コンボ近似をアンカー化 |
| 推論木が明確な押し/降りを示す | 境界から離れている | 推論木の重みを上げてよい |

---

## 6.4 低分散推定器への収縮

この整理は、統計的には次の発想に近い。

- 推論木 = 鋭いが高分散の推定器
- コンボ近似 = 粗いが低分散の推定器
- ID帯近傍や大乖離時には、低分散推定器へ収縮させる

つまり、

> **ID帯だから何となく保守的にする** のではなく、
> **高感度領域では推論木の分散が効きすぎるため、低分散推定器へシュリンクする**

という整理になる。

---

## 7. 推論木を優先してよい条件

以下では、単純にコンボ近似へ戻し切らず、推論木の比重を上げてよい。

- 明確な手出し情報がある
- 仕掛けパターンが極端
- 相手傾向情報の確度が高い
- 河の整合性がかなり強い
- 推論の根拠が多く、例外排除の確かさが高い
- 推論木の結論が ID 帯から十分離れている

したがって、原則は

> **ID帯近傍ならコンボ寄せ。ただし推論根拠が非常に強いときは例外**

である。

---

## 8. 実戦用の二段ルール

### ルール1: 乖離補正

- 推論木とコンボ近似が大きくズレたら、推論木を疑う。

### ルール2: 境界補正

- 推論木が ID 帯近傍なら、コンボ近似を優先しやすくする。

この二段ルールにより、

- 推論木の鋭さは活かす
- ただし読み漏れや高感度領域の不安定性は抑える

という運用が可能になる。

---

## 9. 麻雀における細読みと exploit の位置づけ

### 9.1 細かい読み要素の影響度

麻雀では、細部の読みが無価値なのではない。むしろ、
**多くの場面で単一の細読みが局面価値全体をひっくり返すほどの破壊力を持ちにくい** という意味で、影響度が小さめになりやすい。

これは、

- 単一要素支配ではなく、微差累積ゲームである

という理解に近い。

### 9.2 exploit の効き方

ポーカーに比べると、麻雀は

- 相手が3人いる
- 1人への exploit が他2人で薄まりやすい
- 行動自由度が低い
- 局所的搾取の実現機会が少ない

ため、局所 exploit の期待リターンは相対的に小さくなりやすい。

この意味で、均衡補助/牽制補助レイヤは通常、主戦略というより補助スパイスに留まる。

---

## 10. 研究用の最終整理

### 10.1 3分類

| 区分 | 呼称 | 要旨 |
|---|---|---|
| 1 | ベースレート/コンボ近似レジーム | 限定的削減後、残りは組合せ量で見る |
| 2 | 仮説分岐/推論木レジーム | パターン分岐と傾向重みで危険度を出す |
| 3 | 均衡補助/牽制補助レイヤ | 閾値補正・過剰防御防止・読まれ対策 |

### 10.2 上位構造

| 上位区分 | 下位 |
|---|---|
| 危険度推定系 | 1, 2 |
| 閾値補正系 | 3 |

### 10.3 補正式の要点

| 状況 | 採用方針 |
|---|---|
| 推論木がコンボ近似と大きく乖離 | コンボ近似側へ収縮 |
| 推論木が ID 帯近傍 | コンボ近似寄りにする |
| 推論木が ID 帯から遠く、根拠も強い | 推論木寄りにする |

---

## 11. まとめ

本整理の核心は以下である。

1. 麻雀では、危険度推定の主戦略は **ベースレート/コンボ近似** と **仮説分岐/推論木** の2系統で整理できる。
2. どちらも主目的は危険度推定だが、違うのは **推定アーキテクチャ** である。
3. 均衡補助/牽制補助は、通常は主戦略ではなく **閾値微修正レイヤ** と見るのが妥当である。
4. 推論木は高分解能だが不安定なので、
   - ベースレートと大きく乖離したとき
   - ID帯近傍という高感度領域にあるとき
   には、コンボ近似側への収縮補正が有効である。
5. この整理により、麻雀判断を「読みの鋭さ」と「推定の頑健性」の両面から扱える。
