# 牌理の読み・比較痕跡・Codex実装前提 - 本チャット要約

**作成日**: 2026-05-05  
**対象**: このチャットで扱った「牌理の読み」「比較痕跡」「有効範囲と重み付け」「Codexに渡す前提」の整理  
**本資料の構成理由**: 概念整理×実装指示型の議論だったため、**牌理の基準値 -> 比較痕跡 -> 読みの有効範囲 -> Codex前提** の順で再構成する。

## Layer 1 | 事実・論理モード

## 0. 結論

このチャットで固まった中心命題は次のとおり。

- 読みの主語は**牌種**ではなく、**価値比較の痕跡**である。
- 各打牌は、少なくとも  
  **ShapeValue（形価値） / RoleValue（役価値） / BlockValue（5ブロック・頭価値） / SafetyValue（守備価値） / LocalComboValue（局所コンボ価値）**  
  の比較で負けた牌として扱う。
- したがって、読みとは  
  **「なぜその牌がそのタイミングで比較負けしたか」**  
  を逆算する作業である。
- 基本的には **2・8 は役牌より上になりやすい**。ただし、**役牌と1・9は意外と逆転しやすい**。また、局面によっては**役牌が2・8を上回る**。
- ターツ落とし、内外切り、逆切り、強ターツ外し、外残し傾向などは、すべて**比較痕跡**として再解釈する必要がある。
- それらの読みは「ある / ない」で扱わず、**有効範囲の広さ**と**重み**、そして**例外率**を分けて管理する。
- Codex には「格言集を実装せよ」と渡すのではなく、**既存ロジックとの接続先・禁止事項・出力形式**まで固定した仕様プロンプトを渡す必要がある。

## 1. このチャットでユーザー側から入った重要修正

### 1.1 前回案への主要なダメ出し

このチャットでは、初期案に対して次の修正が入った。

| 指摘 | 内容 | 修正後の方向 |
|---|---|---|
| 巡目依存が強すぎる | 巡目ラベル中心だと浅い。牌理・牌効率から逆算しろ | 巡目は主因ではなく係数に落とす |
| 牌効率理解が甘い | 何が強く、何が弱く、なぜ後まで残るのかの比較が抜けている | 価値比較を主軸に置く |
| 役牌・19・28の比較が雑 | 基本は28有利が多いが、役牌と19は逆転しやすい。役牌が28より上の局面もある | 基準値と逆転条件を分離する |
| コンボ数の視点が弱い | 単牌価値ではなく、局所形に埋め込まれたときのコンボ数や二度受けを見る必要がある | LocalComboValue を追加する |
| 読みの強さ管理がない | どの読みがどれくらい広く使え、どれくらい重く扱うかが曖昧 | 有効範囲・重み・例外率を分ける |
| Codex への指示が曖昧 | 「いい感じに整理して」だと格言集化・雑実装になる | 前提・禁止事項・接続先つきプロンプトにする |

### 1.2 ユーザーが強調したコア視点

このチャットで繰り返し強調されたのは以下。

1. **人は比較して切っている**  
   捨て牌は不要牌ではなく、比較に負けた牌である。

2. **牌理読みは意図の逆算である**  
   何を残し、何を捨てたかから、役・頭・受け入れ・守備のどれを見たかを読む。

3. **麻雀は基本的に読み騙しの期待値が高くない局面が多い**  
   したがって、比較痕跡は読む価値がある。

4. **中間状態・手牌価値レンジの概念が有効**  
   打点・聴牌度・待ち / 受け入れの3軸でレンジ更新すると整理しやすい。

## 2. 牌理読みの基本公理

### 2.1 比較痕跡モデル

このチャットで採用された再整理は次。

```text
TotalValue(tile)
= ShapeValue
+ RoleValue
+ BlockValue
+ SafetyValue
+ LocalComboValue
```

ここでの意味は以下。

| 軸 | 内容 | 典型例 |
|---|---|---|
| ShapeValue | 純形価値。くっつき、良形化、受け入れ | 3-7 > 2-8 > 1-9 の基本順位 |
| RoleValue | 役価値。役牌、タンヤオ、チャンタ、混一色、七対子など | 役牌保留、456処理、ヤオチュー連打 |
| BlockValue | 5ブロック / 頭都合 / ターツ過多 / 両面固定 | ターツ落とし、トイツ落とし、強ターツ外し |
| SafetyValue | 将来安牌、守備、押し引き | 内切り、字牌保留、外牌残し |
| LocalComboValue | 局所形に埋めたときの価値、二度受け、受け入れ被り | 1345の1、112345、12245、13から4引き |

### 2.2 重要な原理

| 原理 | 要旨 |
|---|---|
| 打牌は比較負け | 捨て牌は「その局面で総合価値が最も低い牌」のログ |
| 5ブロック整理 | ターツ落とし / トイツ落としは、外した形以上の形が残る痕跡 |
| 巡目は係数 | 巡目は重み調整には効くが、読みの主因ではない |
| 役種断定は避ける | 観測はまず役レンジ更新・手牌価値レンジ更新に使う |
| 強い偏りは alert 止まり | いきなりテンパイ率へ直変換しない |

## 3. 牌の基本価値と逆転条件

### 3.1 基本順位

| 牌 | 基本傾向 | コメント |
|---|---|---|
| 3-7 | 最も強い | 純形価値・複合変化に優れる |
| 2・8 | 強い | 基本は役牌より有利になりやすい |
| 1・9 | 中位 | 端牌だが、123 / 789、一通、チャンタでは仕事がある |
| 役牌 | 文脈依存で強くなる | 重なり、鳴き、1翻、頭、安牌価値で逆転しやすい |
| オタ風 | 弱いが守備価値はある | 形価値は低い |

### 3.2 このチャットで合意した重要補足

- **役牌と1・9は意外と逆転しやすい。**
- **役牌が2・8を上回る手牌もある。**
- ただし、**基本傾向としては2・8有利が多い**。
- したがって、  
  **「役牌が後から出た」= 常に役牌手** ではなく、  
  **「役牌には途中まで何らかの補助価値が乗っていた」** と読む。

### 3.3 価値逆転を起こす要因

| 逆転要因 | 何が起きるか | 読みへの意味 |
|---|---|---|
| 役牌重なり期待 | 役牌が対子化すると一気に価値上昇 | 19先切り役牌保留を説明しやすい |
| 鳴き起点 | 面前価値より仕掛け価値が上がる | 28先切り役牌保留の説明になる |
| 頭候補不足 | 対子・役牌対子の価値が上がる | トイツ落とし、役牌保留に影響 |
| 平和困難 | 平和が付きにくい手は役牌価値が相対上昇 | 役牌が28を超える一因 |
| 受け入れ被り | 一見強い牌でも局所で機能が薄い | LocalComboValue で補正が必要 |
| 守備補助 | 字牌・外牌を将来安牌として持つ | 内切りや字牌保留の説明になる |

## 4. 比較痕跡から読むセオリー

### 4.1 代表例

| 比較痕跡 | まず読むこと | 更新先 |
|---|---|---|
| 19を先に切って役牌を残す | 役牌に重なり / 鳴き / 頭候補価値が乗っていた | RoleValue, BlockValue |
| 28を先に切って役牌を残す | 役牌補助価値がかなり強く、純形価値を逆転した | RoleValue↑↑, BlockValue↑ |
| 強ターツ外し | 残存ブロックの質が高い、または打点補助がある | hand_value_score |
| ターツ落とし | 6ブロック整理、同等以上の形残り | readiness / hand_value |
| トイツ落とし | 頭候補が他にある、または役価値調整 | BlockValue |
| 内→外 | 形固定 or 守備寄せ | push_alert / shape_fixed_alert |
| 外→内 | 柔軟性維持、変化保留 | flowing_shape_alert |
| 逆切り（中→端） | 順子進行に逆行、トイツ/コーツ保持や変則形 | nonstandard_shape_alert |
| 456早切り | チャンタ / 純チャン / 混一色などヤオチュー活用寄り | yaku_axis_alert |
| ヤオチュー連打 | タンヤオ軸がかなり濃い | yaku_axis_alert |
| 外残し傾向 | 非標準面子手・役寄り・形固定寄りのアラート | comparison_trace_alert |

### 4.2 ユーザーが強く押した局所コンボ系読み

このチャットで重要だったのが、単牌評価では説明できない**局所コンボ系の逆算**。

代表例:
- `3 -> 別色1`
- `112345`
- `12245`
- `13 から 4 引きで 34 化`
- 二度受けを含む局所再編

ここでの主張は次のように整理された。

| 観測 | ユーザー側の重要主張 | 再整理 |
|---|---|---|
| 3を先に切って別色1を残す | 1周辺に局所コンボがあることが多く、3-6は相対的に当たりにくくなることがある | `LocalComboValue(1側)` を疑い、`3-6` を盲信しない |
| 112345 / 12245 | 2ブロック前提や二度受けを含むので、単牌の強弱だけでは読めない | `BlockValue + LocalComboValue` の複合で扱う |
| 外残し傾向 | チャンタ / 二飜役 / 七対子 / 面子手以外の率が結構上がる | 役種断定ではなく `nonstandard_shape_alert` に留める |

**重要**: これらは筋が良いが、標準格言としての普遍性はまだ弱い。  
したがって、**主根拠ではなく alert / 局所補正** として持つのが妥当、という方向で整理された。

## 6. 中間状態・手牌価値レンジとの接続

ユーザー側の既存概念である**中間状態**・**手牌価値レンジ**は、このチャットでかなり有効だと再確認された。

### 6.1 手牌価値レンジの3軸

| 軸 | 内容 |
|---|---|
| 打点 | 何翻・何打点の方向か |
| 聴牌度 | 進行度・速度・形の詰まり具合 |
| 待ち / 受け入れ | 良形化・最終待ち質・受け入れ枚数 |

### 6.2 比較痕跡をレンジ更新に変える例

| 比較痕跡 | 打点軸 | 聴牌度軸 | 待ち / 受け入れ軸 | 解釈 |
|---|---:|---:|---:|---|
| 28先切り役牌残し | ↑ | → or ↓ | ↓ | 速度より役・鳴き価値 |
| 強ターツ外し | ↑ or → | → | ↑ | 残形の質が高い |
| ターツ落とし完了牌の手出し | → | ↓寄り | ↓寄り | まだ整理中 |
| 鳴き後の完了牌 | → | ↑ | → | 1手進行が明確 |
| 内→外 | → | → | 柔軟性↓ | 形固定 or 守備 |
| 456早切り | ↑ | → or ↓ | ↓ | ヤオチュー系役寄せ |
| 外残し傾向 | ↑ | → or ↓ | ↓ | 非標準手アラート |

**要点**: 役寄り・形固定寄り・外残し傾向のようなものは、**即テンパイ率化しない**。  
まず `alert` または `hand_value_score` 側に置く。

## Layer 2 | 圧迫レビュー・拡張説教モード

### 何がダメか

このチャットで繰り返し修正された最大の問題は、**読みを「牌の意味」で処理しようとすること**だった。  
それでは浅い。  
麻雀の打牌は、牌そのものの意味ではなく、**比較の結果**である。

もう一つダメなのは、**形価値と総合価値を混同すること**。  
2・8が基本は強い。だが、役牌には重なり・鳴き・一翻・頭・守備という補助価値がある。  
ここを一本の尺度で見ようとすると理論が崩れる。

### なぜダメか

この混同を放置すると、

- 役牌後切り = 役牌手
- 456先切り = チャンタ
- 外残し = 七対子

のような雑な決め打ちになる。  
実際には、観測と結論の間に **価値比較** と **有効範囲評価** を挟む必要がある。

### どう直すか

今後はすべての読みを次の文法で扱うべき。

1. **基準値**  
   その牌 / 形の基本価値は何か

2. **逆転条件**  
   何がその基準値をひっくり返したか

3. **比較痕跡**  
   何を先に切り、何を後に残したか

4. **レンジ更新**  
   打点 / 聴牌度 / 待ち / 受け入れのどこを動かすか

5. **有効範囲と重み**  
   どれくらい広く効き、どれくらい重く使ってよいか

6. **接続先**  
   danger / readiness / hand_value / alert のどこへ入れるか

この6段構造まで落ちて、ようやく「読みの仕様」と呼べる。
