# ターツ理論

この章で判断できるようになること: リャンメン、カンチャン、ペンチャン、複合ターツを、受け入れ枚数だけでなく変化、役、鳴きやすさ、場況で比較できるようにします。

## リャンメン、カンチャン、ペンチャン

### 要約

ターツの基本序列はリャンメン、カンチャン、ペンチャンです。リャンメンは2種類8枚、カンチャンとペンチャンは基本1種類4枚ですが、実戦では変化や役で補正します。

### 使う局面

5ブロック以上あり、どのターツを残すか、どのターツを落とすかを決める局面で使います。

### 判断基準

- 受け入れの種類と枚数。
- リャンメン変化の有無。
- タンヤオ、ピンフ、三色などの役に絡むか。
- 鳴きやすいか。
- 待ちとして残ったときに出やすいか。
- ドラ周辺か、安全度が高いか。

### 判断手順

1. 各ターツの基本受け入れを確認する。
2. カンチャンとペンチャンはリャンメン変化を探す。
3. 役、ドラ、鳴きやすさを補正する。
4. 1シャンテンなら受け入れを強く見る。
5. 2シャンテン以前なら変化も含めて比較する。

### 例

`23m12p46s789s55z7m` では、`23m` はリャンメン、`12p` はペンチャン、`46s` はカンチャンです。平面では `12p` を落としやすいですが、三色やドラが絡むなら評価を補正します。

### 例外・補正

ペンチャンでも役やドラに絡めば残す価値があります。カンチャンでも端寄りの待ちは場況次第でアガリやすいことがあります。終盤は牌効率より安全度が優先されることがあります。

### よくあるミス

- リャンメンを常に固定し、複合形の変化を消す。
- ペンチャンを無条件に切り、役やドラを見落とす。
- カンチャンとペンチャンのリャンメン変化を比較しない。

### 一言ルール

基本はリャンメン優先、ただし変化・役・鳴きで補正する。

## カンチャン同士の比較

### 要約

カンチャン同士は、受け入れ枚数が同じでもリャンメン変化、役、場況、危険度で差が出ます。単純に内側が強いと決めず、残した後の発展を見ます。

### 使う局面

カンチャンが複数あり、どちらかを落とすメンツオーバーの局面で使います。

### 判断基準

- リャンメン変化の数。
- 周辺牌を引いたときの強さ。
- タンヤオや三色に絡むか。
- ドラ周辺か。
- スジや場況から待ちとして残ったときに有利か。
- 切る牌の危険度。

### 判断手順

1. カンチャンごとに埋まり牌を確認する。
2. 周辺牌を引いたときのリャンメン化を確認する。
3. 役とドラを補正する。
4. 切り出し順を安全度で決める。

### 例

`24m46p78s234s55z9m` では、`24m` と `46p` がカンチャンです。`46p` は中張牌の変化が多い一方、ドラや場況次第では `24m` を残す価値もあります。

### 例外・補正

タンヤオが不要で、端寄りの待ちが場に安い場合は、端寄りカンチャンの実戦価値が上がることがあります。ドラまたぎは受けとして強い一方、切り出し時の危険度が高くなります。

### よくあるミス

- どちらも4枚受けだから同じと考える。
- 待ちになったときの出やすさを見ない。
- 危険牌の先切りと変化残しの比較をしない。

### 一言ルール

カンチャン比較は、埋まり牌だけでなく周辺変化まで見る。

## ペンチャン同士の比較

### 要約

ペンチャン同士は平面では差が小さく見えますが、役、ドラ、場況、鳴きやすさで差が出ます。実戦情報でどちらを残すかを決めます。

### 使う局面

ペンチャンが複数あり、片方を払う局面で使います。

### 判断基準

- 役に絡むか。
- ドラ周辺か。
- 場に安い色か。
- チーしやすいか。
- 下家に鳴かせたくない牌を切ることになるか。
- ペンチャンを外す順番の安全度。

### 判断手順

1. ペンチャンの受け入れを確認する。
2. 役とドラへの関与を見る。
3. 河や副露から出やすさを補正する。
4. 外す場合は危険な内側から切るか、安全な外側から切るかを決める。

### 例

`12m89p345s567s44z3m` は `12m` と `89p` の比較です。タンヤオを見ないなら平面差は小さいですが、ドラが `7p` なら `89p` の価値は下がる場合があります。

### 例外・補正

鳴き手でチーできるペンチャンは、メンゼン手より価値が上がります。終盤の安全度や下家への鳴かせやすさも重要です。

### よくあるミス

- ペンチャンは全部同じと見る。
- ドラ周辺の競争率を無視する。
- ペンチャン落としの2巡リスクを考えない。

### 一言ルール

ペンチャン同士は、場況と役で差をつける。

## 複合ターツ

### 要約

複合ターツは、単純な2枚ターツにフォロー牌や別の役割が重なった形です。メンゼンでは発展性、鳴き手では鳴きやすさを重視します。

### 使う局面

弱ターツにフォロー牌がついているとき、または5ブロックがそろっていてフォローを外すか迷うときに使います。

### 判断基準

- フォロー牌を残すとリャンメン変化があるか。
- 鳴きやすさが上がるか。
- タンヤオ、ピンフ、三色、イーペーコーに絡むか。
- 5ブロックが既にそろっているか。
- 外す牌が安全か危険か。

### 判断手順

1. 複合形を単純ターツとフォロー牌に分解する。
2. フォローを外した後の受け入れを確認する。
3. フォローを残した場合の2次変化を確認する。
4. メンゼン手か鳴き手かで評価軸を切り替える。

### 例

`245m456p78s33z68p9s` の `245m` は、`24m` カンチャンに `5m` のフォローがついた形です。序盤なら残して良形変化を見ますが、1シャンテンなら最大受けとの比較になります。

### 例外・補正

鳴き手では、良形変化よりチーやポンのしやすさが重要になることがあります。高打点が確定している場合は、悪形でも速度を優先します。

### よくあるミス

- フォロー牌をすべて余剰牌として切る。
- 複合ターツを残しすぎて6ブロックのまま進める。
- メンゼン手と鳴き手の評価軸を混ぜる。

### 一言ルール

複合ターツは、発展性と鳴きやすさを分けて評価する。

## 弱ターツ3枚構成理論

### 要約

弱いカンチャンやペンチャンは、フォロー牌を含めた3枚構成にすると強くなります。強いリャンメンは2枚で十分なことが多く、フォローをつける優先度は低くなります。

### 使う局面

2シャンテン以前で、弱ターツを残すか落とすか、フォロー牌を持つかを判断するときに使います。

### 判断基準

- 弱ターツにリャンメン変化があるか。
- フォロー牌が内側か外側か。
- ほかに強い5ブロックがあるか。
- 1シャンテンピークと衝突していないか。
- フォロー牌が役やドラに絡むか。

### 判断手順

1. 弱ターツを探す。
2. 周辺牌を含めた3枚形にできるか確認する。
3. 強いリャンメンにフォローをつけすぎていないか確認する。
4. 1シャンテンに近づいたらフォローを外す候補にする。

### 例

`124m456p78s33z67p9s` の `124m` は、`12m` ペンチャンに `4m` の変化を見られる形です。序盤は残す価値がありますが、テンパイ受け入れを邪魔するなら整理します。

### 例外・補正

ドラ周辺や役に絡むフォロー牌は価値が上がります。終盤や他家の攻撃がある局面では、変化より安全度を優先します。

### よくあるミス

- 弱ターツを2枚だけで残し、変化を消す。
- 強いリャンメンに不要なフォローを残す。
- 1シャンテンでも序盤と同じように変化を追う。

### 一言ルール

弱いターツにはフォローをつけ、強いターツは身軽にする。

## ターツ落とし

### 要約

ターツ落としは、どのターツを落とすかだけでなく、どの順番で落とすかが重要です。2巡使う行為なので、形改善、打点上昇、安全度のリターンが必要です。

### 使う局面

6ブロック以上あるとき、弱ターツが余っているとき、またはくだらない1シャンテンを避けて形を作り直すときに使います。

### 判断基準

- 落とすターツは本当に一番弱いか。
- 2巡使う価値があるか。
- ターツを落とすことで打点や良形率が上がるか。
- 危険牌を先に処理できるか。
- 巡目が早いか遅いか。
- 他家からの攻撃があるか。

### 判断手順

1. ブロック数を確認する。
2. 弱いターツを候補にする。
3. 落とした後に残る5ブロックの強さを見る。
4. 切り出し順を安全度と変化で決める。
5. 1巡目に切ったあと、状況が変われば2枚目を止めるか再検討する。

### 例

`23m45p12s89s456p77z` はターツが多い形です。`12s` と `89s` のどちらを落とすかは、役、ドラ、場況、切り出し牌の安全度で決めます。

### 例外・補正

高打点や良形変化が大きいなら、2シャンテン戻しも選択肢になります。ただし現代麻雀では速度の価値が高いため、リターンの小さいターツ落としは避けます。

### よくあるミス

- ターツ落としに2巡かかることを忘れる。
- 1枚目を切ったあと、状況変化を見ずに2枚目を自動で切る。
- 形改善のために速度を落としすぎる。

### 一言ルール

ターツ落としは2巡投資。見返りを確認してから払う。

## 判断チェックリスト

- 基本序列を確認したか。
- 弱ターツにフォローがあるか。
- 受け入れ枚数と受け入れ後の形を分けて見たか。
- メンゼン手と鳴き手で評価を切り替えたか。
- ターツ落としの2巡リスクを確認したか。
