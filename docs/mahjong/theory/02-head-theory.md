# ヘッド理論

この章で判断できるようになること: ヘッド候補の数から手牌の安定性を読み、トイツを残すか、崩すか、固定するかを判断できるようにします。

## 2ヘッド理論

### 要約

2ヘッドは、2つのトイツをヘッド候補として持つ安定形です。片方がアンコになっても、もう片方をヘッドにできるため、完全1シャンテンを作りやすくなります。

### 使う局面

トイツが2組あり、ほかに4メンツ候補が見える局面で使います。1シャンテン付近で、ヘッド候補を残すか、片方を崩すかを比較します。

### 判断基準

- 2ヘッドを維持すると完全1シャンテンになるか。
- 片方を崩すと受け入れが増えるか減るか。
- トイツが役牌、ドラ、端牌、中張牌のどれか。
- 安牌を持つ価値があるか。
- 鳴き手かメンゼン手か。

### 判断手順

1. トイツを2つ数える。
2. それぞれがヘッド、アンコ、ポン材としてどれだけ価値があるかを見る。
3. 2ヘッド維持と1ヘッド固定の受け入れを比較する。
4. 4枚程度の受け入れ差が、安全度や打点に見合うか判断する。

### 例

`234m456p78s55z88m9p` は `55z` と `88m` の2ヘッドです。`9p` が余剰なら2ヘッドを維持しやすいですが、`88m` を崩すとタンヤオや良形変化が明確に増えるなら比較対象になります。

### 例外・補正

役牌トイツやドラトイツは残す価値が高くなります。逆に、ピンフやタンヤオを強く見たい手では、端牌トイツを崩す選択が出ます。終盤は受け入れより安全牌保持を優先することもあります。

### よくあるミス

- 2ヘッドなら常に正解だと考える。
- トイツを残すために強いリャンメン変化を消す。
- 鳴き手のポン材価値とメンゼン手の効率を同じ基準で見る。

### 一言ルール

2ヘッドは安定形だが、受け入れ差と安全度で使い分ける。

## 3ヘッド最弱理論

### 要約

3ヘッドは、ヘッド候補が多すぎて通常手では重くなりやすい形です。最終的に必要なヘッドは1つだけなので、メンゼン手ではトイツほぐしを検討します。

### 使う局面

トイツが3組あり、通常手に向かうメンゼン手で使います。七対子、対々和、役牌ポンの可能性があるときは別ルートも比較します。

### 判断基準

- メンゼン手か鳴き手か。
- トイツが役牌、ドラ、端牌、中張牌のどれか。
- トイツを崩してリャンメンや複合形にできるか。
- 2ヘッドにしてもヘッド候補が残るか。
- 七対子や対々和が現実的か。

### 判断手順

1. トイツを3つ数える。
2. 通常手、七対子、対々和、鳴き手のどれが近いか見る。
3. 通常手なら、最も将来価値の低いトイツを崩す候補にする。
4. 鳴き手なら、ポン材として残す価値を確認する。

### 例

`223m55p77s34m678p1z` は3ヘッド気味です。メンゼンの通常手なら、周辺変化のある `22m` や `55p` の使い方を見て、2ヘッドへ整理します。役牌やドラが絡むなら残す候補が変わります。

### 例外・補正

鳴き手では3ヘッドはポン材として価値が上がります。役牌トイツ、ドラトイツ、対々和や七対子が見える手では、3ヘッドをすぐ弱いと決めません。

### よくあるミス

- メンゼン手と鳴き手で同じように3ヘッドを嫌う。
- 七対子が近いのに通常手だけで判断する。
- 役牌トイツを単なる余剰ヘッドとして処理する。

### 一言ルール

メンゼンの3ヘッドは重いが、鳴き手ではポン材になる。

## 4ヘッド以上

### 要約

4ヘッド以上は、通常手としてはかなり重い構造です。通常手、七対子、対々和、役牌仕掛けの分岐点として扱います。

### 使う局面

トイツが4組以上ある序盤から中盤で使います。通常手に戻すのか、対子手へ寄せるのかを決めます。

### 判断基準

- 七対子のシャンテン数は近いか。
- 対々和や役牌ポンで速度が出るか。
- 通常手に戻すなら、どのトイツを崩すと良形化するか。
- ドラや役牌のトイツがあるか。
- メンゼン高打点と鳴き速度のどちらが必要か。

### 判断手順

1. トイツ数を数える。
2. 七対子、対々和、通常手の距離を比較する。
3. 残すトイツを価値順に並べる。
4. 通常手なら、周辺変化がある数牌トイツからほぐす候補にする。

### 例

`22m44p66s88s55z6z7z` は対子手の要素が強い形です。通常手だけでなく、七対子や役牌ポンの速度も比較します。

### 例外・補正

親番や早い巡目で高打点を狙えるなら対子手を残しやすくなります。逆に、局消化や速度が必要なら役牌ポンを強く見ます。

### よくあるミス

- 通常手だけを見てトイツを崩しすぎる。
- 七対子と対々和の分岐を考えない。
- ドラトイツの価値を低く見積もる。

### 一言ルール

4ヘッド以上は、通常手と対子手の分岐点。

## 1ヘッド

### 要約

1ヘッドは通常手で安定した構造です。ヘッドを崩すとヘッドレスになり、雀頭を作り直す必要があるため、崩すには明確なリターンが必要です。

### 使う局面

ヘッド候補が1つだけある手で、トイツを固定するか、ほかの形に使うかを判断するときに使います。

### 判断基準

- そのトイツを崩しても新しいヘッド候補を作れるか。
- 崩すことでリャンメン、タンヤオ、ピンフ、ドラ受けが増えるか。
- トイツが役牌やドラか。
- ヘッドレスになるリスクに見合うか。

### 判断手順

1. ヘッド候補が本当に1つだけか確認する。
2. 崩した後のヘッド候補を探す。
3. 崩した場合の受け入れと打点上昇を比較する。
4. 迷う場合はヘッドを維持する。

### 例

`234m456p78s55m79p12z` は `55m` が唯一のヘッドです。`5m` を切るとヘッドレスになるため、明確な打点上昇や良形化がなければ維持します。

### 例外・補正

ヘッドがドラ周辺の中張牌で、崩すと大きく形が広がる場合は例外になります。役牌トイツは鳴けるため、メンゼン効率だけでは判断しません。

### よくあるミス

- 唯一のヘッドを軽く崩して、後で雀頭に困る。
- ヘッドの価値を一律で見て、役牌やドラを無視する。
- ヘッドレス形の受け入れを過大評価する。

### 一言ルール

1ヘッドは安定。崩すなら明確な見返りが必要。

## ヘッドなし

### 要約

ヘッドなしは、メンツ候補はあっても雀頭候補が足りない形です。ヘッド候補を生みやすい複合形や重なりやすい浮き牌の価値が上がります。

### 使う局面

トイツがなく、リャンメンやメンツ候補が多い手で使います。特に1シャンテン付近で雀頭を作れるかが問題になります。

### 判断基準

- トイツになりやすい浮き牌があるか。
- 中ぶくれ、亜リャンメン、連続形があるか。
- 単純なリャンメン固定でヘッド候補を消していないか。
- 字牌や端牌の重なりに価値があるか。

### 判断手順

1. トイツがないことを確認する。
2. ヘッド候補を作る牌を探す。
3. 複合形をメンツ固定せず、ヘッド利用も考える。
4. ブロック数と受け入れを比較して打牌を決める。

### 例

`234m456p678s25m79p1z` はメンツ候補は多いもののヘッドがありません。`5m` や `7p` のような重なりやくっつきを、単なる余剰牌として切りすぎないようにします。

### 例外・補正

鳴き手で役牌がある場合、字牌の重なり価値が上がります。終盤はヘッド候補より安全牌を優先することがあります。

### よくあるミス

- リャンメンだけを残してヘッド候補を消す。
- ヘッドレスなのに、浮き牌を価値のない余剰牌と扱う。
- 亜リャンメンや中ぶくれのヘッド性能を見落とす。

### 一言ルール

ヘッドレスでは、メンツ候補だけでなく雀頭を作る牌を残す。

## メンツ固定かヘッド固定か

### 要約

複合形をメンツとして固定するか、ヘッドとして固定するかを選ぶ判断です。ヘッド固定は内側の牌から切るのが基本ですが、安全度や変化価値で補正します。

### 使う局面

亜リャンメン、中ぶくれ、トイツを含む複合形で、どの役割に固定するか迷う局面で使います。

### 判断基準

- ヘッド候補が足りているか。
- メンツ候補が足りているか。
- 固定すると消える受け入れや変化は何か。
- 内側の牌を先に切る危険度は許容できるか。
- タンヤオ、ピンフ、イーペーコー、ドラ受けに影響するか。

### 判断手順

1. 複合形をヘッド利用とメンツ利用に分けて見る。
2. 全体のヘッド数とブロック数を確認する。
3. 固定後に残る受け入れを比較する。
4. 危険牌処理と将来変化を天秤にかける。

### 例

`3345m456p78s22z9p` の `3345m` は、`33m` をヘッドに見るか、`345m` をメンツに見るかで扱いが変わります。ヘッドが足りないならヘッド固定、ヘッドが足りているならメンツ化や変化を見ます。

### 例外・補正

内側の牌は変化が多い一方、終盤には危険牌になりやすいです。序盤は変化を残し、中盤以降は危険牌処理を強めるなど、巡目で判断を変えます。

### よくあるミス

- 形だけで固定し、全体のヘッド数を見ない。
- 内側の牌を残し続けて終盤に切れなくなる。
- 役やドラ受けを消す固定を無意識に選ぶ。

### 一言ルール

固定判断は、全体のヘッド数とブロック数から決める。

## 判断チェックリスト

- ヘッド候補を0、1、2、3、4以上で数えたか。
- メンゼン手と鳴き手でトイツ価値を切り替えたか。
- 3ヘッドを通常手、七対子、対々和で比較したか。
- ヘッドレスなら、雀頭を作る牌を残しているか。
- 固定で消える受け入れと変化を確認したか。
