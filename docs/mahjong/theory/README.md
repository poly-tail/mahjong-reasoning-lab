# 麻雀牌効率・手組み理論

このドキュメント群は、『ウザ式 麻雀学習 牌効率』の内容ブリーフを一次情報として、麻雀の牌効率・手組み判断を学習しやすい形に再構成したものです。原文、例題、紙面構成の再現ではなく、理論・判断基準・例外・実戦フローとして参照できることを目的にしています。

牌姿表記は `123m456p789s11z` 形式に統一します。`m` は萬子、`p` は筒子、`s` は索子、`z` は字牌で、字牌は `1z=東, 2z=南, 3z=西, 4z=北, 5z=白, 6z=發, 7z=中` です。

## 牌効率とは何か

牌効率とは、最終形である4メンツ1雀頭に向けて、手牌をどのように分解し、どの候補を残し、どの候補を落とすかを判断する技術です。

単純に現在の受け入れ枚数が多い打牌を選ぶだけではありません。受け入れ後の形、2次変化、打点、役、鳴きやすさ、安全度、巡目、シャンテン数を分けて評価します。

## 基本方針

1. シャンテン数を確認する。
2. 手牌をブロックに分ける。
3. 5ブロックで4メンツ1雀頭を作る道筋を見る。
4. 2シャンテン以前では、形の強さや2次変化を残す。
5. 1シャンテンでは、テンパイ受け入れの価値を高く見る。
6. ヘッド数、弱ターツ、複合形、鳴きやすさ、安全度で補正する。

## このドキュメントの使い方

最初は用語集とブロック理論を読み、手牌を分解する視点を作ってください。その後、ヘッド数、ターツ比較、複合形、待ちの数え方へ進むと、何切る判断の理由を説明しやすくなります。

実戦前の確認には [decision-flow.md](decision-flow.md) を使います。練習問題を自作する場合は [practice-prompts.md](practice-prompts.md) を参照してください。
