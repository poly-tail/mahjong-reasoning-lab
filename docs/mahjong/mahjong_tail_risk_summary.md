# 麻雀における局期待値・下側裾・半荘期待値の整理メモ

## 1. この資料の目的

この資料は、以下の論点を整理したもの。

- 局期待値最大化と、半荘期待値最大化は同じではない
- 「分散」という言葉だけでは粗く、実際には
  - 下側裾回避
  - 上側裾獲得
  を分けて考えるべき
- 安手危険押しのような、上が薄く下が重い選択は、局EVがプラスでも半荘価値で削られやすい
- ただし、その有効性は万能ではなく、主戦場は局期待値差の小さい帯域に限られる
- 実力差を考慮しても、比較に効くのは「絶対実力差」ではなく「選択によって将来発揮できる実力差の差分」である

前提は主に次の通り。

- 東場平場、残り局数はそこそこある想定
- 条件戦は除く
- 局面依存の点数状況や親番価値は平均化して考える

---

## 2. 基本の記号

- `d` : 局期待値差。局EV最大打牌Aと、別打牌Bとの差。
  - ここでは `d = EV(A) - EV(B) > 0` と置く
- `H(A), H(B)` : 半荘期待値
- `c` : 裾補正差。Bを選ぶことで得られる半荘価値補正の差
- `G(d)` : 局EVだけ見る戦略と、裾まで見て半荘EV最大化する戦略との差

最も重要な式は次の形。

```text
H(B) - H(A) = c - d
```

したがって、

- `c > d` なら B が半荘期待値で上
- `c = d` なら ほぼ無差
- `c < d` なら A が上

また、局EVだけでAを選ぶ戦略より、裾まで見てBを選ぶ戦略がどれだけ得するかは

```text
G(d) = max(c - d, 0)
```

で表せる。

---

## 3. 「分散」ではなく何を見ているのか

議論で混ざりやすいが、本当に見ているのは次の2つ。

### 3.1 下側裾回避

安手危険押しのように、

- 上がっても +2000 から +3000 程度
- 放銃すると -6500 から -8000 程度

のような選択は、悪い結果1回の重みが大きい。

これは単なる「分散が大きい」ではなく、

- 下側裾が重い
- 上側裾が細い

という非対称性の問題である。

### 3.2 上側裾獲得

一方で、高打点ルートを残す選択は

- 下側裾は多少悪化しても
- 上側裾が太くなる

ので、その「良い荒さ」を取る価値がある。

したがって、雑に「分散を取る/取らない」と言うのではなく、

```text
半荘期待値差 = 局期待値差 - 下側裾回避価値 + 上側裾獲得価値
```

と分けて考える方が正しい。

## 4. 安手危険押しモデル

以下のような二点モデルを置く。

```text
X_A =
  +g   (確率 p)
  -L   (確率 q)
```

ここで

- `g` : 成功時の加点側リターン
- `L` : 失敗時の失点側リスク
- `p + q = 1`

局期待値差 `d` を満たすために

```text
d = p*g - q*L
```

したがって

```text
q = (g - d) / (L + g)
p = (L + d) / (L + g)
```

大失点1回あたりの追加半荘損失を `P` と置くと、半荘価値での実利は

```text
G(d) = max(q*P - d, 0)
```

で表せる。

意味はこう。

- `q*P` が、重い下側裾による追加半荘損失
- これが局期待値差 `d` を超えた時だけ、局EV最大打牌から別打牌へ切り替える実利が出る

| +2000 / -6500 | 実利大 | まだ出る | 境界 | 薄い | ほぼ無い |

- **400差** は境界
- **500超** はかなり薄い
- ただし **高打点上側裾** を同時に取れるなら、400〜500差でも十分に価値が残る

## 8. 海底例の整理

海底で、押しが

- 85%で +1500
- 15%で -8000

降りが -1000 とすると、降りとの差分は

```text
+2500 (85%)
-7000 (15%)
```

なので局期待値差は

```text
0.85*2500 - 0.15*7000 = 1075
```

となる。

このケースでは、下側裾は重いが、それはすでに局EV 1075 の中に入っている。したがって、半荘価値で降りが逆転するには、さらに

```text
0.15 * P > 1075 + 0.85 * B
```

が必要になる。

ここで

- `P` : 8000放銃した時の追加状態価値損失
- `B` : +1500成功時の追加状態価値ボーナス

である。

つまり、この種の具体例では、前の一般的な「逆転ライン100前後」をそのまま使うのではなく、その局面専用に計算しないといけない。

## 9. 実力差を考慮する場合

実力差を毎局 `+400` と置いても、それが両選択に共通なら比較では相殺される。

比較に効くのは、

```text
その選択をしたことで、残り局でどれだけ余分に実力差を発揮できるか
```

の差分だけ。

今局の差を `-1200` とし、残り3局での差分としての実力優位を `delta` とすると、逆転条件は

```text
3 * delta > 1200
```

すなわち

```text
delta > 400
```

である。

したがって、

- 「残り3局で自分は強いから取り返せる」では比較にならない
- 必要なのは「その選択をしたことで A より B の方が残り各局で +400 余分に勝てる」ことである

## 10. 実務用の整理

### 10.1 下側裾回避の主戦場

- 局期待値差 100〜200 : かなり強く効く
- 200〜300 : まだかなり効く
- 300〜400 : 境界帯
- 400〜500 : 薄くなりやすい
- 500超 : 通常は局EV側でよい

### 10.2 上側裾獲得の扱い

- 「高打点側の荒さはどんどん取る」ではなく、
- 下側裾悪化と局EV損失を差し引いてなおプラスなら取る

### 10.3 用語整理

- 分散一般、ではなく
  - 下側裾回避
  - 上側裾獲得
  に分ける
- 今回の主題は主に下側裾回避の実利評価

---

## 11. 最終要約

今回の議論で一番使える結論は次の通り。

1. 安手危険押しは「分散が大きい」ではなく「下側裾が重く上側裾が細い」と捉えるべき。
2. 局EV最大打牌から、裾まで見た半荘EV最大打牌へ切り替える実利は

   ```text
   G(d) = max(qP - d, 0)
   ```

   で見られる。
3. +2000 型なら 100〜300差が主戦場、400は境界、500超はかなり薄い。
4. +4000 型なら 400〜500差でもまだ有効性が残ることがある。
5. 実力差は絶対値ではなく、選択によって将来どれだけ余分に発揮できるかの差分だけが比較に効く。
