# Tenhou Hojo Helper 仕様書 v1.1

## 1. 概要
- 牌画像管理と座席キャンバスの責務を明確化した版。
- 将来のキャプチャ統合を見据えてデータ契約を整理する。

## 2. コンポーネント
| コンポーネント | 役割 | 備考 |
|----------------|------|------|
| `tenhou_hojo` | メインウィンドウ生成と描画制御 | `main()` |
| `LoadImage` | 牌画像の読み込み、回転、ツモ切り差分、座席描画 | `initialize_image`, `create_canvas` |
| キャプチャモジュール | 捨て牌履歴の供給 | 将来実装 |

## 3. データモデル
- `sutehaiLL` は座席ごとの捨て牌データを持つ。
- 画像テーブルは `img_table[draw_type][seat][tile_id]` 形式で管理する。
- ドロー種別は `0=手出し`, `1=ツモ切り`。

## 4. 描画フロー
1. ウィンドウ生成
2. 画像テーブル構築
3. 捨て牌データ取得
4. 4 キャンバス描画
5. `mainloop()` 実行

## 5. レイアウト
- 670x640 のウィンドウ
- 自家・対面は横長、下家・上家は縦長キャンバス
- 6 枚ごとに折り返し
