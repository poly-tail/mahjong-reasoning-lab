## 牌効率とは何か

牌効率とは、手牌を最短または最も期待値の高い形でテンパイ・和了へ近づけるための手組み技術です。単に受け入れ枚数が多い打牌を選ぶだけではなく、次巡以降の変化、打点、役、鳴きやすさ、最終待ちの強さ、守備力を分けて評価します。

牌効率の中心は、通常手である `4メンツ1雀頭` を安定して作ることです。手牌をメンツ候補、ターツ、トイツ、孤立牌に分解し、どのブロックを残し、どの余剰牌を切るかを判断します。

## 4メンツ1雀頭を作る基本方針

1. まずシャンテン数を確認する。
2. ブロック数を数え、足りないなら孤立牌や複合形の価値を見る。
3. ブロックが多いなら弱いターツや余剰トイツを整理する。
4. ヘッド候補の数を確認する。
5. 1シャンテンでは、受け入れ枚数と最終形の質を重視する。
6. 打点、役、ドラ、鳴き、守備、場況で補正する。

## 学習順序

1. `glossary.md` で用語を確認する。
2. `01-block-theory.md` と `02-head-theory.md` で手牌の骨格を見る練習をする。
3. `03-taatsu-theory.md` と `04-complex-shapes.md` でブロック同士の比較を学ぶ。
4. `05-wait-counting.md` で受け入れ・待ちを数える手順を固める。
5. `06-techniques.md` で目先の枚数と2次変化のバランスを学ぶ。
6. `07-calling-efficiency.md` で鳴き前提の速度評価を加える。
7. `decision-flow.md` を使って実戦中の判断順へ落とし込む。
