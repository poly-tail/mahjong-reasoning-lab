# 手組み判断フロー

この章で判断できるようになること:

- 実戦中に、何を先に確認すべきか順番を固定できる。
- 受け入れ、変化、打点、鳴き、守備を混ぜずに比較できる。
- 迷った局面を復習しやすい形で記録できる。

## 手組み判断フロー

### 1. シャンテン数を確認する

- 何シャンテンかを最初に見る。
- 1シャンテンならテンパイ受け入れを重視する。
- 2シャンテン以前なら、2次変化や打点変化も見る。

確認すること:

- 通常手のシャンテン
- 七対子のシャンテン
- 国士無双のシャンテン
- 鳴ける役の有無

### 2. ブロック数を数える

- 完成メンツ、ターツ、トイツをブロックとして数える。
- 5ブロック未満なら、孤立牌や複合形の伸びを見る。
- 6ブロック以上なら、どのブロックを落とすか仮決めする。

判断:

- 4ブロック以下: ブロックを作る牌を残す。
- 5ブロック: 余剰牌を整理する。
- 6ブロック: 弱いブロックを比較する。

### 3. ヘッド候補の数を数える

- 0ヘッド: 重なり価値を重く見る。
- 1ヘッド: ヘッドを不用意に壊さない。
- 2ヘッド: 安定しやすい。
- 3ヘッド: 通常手では余りやすい。
- 4ヘッド以上: 七対子・対々和・鳴きを比較する。

### 4. 弱いターツを探す

弱い順の目安:

1. 役にも変化にも絡まないペンチャン
2. 外側カンチャン
3. 場に多く見えているターツ
4. 他ブロックと受けが重複しているターツ
5. 打点や鳴きに絡まない余剰トイツ

ただし、ドラ受け、役絡み、鳴きやすさ、安全度で補正する。

### 5. 強い複合形を残す

残しやすい形:

- 4連形
- 中ぶくれ
- リャンカン
- 亜リャンメン
- リャンメンカンチャン
- イーペーコー含み
- 多面待ちへ発展する連続形

確認すること:

- メンツにもヘッドにもなるか。
- 受け入れが複数方向あるか。
- 打点や役に絡むか。
- 固定すると何を失うか。

### 6. 孤立牌の価値を評価する

孤立牌は、単に不要牌として切る前に価値を確認する。

価値が高い孤立牌:

- `3` から `7` の内側牌
- ドラ周辺
- 赤ドラ受け
- タンヤオに寄せる牌
- 三色・一通・ホンイツなど役の種
- ヘッドレス時の重なり候補

価値が低い孤立牌:

- 役に絡まない端牌
- 既に周辺が薄い牌
- 受けが重複している牌
- 安全度も低い余剰牌

### 7. 1シャンテンでは受け入れ枚数を最大化する

1シャンテンでは、次にテンパイする枚数が速度に直結する。

確認すること:

- 候補打牌ごとのテンパイ受け入れ種類
- 実枚数
- テンパイ後の待ちの質
- リーチできるか
- 鳴いてテンパイできるか

注意:

- 受け入れ最大でも悪形だらけなら補正する。
- 高打点や良形確定なら少し狭くても選ぶことがある。

### 8. 打点・役・鳴き・守備で補正する

牌効率だけで決めない補正項目:

- ドラの枚数
- 役の確定度
- リーチ価値
- 鳴きやすさ
- 親番・子番
- 巡目
- 点棒状況
- 安全牌の有無
- 他家の速度

補正の考え方:

- 序盤: 変化と打点を見やすい。
- 中盤: 速度と形の安定を重視する。
- 終盤: 安全度と押し引きが大きくなる。

### 9. 最終的な打牌候補を比較する

候補ごとに以下を並べる。

| 観点 | 候補A | 候補B |
| --- | --- | --- |
| シャンテン | 変わるか | 変わるか |
| ブロック | 5ブロックか | 5ブロックか |
| ヘッド | 足りるか | 足りるか |
| 受け入れ | 種類・枚数 | 種類・枚数 |
| 変化 | 良形化・打点化 | 良形化・打点化 |
| 打点 | 役・ドラ | 役・ドラ |
| 鳴き | チー・ポン可 | チー・ポン可 |
| 守備 | 安全牌が残るか | 安全牌が残るか |

最後に、なぜその打牌を選ぶかを一文で説明できれば、復習しやすい判断になっている。
