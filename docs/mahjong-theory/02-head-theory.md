# ヘッド理論

この章で判断できるようになること:

- ヘッド候補の数で手牌の安定性を評価できる。
- 2ヘッドが扱いやすく、3ヘッドが重くなりやすい理由を説明できる。
- ヘッドレス形で何を残すべきか判断できる。
- メンツ固定とヘッド固定の比較ができる。

PDF参照: 第2章ヘッドは p.15-p.29。2ヘッドは p.16-p.18、3ヘッドは p.19-p.20、4ヘッド以上は p.21、1ヘッドは p.22、ヘッドなしは p.23-p.24、固定判断は p.25-p.29。

## 2ヘッド理論

### 要約

2ヘッドは、雀頭候補を2つ持つことで手牌が安定しやすい形である。片方を雀頭、もう片方をメンツ候補として使えるため、受け入れと変化のバランスがよい。

### 使う局面

- トイツが2つある2シャンテンから1シャンテン。
- 片方のトイツを残すか、ターツを残すか迷う局面。
- ヘッド候補を固定しすぎると受け入れが減る局面。

### 判断基準

- 2つのトイツが役牌、ドラ、端牌、数牌のどれか。
- 片方が暗刻化したときの打点・速度。
- 周辺牌で複合形になるか。
- 鳴き前提ならポン材として価値があるか。

### 判断手順

1. トイツが2つあるか確認する。
2. どちらをヘッドにしてもよい形か見る。
3. 片方がメンツ化したときに残りがヘッドになるか確認する。
4. 役牌やドラトイツなら価値を上げる。
5. 受け入れを大きく減らす固定は避ける。

### 例

再構成例:

`234m56p78p33s77z` は `33s` と `77z` の2ヘッド形。どちらかが暗刻化すればもう片方が雀頭になり、手牌が崩れにくい。

PDF p.16-p.18 に2ヘッドの例がある。牌姿の厳密転記は `[要確認]`。

### 例外・補正

- 字牌トイツが役牌なら、鳴き効率と打点で価値が上がる。
- オタ風トイツは安全牌候補だが、速度面では数牌トイツに劣ることがある。
- 2ヘッドでも、ほかのターツが弱すぎる場合はトイツをほぐす選択がある。

### よくあるミス

- 2ヘッドを早く1ヘッドに固定しすぎる。
- 役牌トイツを単なるヘッドとしてしか見ない。
- トイツ周辺の複合形を見落とす。

### 一言ルール

2ヘッドは安定形、急いで片方に決めすぎない。

## 3ヘッド最弱理論

### 要約

3ヘッドは一見受けが多そうだが、通常手では雀頭は1つしか使わないため、トイツが余りやすい。メンツ候補が不足していると、手牌全体が重くなる。

### 使う局面

- トイツが3つあり、ターツが不足している。
- どのトイツを落とすか、どのターツを残すか迷う。
- 1シャンテンでトイツ固定が受け入れを減らしている。

### 判断基準

- 3つのトイツのうち、役牌・ドラ・安全牌価値があるものはどれか。
- 数牌トイツが周辺牌で伸びるか。
- トイツを1つ切ることでターツが残せるか。
- 七対子や対々和を見る価値があるか。

### 判断手順

1. 3トイツを確認する。
2. 通常手、七対子、対々和のどれを主軸にするか決める。
3. 通常手なら、余剰トイツ候補を探す。
4. 役牌・ドラ・鳴きやすさ・安全度で残すトイツを補正する。
5. 1シャンテンでは受け入れ枚数を確認してトイツを整理する。

### 例

再構成例:

`234m56p78p33s77z99z` は3ヘッド気味。通常手なら、役がない字牌トイツや孤立した端寄りトイツから整理し、メンツ候補を増やす。

PDF p.19-p.20 に3ヘッド最弱理論の例がある。牌姿は `[要確認]`。

### 例外・補正

- 七対子2シャンテン以内なら3ヘッド以上を維持する価値がある。
- 役牌トイツが複数ある鳴き手では、3ヘッドが弱いとは限らない。
- 守備重視なら字牌トイツを残す価値がある。

### よくあるミス

- トイツが多いほど強いと誤解する。
- 通常手と七対子を中途半端に両追いする。
- 役牌トイツとオタ風トイツを同じ価値で扱う。

### 一言ルール

通常手の3ヘッドは、1つ余る前提で整理候補を探す。

## 4ヘッド以上

### 要約

4ヘッド以上は、通常手より七対子・対々和・役牌ポンを強く意識する形である。通常手に戻すなら、どのトイツをメンツ化・雀頭化・安全牌化するかを整理する。

### 使う局面

- トイツが4つ以上ある。
- 七対子のシャンテンが通常手より近い。
- 役牌やドラトイツが多く、鳴き手に向く。

### 判断基準

- 七対子の距離。
- 対々和や役牌ポンの現実性。
- トイツの牌種が鳴きやすいか。
- 通常手に戻したときのターツ不足。

### 判断手順

1. 通常手と七対子のシャンテンを比較する。
2. 鳴ける役牌・ドラトイツを確認する。
3. 通常手にするなら、弱いトイツをほぐす。
4. 七対子にするなら、孤立牌の重なりやすさを評価する。

### 例

PDF p.21 に4ヘッド以上の扱いがある。画像一覧では牌姿細部が不明のため `[要確認]`。

### 例外・補正

- 役牌トイツが多い親番は、鳴き速度が高い。
- 七対子は守備力が残りやすいが、速度はツモ依存になる。
- ドラトイツは打点価値が高い。

### よくあるミス

- 4ヘッド以上でも通常手だけで考える。
- 七対子へ寄せる判断が遅れ、孤立牌を無駄に切る。
- 鳴き手なのにポン材を軽視する。

### 一言ルール

4ヘッド以上は、通常手か七対子・対々和かを早めに決める。

## 1ヘッド

### 要約

1ヘッドは雀頭が確保されているため形は安定するが、ヘッド固定が早すぎるとメンツ化の受けを失うことがある。ほかに雀頭候補がない場合は、ヘッドを守る価値が高い。

### 使う局面

- トイツが1つだけある。
- そのトイツを切るとヘッドレスになる。
- トイツ周辺にメンツ化の変化がある。

### 判断基準

- ほかにヘッド候補が作れそうか。
- 現在のトイツが役牌・ドラか。
- トイツをメンツ化したときに雀頭が不足しないか。
- 1シャンテンで受け入れが増える固定か。

### 判断手順

1. ヘッド候補が1つだけか確認する。
2. 切るとヘッドレスになる牌を把握する。
3. メンツ化した場合の代替ヘッドを探す。
4. 代替がないならヘッド固定を優先する。

### 例

PDF p.22 に1ヘッドの扱いがある。牌姿は `[要確認]`。

### 例外・補正

- 連続形の中のトイツは、メンツにもヘッドにもなるため価値が高い。
- 七対子を見る手では1ヘッドの意味が変わる。
- 鳴き手で役牌トイツならヘッドではなくポン材として見る。

### よくあるミス

- 1ヘッドを不用意に切ってヘッドレスにする。
- ヘッド固定しすぎて、良形変化を失う。

### 一言ルール

1ヘッドは保険、代替ヘッドがないなら大切にする。

## ヘッドなし

### 要約

ヘッドレス形では、雀頭候補を作る牌の価値が上がる。強いターツを残すだけでは完成できないため、トイツ化しやすい孤立牌や複合形も評価する。

### 使う局面

- トイツがなく、メンツ候補だけで構成されている。
- リャンメンが多いが雀頭がない。
- 孤立牌を切るとヘッド候補が不足する。

### 判断基準

- どの牌が重なるとヘッドになるか。
- 連続形の中でトイツ化しやすい牌があるか。
- ヘッドを作るために受け入れをどれだけ落とすか。
- 鳴いた後にヘッドが残るか。

### 判断手順

1. ヘッド候補がないことを確認する。
2. 重なりで価値が出る孤立牌を探す。
3. リャンメン固定でヘッド候補を消さないか確認する。
4. 1シャンテンでは、ヘッドができる受けを含めて数える。

### 例

PDF p.23-p.24 にヘッドなし形の例がある。牌姿の正確な読み取りは `[要確認]`。

### 例外・補正

- 完成メンツが多い場合は、ヘッド候補だけを探す判断が明確になる。
- 七対子移行が見えるなら、孤立牌の重なり価値がさらに上がる。

### よくあるミス

- リャンメンだけを残してヘッド候補を消す。
- ヘッドレスなのに孤立牌をすぐ切る。

### 一言ルール

ヘッドレスでは、重なりの価値を受け入れに含める。

## メンツ固定かヘッド固定か

### 要約

複合形では、メンツとして固定するか、ヘッドとして固定するかで受け入れが変わる。固定判断は、現在のヘッド候補数、ターツの強さ、1シャンテン時のテンパイ枚数で決める。

### 使う局面

- トイツを含む複合形がある。
- 1シャンテンで固定によって受け入れが大きく変わる。
- ヘッド候補とメンツ候補が重複している。

### 判断基準

- ほかにヘッドがあるか。
- 固定後のテンパイ受け入れ枚数。
- 固定後の待ちの質。
- 打点・役・ドラとの関係。
- 鳴いたときに固定の意味が変わるか。

### 判断手順

1. 固定前の形をメンツ候補とヘッド候補に分解する。
2. メンツ固定した場合の残りヘッドを確認する。
3. ヘッド固定した場合の残りターツを確認する。
4. 候補打牌ごとに受け入れを数える。
5. 同等なら打点、鳴きやすさ、安全度で補正する。

### 例

PDF p.25-p.29 に固定判断の比較例がある。表の数値は画像一覧で読める部分もあるが、牌姿の細部は `[要確認]`。

### 例外・補正

- ヘッド候補が複数あるならメンツ固定が強くなることが多い。
- ヘッド候補がないなら、ヘッド固定を優先しやすい。
- 鳴き手ではポン材としてトイツを残す価値が上がる。

### よくあるミス

- 見た目の完成メンツだけで固定する。
- ヘッド候補の数を数えずにリャンメン固定する。
- 1シャンテンなのに受け入れ枚数を確認しない。

### 一言ルール

固定前に、ヘッド候補の数と固定後のテンパイ枚数を必ず見る。
