# 鳴き効率

この章で判断できるようになること: メンゼン手と鳴き手で評価軸を切り替え、チー、ポン、3ヘッド、打点、喰い替えを含めた速度判断ができるようにします。

## チー2倍速、ポン4倍速

### 要約

チーは上家からしかできませんが、ポンは3人からできます。そのため鳴き手では、ポン材であるトイツの速度価値が大きく上がります。

### 使う局面

役牌トイツ、ドラトイツ、鳴いても役が残る手で、メンゼン維持か鳴き速度かを比較するときに使います。

### 判断基準

- 鳴いて役が残るか。
- ポン材が役牌やドラか。
- チーできるターツが上家依存か。
- 鳴いた後の打点が十分か。
- 鳴いた後に守備力が落ちすぎないか。

### 判断手順

1. 鳴ける役を確認する。
2. ポン材とチー材を分ける。
3. 鳴いた後のシャンテン数と打点を見る。
4. 鳴いた後の打牌候補を決める。
5. 守備力低下を補正する。

### 例

`234m45p78s55z66z9p` で `55z` が役牌なら、ポンで速度が大きく上がります。メンゼンの良形変化より、役牌ポンの実戦速度を高く見ます。

### 例外・補正

メンゼン高打点が近い手、リーチ価値が高い手、守備力が必要な局面では鳴きを控えることがあります。役なしになる鳴きは原則避けます。

### よくあるミス

- チーとポンの速度価値を同じに見る。
- 鳴いた後の役や打牌を確認しない。
- メンゼン手の牌効率を鳴き手にそのまま適用する。

### 一言ルール

鳴き手では、ポン材の速度価値を高く見る。

## 鳴き手とメンゼン手で変わる価値判断

### 要約

メンゼン手では発展性や良形変化を重視し、鳴き手では鳴きやすさと即効性を重視します。同じ複合形でも、手役方針によって価値が変わります。

### 使う局面

役牌、タンヤオ、ホンイツ、トイトイなど鳴ける役が見える手で使います。

### 判断基準

- メンゼンでリーチ価値があるか。
- 鳴いても役と打点が残るか。
- 複合形は良形変化型か、鳴きやすい型か。
- ポン材やチー材が多いか。
- 鳴いた後の最終形が悪くなりすぎないか。

### 判断手順

1. メンゼンルートと鳴きルートを分ける。
2. それぞれの速度、打点、最終形を比較する。
3. 複合形の価値をルートごとに評価する。
4. 局面目的に合う方針を選ぶ。

### 例

`245m456p78s55z33p` の `245m` はメンゼンなら良形変化を見ます。一方、鳴きタンヤオに寄せるなら、鳴けるターツやポン材の価値を高く見ます。

### 例外・補正

鳴くと安くなりすぎる手ではメンゼンを維持します。逆に、鳴いても満貫級なら速度を優先しやすくなります。

### よくあるミス

- メンゼンの発展性だけで鳴き手を評価する。
- 鳴いた後の役なしを見落とす。
- 鳴き手なのにポン材を軽く扱う。

### 一言ルール

メンゼンは発展性、鳴き手は鳴きやすさ。

## 鳴き手の3ヘッド

### 要約

メンゼンでは3ヘッドが重くなりやすい一方、鳴き手では3ヘッドがポン材として強くなります。好形3ヘッドと悪形3ヘッドを分けて評価します。

### 使う局面

鳴ける役があり、トイツが3組ある手で使います。

### 判断基準

- トイツが役牌、ドラ、端牌、中張牌のどれか。
- ポン後に役が残るか。
- ポン後に良形ターツが残るか。
- 七対子や対々和も見えるか。
- 守備力が落ちすぎないか。

### 判断手順

1. トイツ3組を数える。
2. ポンしたい順に価値を並べる。
3. ポン後の残りブロックを確認する。
4. メンゼンでほぐす場合との速度差を見る。
5. 打点と安全度を補正する。

### 例

`22m55z66z34p78s456m` は、役牌トイツがあれば鳴き手の3ヘッドとして速度価値があります。メンゼンの3ヘッド最弱理論をそのまま当てはめません。

### 例外・補正

役がない3ヘッドは鳴いても進めにくいです。守備が必要な局面や、メンゼン高打点が近い手ではトイツをほぐす選択もあります。

### よくあるミス

- 鳴き手でも3ヘッドを無条件に嫌う。
- ポン後の打牌を決めずに鳴く。
- 七対子や対々和との比較をしない。

### 一言ルール

鳴き手の3ヘッドは、重さではなくポン材として見る。

## 鳴いてもマンガンは強い

### 要約

鳴くと打点が下がることは多いですが、鳴いてもマンガン級なら十分強い手です。高打点が確保できるなら、速度を買う鳴きの価値が高くなります。

### 使う局面

ドラ、役牌、ホンイツ、トイトイ、チャンタ系などで、鳴いても高打点が見える局面で使います。

### 判断基準

- 鳴いた後の打点が十分か。
- 鳴くことで消える役は何か。
- 速度上昇がどれだけ大きいか。
- 守備力低下に耐えられるか。
- 局面上、打点と速度のどちらが必要か。

### 判断手順

1. メンゼン時の想定打点を見る。
2. 鳴いた後の想定打点を見る。
3. 鳴くことで何巡分速くなるかを見る。
4. 他家状況と点棒状況で補正する。
5. 鳴いた後の最終形を確認する。

### 例

`234m55z66z789p789s` で役牌とドラが絡むなら、鳴いても高打点が残る可能性があります。メンゼンにこだわらず速度を買う選択が出ます。

### 例外・補正

鳴くと3900以下に落ちる、守備力が大きく落ちる、リーチ価値が高い場合はメンゼンを維持します。オーラス条件では必要打点を優先します。

### よくあるミス

- 鳴くと安いという印象だけで高打点の鳴きを逃す。
- 鳴いた後の打点を計算しない。
- 守備力低下を軽視する。

### 一言ルール

鳴いても高打点なら、速度を買う。

## 喰い替え

### 要約

喰い替えにはルール上の制約があります。鳴く前に、鳴いた後に何を切れるか、役が残るか、手詰まりしないかを確認します。

### 使う局面

チーやポンを検討するとき、鳴いた直後の打牌制限が問題になる局面で使います。

### 判断基準

- 鳴いた後に切れる牌があるか。
- 喰い替え制約に引っかからないか。
- 鳴いた後に役が残るか。
- 残る形が弱くなりすぎないか。
- 安牌を失いすぎないか。

### 判断手順

1. 鳴く前に鳴いた後の手牌を想定する。
2. 直後に切れる牌を確認する。
3. 喰い替え制約を確認する。
4. 役、打点、形、安全度を再評価する。
5. 問題なければ鳴く。

### 例

`234m45p78s55z66p9m` で `3p` をチーしたい場合、鳴いた後に何を切るかを先に決めます。切りたい牌が喰い替え制約に触れるなら鳴きは再検討します。

### 例外・補正

ルールセットによって喰い替えの扱いが異なる場合があります。天鳳など自分が使うルールで確認し、実戦では鳴く前に直後の打牌を決めます。

### よくあるミス

- 鳴いてから何を切るか考える。
- 喰い替え制約を忘れる。
- 鳴いた後に役なしになる。

### 一言ルール

鳴く前に、鳴いた後の打牌まで決める。

## 判断チェックリスト

- 鳴いて役が残るか。
- ポン材とチー材を分けて評価したか。
- メンゼン手と鳴き手で評価軸を切り替えたか。
- 鳴いた後の打点を確認したか。
- 喰い替えと直後の打牌を確認したか。
