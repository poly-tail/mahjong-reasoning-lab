# 鳴き効率

この章で判断できるようになること:

- 鳴きによって速度がどう変わるか説明できる。
- メンゼン前提と鳴き前提で形の価値が変わることを理解できる。
- 好形3ヘッドと悪形3ヘッドを鳴き手として比較できる。
- 鳴いても高打点なら強い場面を判断できる。

PDF参照: 第7章鳴き効率は p.93-p.99。チー2倍速・ポン4倍速は p.94、鳴きとメンゼンで変わる複合形は p.95、好形3ヘッドは p.96、悪形3ヘッドは p.97、鳴いてもマンガンは強いは p.98、喰い替えは p.99。

## チー2倍速、ポン4倍速

### 要約

鳴きは自分のツモだけでなく他家の打牌も利用できるため、手牌進行を大きく速める。特にポンは3人の打牌を利用できるため、トイツの価値を大きく上げる。

### 使う局面

- 役牌トイツがある。
- タンヤオ、役牌、ホンイツなど鳴いて役が残る。
- 速度が必要な局面。

### 判断基準

- 鳴いて役が残るか。
- チーできるターツか、ポンできるトイツか。
- 鳴いた後の残り形が悪くないか。
- 打点が十分か。
- 守備力低下を許容できるか。

### 判断手順

1. 鳴ける役を確認する。
2. チー材とポン材を分ける。
3. 鳴いた後のブロック数とヘッドを確認する。
4. 打点と速度のバランスを見る。
5. 守備力低下を補正する。

### 例

PDF p.94 にチーとポンの速度差を扱う例がある。牌姿は `[要確認]`。

### 例外・補正

- 鳴いて役なしになる形は鳴けない。
- リーチ・ツモ・一発・裏ドラの価値を失う。
- 高打点メンゼン手は、鳴くと期待値が落ちることがある。

### よくあるミス

- 鳴けば常に速いと考える。
- 鳴いた後のヘッド不足を見落とす。
- 守備力低下を無視する。

### 一言ルール

鳴きは速いが、役・残り形・打点を確認してから。

## 鳴き手とメンゼン手で変わる複合形の価値

### 要約

メンゼンではリーチや一盃口などの価値がある形も、鳴き前提では評価が変わる。鳴き手では、チー・ポンできる形、役が残る形、打点が落ちにくい形を優先する。

### 使う局面

- メンゼンで進めるか、鳴いて進めるか迷う。
- 一盃口含みや複合形がある。
- 役牌やタンヤオで鳴ける。

### 判断基準

- 鳴いて消える役か。
- 鳴いても残る役か。
- チー・ポンのしやすさ。
- 鳴いた後の待ちの質。
- 打点低下の大きさ。

### 判断手順

1. メンゼン時の価値を確認する。
2. 鳴いた場合に消える役を確認する。
3. 鳴きで速度がどれだけ上がるか見る。
4. 打点低下と速度上昇を比較する。

### 例

PDF p.95 に、鳴き手とメンゼン手で複合形の価値が変わる例がある。牌姿は `[要確認]`。

### 例外・補正

- メンゼン限定役が重要な局面では鳴かない。
- 鳴いても満貫以上なら速度重視に寄せやすい。
- 役牌バックなど片アガリは不安定さを考慮する。

### よくあるミス

- メンゼンで強い形を、鳴き手でも同じ価値にする。
- 鳴いた後の役なしを見落とす。

### 一言ルール

鳴き前提では、消える役より鳴ける形を重く見る。

## 好形3ヘッド・悪形3ヘッド

### 要約

メンゼン通常手では3ヘッドは重くなりやすいが、鳴き手ではポン材として価値が上がる。好形3ヘッドはポンしても残り形が整いやすく、悪形3ヘッドは鳴いた後に形が苦しくなりやすい。

### 使う局面

- トイツが3つある鳴き手。
- 役牌やドラトイツがある。
- ポンするか、メンゼンで進めるか迷う。

### 判断基準

- ポンした後にヘッドが残るか。
- 残りターツがリャンメンか悪形か。
- 役牌・ドラ・タンヤオなど打点があるか。
- ポン材が出やすいか。

### 判断手順

1. 3トイツを分類する。
2. ポンした後のブロック数を数える。
3. ヘッド候補が残るか確認する。
4. 残り形が好形か悪形か評価する。
5. 打点と速度で鳴き判断する。

### 例

PDF p.96 に好形3ヘッド、p.97 に愚形3ヘッドの例がある。牌姿は `[要確認]`。

### 例外・補正

- 役牌ドラトイツは悪形でも鳴く価値がある。
- 守備重視ならポンで安全牌が減る点を考慮する。

### よくあるミス

- 3ヘッドをメンゼン評価のまま弱いと決める。
- ポン後のヘッド不足を見落とす。
- 鳴いた後のターツの質を見ない。

### 一言ルール

鳴き手の3ヘッドは、ポン後の残り形で評価する。

## 鳴いてもマンガンは強い

### 要約

鳴くと打点は下がりやすいが、鳴いても満貫以上が見える手は速度を優先しやすい。高打点を維持したまま和了率を上げられるなら、鳴きは有力な選択になる。

### 使う局面

- 役牌、ドラ、ホンイツ、トイトイなどで鳴いても高打点。
- 速度が必要な親番や局面。
- メンゼンの上振れより和了率を重視したい。

### 判断基準

- 鳴いた後の打点。
- 鳴いた後の残り形。
- 他家速度。
- 巡目。
- 守備力低下。

### 判断手順

1. 鳴いた後の打点を見積もる。
2. 残り形と和了ルートを確認する。
3. メンゼンで進めた場合の打点上昇を比較する。
4. 他家速度と局面価値を加える。

### 例

PDF p.98 に鳴いてもマンガンが強い例がある。牌姿は `[要確認]`。

### 例外・補正

- オーラスで満貫が不要なら速度だけを重視する。
- 満貫でも待ちが極端に悪い場合はメンゼン変化を見る。
- 守備不能になる鳴きは場況次第で控える。

### よくあるミス

- 鳴くと安いという理由だけで高打点鳴きを逃す。
- 鳴いた後の役消失を見落とす。

### 一言ルール

鳴いても満貫なら、速度上昇は大きな武器。

## 喰い替え

### 要約

喰い替えはルール上制限されるため、鳴き後に切れる牌と切れない牌を把握しておく必要がある。形だけでなく、鳴いた直後の打牌制約まで含めて判断する。

### 使う局面

- チー後に同じ筋の牌を切りたい。
- 鳴きで手牌を進めるが、余剰牌処理が難しい。
- 喰い替え制限があるルールで打つ。

### 判断基準

- チーした牌の構成。
- 直後に切りたい牌が喰い替えに該当するか。
- 切れない場合の代替打牌。
- 鳴いた後の安全度。

### 判断手順

1. 鳴く前に、鳴いた後の打牌候補を決める。
2. その打牌が喰い替え制限に触れないか確認する。
3. 代替打牌でも手牌が崩れないか見る。
4. 問題なければ鳴く。

### 例

PDF p.99 に喰い替えの例がある。牌姿は `[要確認]`。

### 例外・補正

- ルールによって喰い替え制限の扱いが異なる場合がある。
- ネット麻雀ではUIが制限してくれるが、判断前に知っておく方がよい。

### よくあるミス

- 鳴いた後に切りたい牌が切れず、手牌が崩れる。
- 喰い替えを避けるための代替打牌を考えていない。

### 一言ルール

鳴く前に、鳴いた直後に切れる牌まで確認する。
