# ターツ理論

この章で判断できるようになること:

- リャンメン、カンチャン、ペンチャンの強さを比較できる。
- 複合ターツを分解して評価できる。
- 弱ターツ3枚構成を理解し、どこから落とすか判断できる。
- ターツ落としの順番とタイミングを決められる。

PDF参照: 第3章ターツは p.30-p.41。基本比較は p.31-p.34、複合ターツは p.35-p.37、弱ターツ3枚構成は p.38-p.39、ターツ落としは p.40-p.41。

## ターツの基本比較

### 要約

一般に、リャンメンは受け入れが広く、カンチャンとペンチャンは狭い。カンチャン同士・ペンチャン同士では、内側変化、タンヤオ、赤ドラ、鳴きやすさ、他ブロックとの重複で価値が変わる。

### 使う局面

- 6ブロックから1ブロックを落とす。
- 弱いターツ同士を比較する。
- 序盤に変化を残すか、目先の受けを取るか迷う。

### 判断基準

- 受け入れ枚数。
- 良形変化の多さ。
- 打点上昇の可能性。
- 鳴きやすさ。
- 役との相性。
- 他ブロックと受けが重複していないか。

### 判断手順

1. リャンメン、カンチャン、ペンチャンに分類する。
2. 基本はリャンメンを優先する。
3. 悪形同士では内側変化の多いものを残す。
4. タンヤオ・三色・一通・ドラ受けで補正する。
5. 1シャンテンでは、テンパイ受け入れ枚数を再計算する。

### 例

再構成例:

`23m` は `1m/4m`、`46p` は `5p`、`89s` は `7s` が主受け。目先の受けではリャンメンが強いが、序盤の `46p` は `3p/7p` でリャンメン化する変化もある。

PDF p.31-p.34 にリャンメン、カンチャン、ペンチャン比較の例がある。牌姿は `[要確認]`。

### 例外・補正

- ペンチャンでも三色や一通の急所なら残すことがある。
- カンチャンでも赤受けやドラ受けなら価値が上がる。
- 鳴き手なら、チーしやすいターツの価値が上がる。
- 場に見えている牌が多ければ、見た目の枚数より価値が下がる。

### よくあるミス

- リャンメンなら必ず残すと決めつける。
- ペンチャンを常に最弱扱いして役絡みを見落とす。
- 同じ牌を複数ブロックで待っている重複を見落とす。

### 一言ルール

ターツは枚数、変化、役、鳴き、重複で評価する。

## 複合ターツ

### 要約

複合ターツは、1つの形が複数のターツやヘッド候補を兼ねる形である。単体のカンチャンやペンチャンより価値が高いことが多く、早く切りすぎると受け入れと変化を同時に失う。

### 使う局面

- 連続形やトイツを含む形がある。
- どの部分を固定するか迷う。
- 6ブロックで複合形と単純ターツを比較する。

### 判断基準

- 何種類の受け入れがあるか。
- 良形化する牌が何か。
- ヘッド候補を兼ねるか。
- 打点や役に絡むか。
- ほかのブロックと重複していないか。

### 判断手順

1. 複合形を複数のターツに分解する。
2. 受け入れ牌を列挙する。
3. 良形化・ヘッド化・打点化の変化を分けて見る。
4. 単純ターツと比較する。
5. 1シャンテンでは固定後のテンパイ枚数を確認する。

### 例

再構成例:

`4556m` は `45m` と `56m`、さらに `55m` ヘッド候補を含む。単なるリャンメン1つではなく、メンツにもヘッドにもなるため、単純な孤立牌より残す価値が高い。

PDF p.35-p.37 に複合ターツの例がある。牌姿は `[要確認]`。

### 例外・補正

- 複合形でも、ほかに強いブロックが十分なら余剰部分を切る。
- 打点不要で速度優先なら、複雑な変化より明確な受けを取る。
- 鳴き前提では、複合形の一部がチー・ポンしやすいかを見る。

### よくあるミス

- 複合形を単なるカンチャンやトイツとして数える。
- 固定が早すぎて受け入れを減らす。
- ヘッド候補を兼ねる価値を見落とす。

### 一言ルール

複合ターツは、分解してから切る価値を判断する。

## 弱ターツ3枚構成理論

### 要約

弱いターツが3つある手では、どれを残すかが手組みの分岐になる。単純な枚数差だけでなく、良形変化、役、ドラ、鳴きやすさで順位をつける。

### 使う局面

- カンチャン、ペンチャン、孤立トイツなど弱いブロックが複数ある。
- 5ブロックに絞るために1つ落とす。
- 1シャンテン前の形選択。

### 判断基準

- 最も悪形固定になりやすいターツはどれか。
- 内側に寄っているか。
- タンヤオや三色など役に絡むか。
- 鳴きやすい牌か。
- 場に切れている枚数。

### 判断手順

1. 弱ターツをすべて列挙する。
2. 受け入れ枚数を比較する。
3. 良形化する牌を比較する。
4. 役・打点・鳴き・場況で補正する。
5. 最も将来価値の低いターツから落とす。

### 例

PDF p.38-p.39 に弱ターツ3枚構成の比較例がある。牌姿と表の詳細は画像一覧では不明瞭なため `[要確認]`。

### 例外・補正

- 役絡みのペンチャンは単純なカンチャンより残すことがある。
- ドラ受けのカンチャンは価値が上がる。
- 鳴き手ではペンチャンでもチーできれば速度が補正される。

### よくあるミス

- 悪形をすべて同じ価値で扱う。
- 場に見えている牌を差し引かない。
- 役の完成ルートを消す。

### 一言ルール

弱ターツ同士は、目先の枚数より将来の良形化を比べる。

## ターツ落とし

### 要約

ターツ落としは、余ったブロックを2巡かけて切る判断である。落とす順番を誤ると、ツモ変化を逃したり、安全度を落としたりする。

### 使う局面

- 6ブロックから5ブロックへ絞る。
- 弱ターツを完全に見切る。
- 1シャンテンで受け入れ最大化のために固定する。

### 判断基準

- 落とすターツの受け入れが薄いか。
- 片方を先に切ったときに残る変化があるか。
- 危険牌を先に処理したいか。
- 安全牌として片方を残せるか。

### 判断手順

1. 落とすターツを決める。
2. 先に切る牌と後に切る牌で残る変化を比較する。
3. 危険度が高い牌を先切りするか検討する。
4. 次巡に有効変化を引いた場合の戻し方を考える。
5. 完全に不要なら2枚続けて処理する。

### 例

再構成例:

`12m` を落とす場合、`1m` から切ると `3m` 引きの変化を残せないが、`2m` から切ると `3m` 引きで `13m` ではなく孤立寄りになる。どちらがよいかは、残る安全度やほかの形で変わる。

PDF p.40-p.41 にターツ落としの順番・タイミングの例がある。牌姿は `[要確認]`。

### 例外・補正

- 危険牌処理を優先する場合は効率順と逆になることがある。
- ドラ周辺ターツは、完全に見切るまで慎重に扱う。
- 鳴き手なら、チー材として残す価値がある。

### よくあるミス

- 何となく端から切って、残せた変化を逃す。
- 1枚切った後に方針を忘れる。
- 安全度と効率を分けて考えない。

### 一言ルール

ターツ落としは、落とすブロックだけでなく切る順番も選択である。
