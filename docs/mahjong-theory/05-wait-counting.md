# 待ちの探し方と数え方

この章で判断できるようになること: 有効牌の種類と枚数を分けて数え、複雑な待ちをメンツ抜きで分解し、見えている枚数や待ちの価値まで評価できるようにします。

## 有効牌の種類と枚数

### 要約

有効牌は、手を進める牌です。判断では「何種類で進むか」と「実際に何枚残っているか」を分けて数えます。

### 使う局面

打牌候補の比較、1シャンテンのテンパイ受け、テンパイ時の待ち評価で使います。

### 判断基準

- シャンテン数が進む牌か。
- 種類は何種類か。
- 最大枚数は何枚か。
- 自分の手牌、河、副露、ドラ表示牌で何枚見えているか。
- 受けた後の形が良いか悪いか。

### 判断手順

1. 手牌をブロックに分解する。
2. 打牌候補ごとにシャンテンが進む牌を列挙する。
3. 種類と最大枚数を分けて数える。
4. 見えている牌を差し引く。
5. 受けた後の待ちの質を確認する。

### 例

`234m456p78s55z67m9p` で `9p` を切る場合、テンパイに進む牌の種類を列挙し、見えている枚数を差し引きます。枚数が多くても、悪形テンパイばかりなら評価を下げます。

### 例外・補正

有効牌が多くても役なし、低打点、危険な待ちになるなら価値は下がります。逆に少ない受けでも高打点や出やすい待ちなら選択肢になります。

### よくあるミス

- 種類数と枚数を混同する。
- 自分で使っている牌を差し引かない。
- 受け入れ後の待ちの質を見ない。

### 一言ルール

有効牌は、種類と残り枚数を分けて数える。

## 見えている枚数の差し引き

### 要約

待ちや受け入れの実枚数は、最大枚数から見えている牌を引いて数えます。自分の手牌だけでなく、河、副露、ドラ表示牌も確認します。

### 使う局面

1シャンテンの受け入れ比較、テンパイ時の待ち選択、鳴き判断で使います。

### 判断基準

- 自分の手牌に何枚あるか。
- 河に何枚見えているか。
- 副露で使われているか。
- ドラ表示牌として見えているか。
- 他家が使っていそうな色か。

### 判断手順

1. 待ち候補の最大枚数を出す。
2. 自分の手牌内の同牌を引く。
3. 河と副露の見えている牌を引く。
4. ドラ表示牌を引く。
5. 残り枚数と出やすさを別に評価する。

### 例

`23m` の受けは `1m4m` で最大8枚です。自分が `4m` を1枚持ち、河に `1m` が2枚見えているなら、実際の残り枚数は減ります。

### 例外・補正

見えていない牌でも、他家の手に多く使われていそうな牌は実戦上の価値が下がります。逆に場に安い色の待ちは残り枚数以上にアガリやすいことがあります。

### よくあるミス

- 最大枚数だけで判断する。
- ドラ表示牌を差し引き忘れる。
- 枚数と出やすさを同じものとして扱う。

### 一言ルール

最大枚数から、見えている牌を必ず引く。

## メンツ抜き

### 要約

メンツ抜きは、複雑な形から完成メンツを仮に抜き、残った部分の待ちを調べる方法です。多面待ちやメンチンの待ち探しに有効です。

### 使う局面

テンパイ時や、複雑な数牌の塊があるときに使います。

### 判断基準

- どの完成メンツを抜けるか。
- 抜いた残りが単騎、リャンメン、カンチャン、ペンチャン、シャンポンのどれか。
- 別の抜き方で別の待ちが出ないか。
- 待ちが重複していないか。

### 判断手順

1. まず見える順子や刻子を1つ抜く。
2. 残った形の待ちを読む。
3. 別のメンツの抜き方を試す。
4. 出てきた待ちを一覧化する。
5. 重複を消して実枚数を数える。

### 例

`233445m` は、`234m` を抜く見方と `345m` を抜く見方で残り形が変わります。複数の抜き方を試すことで待ち漏れを減らします。

### 例外・補正

字牌やトイツを含む形では、シャンポンや単騎も忘れずに確認します。鳴いた手では、既に固定されたメンツを動かせない点に注意します。

### よくあるミス

- 最初に見えたメンツだけで待ちを決める。
- 同じ待ちを複数回数える。
- 刻子を固定しすぎて別の待ちを見落とす。

### 一言ルール

複雑な待ちは、メンツを抜く順番を変えて探す。

## メンチンの待ち探し

### 要約

メンチンは、同一色に牌が集中するため待ちが複雑になります。端からメンツを抜く、ヘッド候補を固定する、残り形を見るという手順で整理します。

### 使う局面

清一色や混一色に近い手、同一色の7枚以上の形で待ちを確認するときに使います。

### 判断基準

- 端から順子を抜けるか。
- トイツやアンコを固定するか。
- ヘッド候補はどこか。
- 別の抜き方で待ちが増えるか。
- フリテンや見えている枚数はどうか。

### 判断手順

1. 牌を数順に並べる。
2. 端から順子を抜く。
3. トイツをヘッド候補として固定してみる。
4. 別パターンでメンツを抜く。
5. 待ちを統合し、重複を消す。

### 例

`1122334455667m` のような形は、端から抜く、ヘッドを固定する、連続形として見る、という複数の見方を試します。短時間で読むには、手順を固定することが重要です。

### 例外・補正

メンチンは打点が高い一方、待ちを間違えるリスクがあります。実戦ではフリテン、役の成立、見えている枚数も同時に確認します。

### よくあるミス

- 見た目の広さだけで待ちを断定する。
- ヘッド候補を固定せずに混乱する。
- フリテンを確認しない。

### 一言ルール

メンチンは、端から抜いて、ヘッドを固定して、別解を試す。

## 多面待ちの数え方

### 要約

多面待ちは、候補を列挙したあと重複を消して数えます。枚数だけでなく、良形率、出やすさ、役、打点も含めて評価します。

### 使う局面

テンパイ時の待ち確認、リーチ判断、ダマ判断、待ち変え判断で使います。

### 判断基準

- 待ち候補は何種類あるか。
- 最大枚数は何枚か。
- 見えている牌は何枚か。
- 良形として残るか。
- 出やすい牌か。
- 打点や役に関係するか。

### 判断手順

1. メンツ抜きで候補を出す。
2. 待ち牌を一覧化する。
3. 重複を消す。
4. 見えている枚数を引く。
5. 出やすさと打点で順位をつける。

### 例

`2344556m` のような形では、リャンメン、単騎、シャンポン的な見方が重なることがあります。候補を紙に列挙するつもりで整理します。

### 例外・補正

多面待ちでも高め安めが大きい場合、打点差を考えます。枚数が少ない待ちでも、役牌単騎やドラ単騎など局面上の価値がある場合があります。

### よくあるミス

- 多面待ちを見た目の印象で過大評価する。
- 重複を消さずに枚数を多く数える。
- 高め安めを見落とす。

### 一言ルール

多面待ちは、候補列挙、重複除去、見え枚数差し引きの順に数える。

## 待ちの価値

### 要約

待ちの価値は枚数だけで決まりません。出やすさ、役、打点、リーチ判断、安全度、場況を合わせて評価します。

### 使う局面

リーチするか、ダマにするか、待ち変えするか、鳴いてテンパイを取るか判断するときに使います。

### 判断基準

- 残り枚数が多いか。
- リャンメンなど良形か。
- 場に安い牌か。
- 高め安めの打点差があるか。
- 役ありでダマにできるか。
- 他家の攻撃に耐えられるか。

### 判断手順

1. 待ちの種類と残り枚数を出す。
2. 出やすさを河と副露から見る。
3. 打点と役を確認する。
4. リーチ、ダマ、待ち変えを比較する。
5. 局面目的に合う選択をする。

### 例

`23m` 待ちのリャンメンは枚数面で強いですが、場に `1m4m` が多く見えていれば価値は下がります。逆に単騎でも、場に安い字牌なら選択肢になります。

### 例外・補正

親番、ラス目、オーラス条件、供託、他家の仕掛けで判断は変わります。形式テンパイが重要な局面では、待ちの質よりテンパイ維持を優先することがあります。

### よくあるミス

- リャンメンなら常に強いと考える。
- 枚数だけ見て打点や役を見ない。
- 待ち変えでシャンテンを戻すリスクを軽く見る。

### 一言ルール

待ちは枚数、出やすさ、打点を分けて評価する。

## 判断チェックリスト

- 有効牌の種類と枚数を分けたか。
- 見えている牌を差し引いたか。
- メンツ抜きを複数パターン試したか。
- 待ちの重複を消したか。
- 枚数だけでなく出やすさと打点を見たか。
