# 待ちの探し方と数え方

この章で判断できるようになること:

- 有効牌の種類と枚数を分けて数えられる。
- 見えている牌を差し引いて実枚数を評価できる。
- メンツ抜きで複雑な待ちを探せる。
- メンチンや多面待ちの見落としを減らせる。

PDF参照: 第5章は p.73-p.84。有効牌の種類と枚数は p.74-p.77、メンツ抜きは p.78-p.79、メンチンの待ち探しは p.80-p.83。

## 有効牌の種類と枚数

### 要約

有効牌は、手牌を前進させる牌である。種類数と枚数は別物で、同じ3種類受けでも場に見えている枚数で実際の価値は変わる。

### 使う局面

- 何切るで候補打牌を比較する。
- 1シャンテンでテンパイ受け入れを数える。
- 多面待ちや複合形の価値を確認する。

### 判断基準

- 前進する牌の種類。
- 各種類の残り枚数。
- 自分の手牌、河、ドラ表示牌、副露で見えている枚数。
- 前進後の待ちの質。

### 判断手順

1. 候補打牌を決める。
2. その打牌後にシャンテンが進む牌を列挙する。
3. 各牌の最大4枚から見えている枚数を引く。
4. 種類数と実枚数を別々に記録する。
5. 受け入れ後の最終形を評価する。

### 例

再構成例:

`23m45p789s55z` の `23m` は `1m/4m` が有効牌だが、`1m` が3枚見えていれば実質はほぼ `4m` 受けになる。

PDF p.74-p.77 に有効牌の種類・枚数を比較する例がある。表の細部は `[要確認]`。

### 例外・補正

- 有効牌でも役なしテンパイになる牌は価値が下がる。
- 高打点に変わる牌は、枚数が少なくても価値がある。
- 鳴ける牌は、自摸限定の牌より速度価値が高い。

### よくあるミス

- 種類数だけで判断する。
- 自分で使っている牌を差し引かない。
- 見えている牌を無視する。

### 一言ルール

有効牌は、種類と残り枚数を分けて数える。

## メンツ抜き

### 要約

メンツ抜きは、完成メンツを仮に取り除き、残りの形から待ちや受け入れを探す方法である。複雑な形ほど、複数の抜き方を試す必要がある。

### 使う局面

- テンパイ形の待ちがすぐ分からない。
- 一色手や連続形が長い。
- 多面待ちを見落としたくない。

### 判断基準

- どの3枚を順子・刻子として抜けるか。
- 抜いた後に雀頭が残るか。
- 別のメンツ抜きで別の待ちが出ないか。
- 同じ待ちを重複して数えていないか。

### 判断手順

1. 明らかなメンツを1つ抜く。
2. 残りを雀頭＋ターツに分解する。
3. 別のメンツ候補も抜いてみる。
4. すべての待ちを統合する。
5. フリテン・役なし・見え枚数を確認する。

### 例

PDF p.78-p.79 にメンツ抜きの例がある。牌姿は小さく、厳密な転記は `[要確認]`。

### 例外・補正

- 七対子はメンツ抜きではなくトイツ単位で見る。
- 国士無双は別手順で数える。
- 副露手では見えているメンツを固定して考える。

### よくあるミス

- 最初に見えたメンツ抜きだけで待ちを決める。
- ヘッド候補を固定しすぎる。
- 重複待ちを二重に数える。

### 一言ルール

メンツ抜きは、1通りではなく複数通り試す。

## メンチンの待ち探し

### 要約

メンチンは同一色の牌が密集するため、待ちが多面化しやすい。数字の連なりを区切り、メンツ抜き、ヘッド仮置き、端からの分解を順番に試すと見落としにくい。

### 使う局面

- 清一色・混一色のテンパイ。
- 同一色で7枚以上の複合形がある。
- 待ちが何種類あるか分からない。

### 判断基準

- 数字の連続範囲。
- トイツになり得る数字。
- 端から順子を抜いた場合。
- 中央から順子を抜いた場合。
- フリテンの有無。

### 判断手順

1. 同一色の牌を数字順に並べる。
2. 端から順子を抜く。
3. 中央のトイツをヘッド仮置きする。
4. 別の抜き方を試す。
5. 出た待ちを統合し、見え枚数を差し引く。

### 例

再構成例:

`1112345678999m` のような形は、刻子、順子、ヘッドの取り方が複数ある。端からだけでなく中央からも分解して待ちを探す。

PDF p.80-p.83 にメンチン待ち探しの例がある。牌姿の正確な転記は `[要確認]`。

### 例外・補正

- 高打点確定でも、フリテンならアガリにくさを考慮する。
- 役あり・役なしの差がある待ちは同じ価値ではない。
- 場に多く見えている待ちは実枚数が下がる。

### よくあるミス

- 連続形を一方向からだけ分解する。
- 待ちの種類は分かったが枚数を数えない。
- フリテンを見落とす。

### 一言ルール

メンチンは、端・中央・ヘッド仮置きの3方向から見る。

## 待ちの価値

### 要約

待ちの価値は枚数だけで決まらない。出やすさ、役の有無、打点、リーチ判断、場況、鳴きやすさまで含めて評価する。

### 使う局面

- 良形テンパイと高打点悪形テンパイの比較。
- リーチするか、ダマにするか迷う。
- 待ち替えをするか迷う。

### 判断基準

- 残り枚数。
- 場に安いか高いか。
- 役ありか役なしか。
- 打点差。
- 自分の順位・親番・巡目。

### 判断手順

1. 待ちの種類を出す。
2. 残り枚数を数える。
3. 出やすさを河から補正する。
4. 打点と役を確認する。
5. リーチ・ダマ・待ち替えを比較する。

### 例

PDF p.55-p.56 に待ちの価値比較がある。グラフや表の細部は `[要確認]`。

### 例外・補正

- 終盤は枚数より安全度・押し引きが重要になる。
- 親の高打点手は悪形でも押す価値がある。
- オーラス条件では必要打点が最優先になる。

### よくあるミス

- リャンメンなら常にリーチと決める。
- 枚数だけで待ち替えする。
- 場に見えている枚数を無視する。

### 一言ルール

待ちは枚数、出やすさ、打点、役で評価する。
