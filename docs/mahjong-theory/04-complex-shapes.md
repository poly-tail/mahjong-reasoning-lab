# 複合形

この章で判断できるようになること:

- 複合形を暗記ではなく分解して評価できる。
- リャンカン、4連形、中ぶくれ、亜リャンメンなどの価値を比較できる。
- 多面待ちをメンツ抜きや形分解で探せる。
- 複合形を残す場面と崩す場面を判断できる。

PDF参照: 第4章複合形は p.42-p.72。リャンカン p.43-p.47、4連形 p.48-p.49、中ぶくれ p.50-p.52、亜リャンメン p.53-p.54、待ちの価値 p.55-p.56、並びトイツ p.58、飛びトイツ p.59-p.60、リャンメンカンチャン p.61-p.63、多面待ち p.64-p.65、エントツ形 p.67、イーペーコー含み p.68-p.70、ウイング形 p.71-p.72。

## リャンカン

### 要約

リャンカンは、2つのカンチャンが重なった形で、単独カンチャンより受け入れや変化が強い。良形変化や一盃口、三色などの芽も含むことがある。

### 使う局面

- `135m`、`246p` のように間が2つ空いた3枚形がある。
- 弱ターツとリャンカンのどちらを残すか迷う。
- 打点変化を残したい序盤。

### 判断基準

- 受け入れが2種あるか。
- 内側に寄っているか。
- リャンメン化する牌があるか。
- 役やドラに絡むか。
- 1シャンテンで悪形テンパイをどれだけ避けられるか。

### 判断手順

1. 2つのカンチャンに分解する。
2. 受け入れ牌を列挙する。
3. 良形変化と打点変化を確認する。
4. 単独カンチャンやペンチャンと比較する。
5. 1シャンテンではテンパイ枚数を優先する。

### 例

再構成例:

`246m` は `3m/5m` の2種受けを持つ。`3m` を引けば `234m`、`5m` を引けば `456m` になり、単独カンチャンより安定する。

PDF p.43-p.47 にリャンカンの価値と渡りの例がある。牌姿の細部は `[要確認]`。

### 例外・補正

- 片方の受けが場に多く見えていると価値が下がる。
- 既に良形ブロックが十分なら、リャンカンでも整理候補になる。
- 鳴き手では、チーできる方向が多いほど価値が上がる。

### よくあるミス

- リャンカンを単独カンチャンと同じ扱いにする。
- 役絡みのリャンカンを早く崩す。
- 受け入れ2種のうち片方が重複していることを見落とす。

### 一言ルール

リャンカンは悪形2つではなく、受けが2方向ある保留形。

## 4連形

### 要約

4連形は、連続した4枚の数牌で、リャンメン2つや複数の変化を含む強い形である。固定しすぎず、周辺牌のツモで伸びる価値を見る。

### 使う局面

- `3456m`、`4567p` のような4枚連続形がある。
- 5ブロックが足りず、形の伸びを残したい。
- リャンメン固定するか、浮かせるか迷う。

### 判断基準

- 両端の受けが残っているか。
- 中央寄りでタンヤオや赤ドラに絡むか。
- ヘッド候補を兼ねるか。
- ほかに強いブロックが十分あるか。

### 判断手順

1. 4連形を2つのリャンメンに分解する。
2. 端引き、中引き、重なりの変化を見る。
3. ブロック不足なら残す。
4. ブロック過多なら、ほかの弱ターツと比較する。

### 例

再構成例:

`3456m` は `34m` と `56m` の両方を含む。`2m/7m` だけでなく、`3m/6m` 重なりも形の変化に関わる。

PDF p.48-p.49 に4連形の例がある。牌姿は `[要確認]`。

### 例外・補正

- 端寄りの4連形はタンヤオ価値が下がる。
- 既に5ブロックが強いなら、余剰部分を整理することがある。

### よくあるミス

- すぐリャンメン固定して4連形の変化を消す。
- 4連形を1ブロックとしてだけ数え、余剰価値を見落とす。

### 一言ルール

4連形は、固定前に2つのリャンメンとして見る。

## 中ぶくれ

### 要約

中ぶくれは、中央牌が重なった連続形で、メンツ・ヘッド・良形変化を同時に持つ。単純なリャンメンより柔軟で、序盤ほど残す価値が高い。

### 使う局面

- `3445m`、`4556p` のような形がある。
- ヘッド候補が不安定。
- 5ブロックが未確定で、形の伸びを見たい。

### 判断基準

- ヘッド候補を兼ねるか。
- リャンメン変化が複数あるか。
- 赤ドラやタンヤオと相性がよいか。
- 1シャンテンで固定した方が受け入れが増えるか。

### 判断手順

1. 中ぶくれをリャンメンとトイツに分解する。
2. ヘッド候補が必要か確認する。
3. 周辺牌ツモの変化を列挙する。
4. ブロック過多なら、弱ターツと比較する。

### 例

PDF p.50-p.52 に中ぶくれの例がある。画像一覧では牌姿細部が不明のため `[要確認]`。

### 例外・補正

- 1シャンテンでは、中ぶくれを固定して受け入れ最大化することがある。
- 外側牌が多く見えていると変化価値は下がる。

### よくあるミス

- 中ぶくれを単なるトイツとして扱う。
- ヘッドレスで中ぶくれを切ってしまう。

### 一言ルール

中ぶくれはメンツにもヘッドにもなる柔軟形。

## 亜リャンメン

### 要約

亜リャンメンは、リャンメンにトイツ要素が絡んだ形で、受け入れの見た目と実際の価値がずれやすい。ヘッド候補を兼ねるため、ヘッド数によって評価が変わる。

### 使う局面

- `2334m` のようにトイツと連続形が重なる。
- ヘッド固定かメンツ固定か迷う。
- 待ちが多面化しそうな形。

### 判断基準

- ヘッド候補がほかにあるか。
- 受け入れが重複していないか。
- 待ちになった時にフリテンや片アガリがないか。
- 打点や役に絡むか。

### 判断手順

1. トイツ部分とリャンメン部分に分ける。
2. ヘッドとして使う場合を考える。
3. メンツとして使う場合を考える。
4. 受け入れと待ちを数える。

### 例

PDF p.53-p.54 に亜リャンメンの例がある。牌姿は `[要確認]`。

### 例外・補正

- ヘッドレスなら価値が上がる。
- 2ヘッド以上なら固定しやすい。
- 鳴き手ではポン材としても評価する。

### よくあるミス

- 見た目のリャンメンだけで判断する。
- ヘッド候補としての価値を見落とす。

### 一言ルール

亜リャンメンは、ヘッド数で価値が変わる。

## 並びトイツ・飛びトイツ

### 要約

並びトイツや飛びトイツは、複数のトイツが近い位置にある形で、ヘッド候補、暗刻化、連続形変化を同時に見る。通常手、七対子、鳴き手で評価が変わる。

### 使う局面

- `33m44m` のような並びトイツ。
- `33m55m` のような飛びトイツ。
- 3ヘッド以上でトイツ整理に迷う。

### 判断基準

- 周辺牌でメンツ化しやすいか。
- 七対子を見るか。
- 鳴きやすい牌か。
- ヘッド候補が過剰か不足か。

### 判断手順

1. トイツ数を数える。
2. 通常手と七対子の距離を比較する。
3. 周辺変化でリャンメン化するか見る。
4. 鳴き前提ならポン材価値を足す。

### 例

PDF p.58 に並びトイツ、p.59-p.60 に飛びトイツの例がある。牌姿は `[要確認]`。

### 例外・補正

- 役牌トイツは並び・飛びの形より役価値が重要。
- ドラトイツは通常手でも残す価値が高い。

### よくあるミス

- トイツが多いだけで七対子へ寄せる。
- 並びトイツのメンツ化を見落とす。

### 一言ルール

近いトイツは、通常手・七対子・鳴きを同時に比較する。

## リャンメンカンチャン

### 要約

リャンメンカンチャンは、良形受けとカンチャン受けが同居する複合形である。単純にリャンメン固定すると、カンチャン側の受けや変化を失うことがある。

### 使う局面

- `2346m`、`2456p` のような形。
- 良形を固定するか、広く構えるか迷う。
- 1シャンテンで受け入れ枚数を比較する。

### 判断基準

- リャンメン側とカンチャン側の受け入れ。
- カンチャン側が役やドラに絡むか。
- ヘッド候補があるか。
- 固定後のテンパイ枚数。

### 判断手順

1. リャンメン部分を抜き出す。
2. カンチャン部分を抜き出す。
3. 重複受けを確認する。
4. 固定前後でテンパイ枚数を比較する。

### 例

PDF p.61-p.63 にリャンメンカンチャンの例がある。牌姿は `[要確認]`。

### 例外・補正

- 1シャンテンでは広さ優先で固定しないことがある。
- 打点確定のためにあえて固定することもある。

### よくあるミス

- リャンメンだけを見て、複合受けを捨てる。
- カンチャン受けの打点価値を見落とす。

### 一言ルール

リャンメンカンチャンは、良形固定前に受けの総量を見る。

## 多面待ち

### 要約

多面待ちは、複数のメンツ分解が重なることで発生する。暗記よりも、メンツを抜く、トイツを仮置きする、連続形を分解する手順で探すと見落としにくい。

### 使う局面

- メンチンや複雑な一色手。
- 7枚以上の連続形。
- 待ちが複数ありそうなテンパイ形。

### 判断基準

- どの3枚をメンツとして抜けるか。
- どの2枚をヘッドとして置けるか。
- 同じ待ちを重複して数えていないか。
- 場に見えている枚数。

### 判断手順

1. 完成メンツを仮に抜く。
2. 残りをヘッド＋ターツに分ける。
3. 別のメンツ抜きも試す。
4. 出てきた待ちを統合する。
5. 見えている牌を差し引く。

### 例

PDF p.64-p.65 に7枚形の多面待ちと多面待ちの法則がある。牌姿一覧が小さいため、個別牌姿は `[要確認]`。

### 例外・補正

- フリテン、片アガリ、役なしは待ちの価値を下げる。
- 高打点なら待ち枚数が少なくても押せることがある。

### よくあるミス

- 1通りのメンツ抜きだけで待ちを確定する。
- 同じ牌を重複して数える。
- 見えている牌を差し引かない。

### 一言ルール

多面待ちは、メンツ抜きを複数回試して統合する。

## イーペーコー含み・ウイング形

### 要約

イーペーコー含みやウイング形は、打点と受け入れが絡む複合形である。形を崩すと枚数だけでなく役の可能性も失うため、速度と打点を分けて評価する。

### 使う局面

- 同じ順子が重なりそうな形。
- 8枚形・9枚形の広い連続形。
- 一色手や三色、一盃口を見たい手。

### 判断基準

- 役が確定するか、ただの可能性か。
- 受け入れ枚数がどれだけ増減するか。
- リーチ時の打点差。
- 鳴くと役価値が消えるか。

### 判断手順

1. 役になる受けと、速度だけの受けを分ける。
2. 形を崩した時に失う受けを列挙する。
3. 打点が必要な局面か確認する。
4. 鳴き前提なら一盃口価値を下げる。

### 例

PDF p.68-p.70 にイーペーコー含み、p.71-p.72 にウイング形の例がある。牌姿は `[要確認]`。

### 例外・補正

- 一盃口はメンゼン役なので、鳴き前提では価値が下がる。
- ウイング形でも1シャンテンでは固定した方が広い場合がある。

### よくあるミス

- 役の可能性だけで速度を大きく落とす。
- 鳴いた後に消える役を過大評価する。

### 一言ルール

複合形は、速度の受けと打点の受けを分けて見る。
