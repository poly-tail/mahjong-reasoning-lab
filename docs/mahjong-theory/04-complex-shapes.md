# 複合形

この章で判断できるようになること: 複合形を暗記だけで処理せず、メンツ候補、ヘッド候補、ターツ、フォロー牌に分解して評価できるようにします。

## リャンカン

### 要約

リャンカンは、カンチャンが2つ重なった形です。テンパイまでの受け入れは広く見えますが、最終形ではカンチャン待ちになりやすいため、リャンメンの下位として扱います。

### 使う局面

カンチャンが重なった3枚形を残すか、リャンメンやほかの複合形を優先するか迷うときに使います。

### 判断基準

- 埋まった後の最終形が良形か。
- 三色、タンヤオ、ドラ受けに絡むか。
- ヘッド候補が足りているか。
- 他ブロックが強いか弱いか。
- 鳴きで処理できるか。

### 判断手順

1. リャンカンの2つのカンチャン受けを確認する。
2. どちらが埋まっても残る形を確認する。
3. 役やドラへの関与を補正する。
4. リャンメンや4連形と比較する。

### 例

`246m345p78s55z67p9s` の `246m` はリャンカンです。`3m` または `5m` で進みますが、最終的に悪形が残りやすい点を見ます。

### 例外・補正

三色やタンヤオに強く絡むとき、または鳴ける手では価値が上がります。ヘッドがない手で、リャンカン周辺がヘッドを作る可能性を持つ場合も評価が変わります。

### よくあるミス

- 2種類受けだからリャンメンと同じ強さだと考える。
- 埋まった後の最終待ちを見ない。
- 役や鳴きで価値が変わる場面を無視する。

### 一言ルール

リャンカンは受けは広いが、最終形は悪形になりやすい。

## 4連形

### 要約

4連形は、連続した4枚の数牌形で、リャンメン、カンチャン、ヘッド候補など複数の役割を持ちます。ブロック不足や序盤では価値が高い形です。

### 使う局面

序盤から2シャンテン以前で、孤立牌や弱ターツと比較してどの形を残すか決めるときに使います。

### 判断基準

- ブロック不足か。
- ヘッド候補が足りているか。
- 周辺牌のくっつきで良形が増えるか。
- 5ブロックが既に強くそろっているか。
- 役やドラに絡むか。

### 判断手順

1. 4連形を複数の分解パターンで見る。
2. リャンメン候補、ヘッド候補、くっつき候補を確認する。
3. ほかのブロックの強さと比較する。
4. 不要になったら端から固定または切り出す。

### 例

`3456m45p78s33z12p9s` の `3456m` は4連形です。`25m`、`47m` 周辺の変化があり、序盤は孤立牌より残したい候補です。

### 例外・補正

5ブロックが十分強く、4連形が余剰になっている場合は固定して切り出します。終盤は変化より危険度を優先します。

### よくあるミス

- 4連形をただのリャンメン1つとして固定する。
- ブロック不足なのに変化の多い4連形を切る。
- 余剰になった後も形に固執する。

### 一言ルール

4連形は変化の多い強い素材。序盤は簡単に切らない。

## 中ぶくれ

### 要約

中ぶくれは、中央の牌が重なった4枚形で、ヘッド候補とメンツ候補を同時に持ちます。ヘッドレスやブロック不足で価値が上がります。

### 使う局面

ヘッド候補が足りない手、またはメンツ候補と雀頭候補を同時に見たい手で使います。

### 判断基準

- ヘッドが足りているか。
- 中央の重なりが雀頭として使えるか。
- 周辺牌でリャンメンや多面形に変化するか。
- 余剰牌として扱ってよいほど5ブロックが強いか。

### 判断手順

1. 中ぶくれをヘッド候補として見る。
2. メンツ候補としての分解も確認する。
3. ヘッド数とブロック数で価値を決める。
4. 固定するなら、消える変化を確認する。

### 例

`3445m456p78s12z7p9s` の `3445m` は中ぶくれです。`44m` をヘッドにするか、周辺変化で良形化するかを全体のヘッド数で判断します。

### 例外・補正

ヘッドが既に複数ある場合は価値が下がります。タンヤオやピンフに絡む場合、中央牌の価値は上がります。

### よくあるミス

- 中ぶくれを単なる余剰牌込みの形と見る。
- ヘッドレスなのに中ぶくれを早く崩す。
- 3ヘッド以上の手で中ぶくれを過大評価する。

### 一言ルール

中ぶくれは、ヘッドと変化を同時に持つ。

## 亜リャンメン

### 要約

亜リャンメンは、リャンメンとヘッド候補が重なった形です。待ちの強さだけでなく、ヘッドとして使う価値も評価します。

### 使う局面

トイツを含む連続形があり、メンツ利用かヘッド利用かを選ぶときに使います。

### 判断基準

- ヘッド候補が足りているか。
- 亜リャンメンを崩すと受け入れがどれだけ減るか。
- 良形テンパイに向かうか。
- 役やドラに絡むか。

### 判断手順

1. トイツ部分をヘッド候補として見る。
2. リャンメン部分をメンツ候補として見る。
3. 全体のヘッド数でどちらの価値が高いか決める。
4. 固定する場合は消える受け入れを確認する。

### 例

`334m456p78s22z67p9m` の `334m` は亜リャンメン的に扱えます。ヘッドが足りないなら `33m` の価値が高く、ヘッドが十分ならメンツ化を見ます。

### 例外・補正

役牌トイツやドラトイツが別にあると、亜リャンメンのヘッド価値は下がります。ピンフを見たい手では、ヘッド固定が役に影響することがあります。

### よくあるミス

- 亜リャンメンを普通のリャンメンと同じように扱う。
- ヘッド候補の数を見ずに固定する。
- ヘッドレス時の価値を見落とす。

### 一言ルール

亜リャンメンは、リャンメンとヘッドの二役で見る。

## 並びトイツ

### 要約

並びトイツは、隣り合うトイツがメンツや多面形に変化する形です。通常手、七対子、対々和、鳴き手の分岐として評価します。

### 使う局面

トイツが複数あり、隣接している形を崩すか残すか判断するときに使います。

### 判断基準

- 通常手でメンツ化しやすいか。
- 七対子や対々和が近いか。
- 鳴き手でポン材として価値があるか。
- 3ヘッド以上になって重くなっていないか。

### 判断手順

1. トイツ数を数える。
2. 並びトイツを通常手に分解する。
3. 対子手ルートも比較する。
4. メンゼン手か鳴き手かで残す価値を変える。

### 例

`3344m456p78s55z9p` は並びトイツを含みます。メンゼンでは重さに注意し、鳴き手ならポン材としての速度を見ます。

### 例外・補正

役牌やドラのトイツが別にある場合、数牌の並びトイツを崩して通常手に戻す価値が上がることがあります。

### よくあるミス

- 並びトイツをただの2ヘッドとしてしか見ない。
- 鳴き手でのポン材価値を過小評価する。
- 七対子ルートを考えずに崩す。

### 一言ルール

並びトイツは、通常手と対子手の両方で見る。

## 飛びトイツ

### 要約

飛びトイツは、1つ間を空けたトイツ同士の形です。中間牌を引くと強い複合形になる一方、そのままでは重くなりやすいです。

### 使う局面

トイツが飛び形で並び、通常手に使うか、対子手に寄せるか判断するときに使います。

### 判断基準

- 中間牌を引いたときの変化が強いか。
- ヘッド候補が多すぎないか。
- 七対子や対々和が現実的か。
- 鳴けるトイツか。

### 判断手順

1. 飛びトイツの中間牌を確認する。
2. 中間牌を引いた後の形を想定する。
3. トイツ数が多すぎる場合は通常手へのほぐしを検討する。
4. 鳴き手ならポン材価値を加点する。

### 例

`3355m456p78s22z9p` は飛びトイツを含みます。`4m` を引くと形が強くなりますが、3ヘッド以上なら重さも見ます。

### 例外・補正

ドラトイツや役牌トイツが絡むと対子手寄せの価値が上がります。メンゼンの平和系では重くなりやすいため、ほぐしを検討します。

### よくあるミス

- 中間牌の変化だけを見て、現在の重さを見ない。
- 対子手が遠いのにトイツを残しすぎる。
- 鳴き手とメンゼン手の価値差を見ない。

### 一言ルール

飛びトイツは中間牌の変化と現在の重さを両方見る。

## リャンメンカンチャン

### 要約

リャンメンカンチャンは、リャンメンとカンチャンが重なった形で、受け入れが広く形を保ちやすい複合形です。固定場所を間違えると強さを失います。

### 使う局面

複合ターツの中でどの部分を固定するか、フォロー牌を外すかを判断するときに使います。

### 判断基準

- どの牌を切るとリャンメンが残るか。
- カンチャン受けを残す価値があるか。
- 5ブロックがそろっているか。
- ヘッド候補が足りているか。
- 役やドラに絡むか。

### 判断手順

1. リャンメン部分とカンチャン部分に分解する。
2. 各打牌で残る受け入れを確認する。
3. 1シャンテンならテンパイ受け入れを重視する。
4. 2シャンテン以前なら変化価値も見る。

### 例

`2346m456p78s55z12p` の `2346m` は、`23m` リャンメンと `46m` カンチャンの要素があります。どこを固定するかで残る受けが変わります。

### 例外・補正

ドラ周辺や三色に絡むカンチャン受けは残す価値があります。終盤は広さより安全な切り出しを優先することがあります。

### よくあるミス

- 強い複合形を早く固定しすぎる。
- 5ブロックが足りないのにフォローを外す。
- 1シャンテンでも変化を追いすぎる。

### 一言ルール

リャンメンカンチャンは、固定前に残る受けを確認する。

## 多面待ち

### 要約

多面待ちは、複数のメンツ候補やヘッド候補が重なった待ちです。丸暗記ではなく、メンツ抜きで分解して待ちを列挙します。

### 使う局面

テンパイ時、またはテンパイに近い複雑形で、待ちを正確に数える必要があるときに使います。

### 判断基準

- 完成メンツとして抜ける部分はどこか。
- 残りの形が単騎、リャンメン、カンチャン、シャンポンのどれか。
- 同じ待ちを二重に数えていないか。
- 見えている枚数を差し引いたか。

### 判断手順

1. メンツを抜く。
2. 残り形の待ちを列挙する。
3. 別のメンツ抜きパターンを試す。
4. 待ちの重複を消す。
5. 見えている牌を差し引く。

### 例

`233445m` のような短い形でも、メンツの抜き方で待ちの見え方が変わります。`234m` を抜く、`345m` を抜くなど複数パターンを試します。

### 例外・補正

枚数が多い待ちでも、役なしや打点不足なら価値が下がります。逆に枚数が少なくても、出やすい牌や高打点なら選ぶ価値があります。

### よくあるミス

- 見た目だけで待ちを決める。
- 同じ待ちを重複して数える。
- 見えている枚数を差し引かない。

### 一言ルール

多面待ちは、メンツを抜いて重複を消す。

## エントツ形

### 要約

エントツ形は、トイツを含む縦の要素と順子候補が重なった複合形です。待ちや変化を数えるときは、ヘッド利用とメンツ利用を分けます。

### 使う局面

トイツを含む数牌の塊で、待ちが直感的に分かりにくいときに使います。

### 判断基準

- トイツ部分をヘッドにするか。
- 周辺牌で順子が作れるか。
- 別のメンツ抜きで待ちが増えるか。
- ヘッド候補が全体で足りているか。

### 判断手順

1. トイツ部分を固定して待ちを見る。
2. トイツをメンツ素材として使う分解も見る。
3. 待ちの重複を消す。
4. 全体のヘッド数で価値を補正する。

### 例

`22234m` のような形では、`222m` をメンツに見るか、`22m` をヘッドに見るかで受けの見え方が変わります。

### 例外・補正

役やドラが絡む場合、待ちの広さより打点を優先することがあります。鳴き手ではポン後の形も確認します。

### よくあるミス

- アンコ部分を常に固定して、別の待ちを見落とす。
- ヘッド候補としての価値を見ない。
- 鳴いた後の形を確認しない。

### 一言ルール

エントツ形は、トイツ固定とメンツ固定を両方試す。

## イーペーコー含み

### 要約

イーペーコー含みの形は、役を残す価値と受け入れ枚数の比較になります。打点が必要な場面では価値が上がりますが、速度を大きく失うなら固執しません。

### 使う局面

同種同順の可能性があり、役を追うか受け入れを広げるかを判断するときに使います。

### 判断基準

- イーペーコーが確定または高確率か。
- 受け入れをどれだけ失うか。
- 打点が必要な局面か。
- メンゼンを維持できるか。
- ピンフやタンヤオと両立するか。

### 判断手順

1. イーペーコー候補を確認する。
2. 役を残す打牌と最大受け打牌を比較する。
3. 打点状況と巡目で補正する。
4. 鳴く予定があるなら価値を下げる。

### 例

`223344m456p78s55z` はイーペーコー要素があります。メンゼン打点を見たいなら残す価値がありますが、鳴き手にするなら役としての価値は消えます。

### 例外・補正

トップ目で局消化したい場合は速度優先です。ラス目や打点が必要な親番では、多少の受け入れ減を許容することがあります。

### よくあるミス

- イーペーコーに固執して速度を大きく落とす。
- 鳴く予定なのにメンゼン役を過大評価する。
- 役を残した後の待ちが悪いことを見落とす。

### 一言ルール

イーペーコーは嬉しいが、速度を大きく捨ててまで追わない。

## ウイング形

### 要約

ウイング形は、中心の連続形に左右のフォローがついた広い複合形です。多面待ちや良形変化につながるため、分解して残す価値を判断します。

### 使う局面

数牌の塊が大きく、どの部分を固定すべきか迷う序盤から中盤で使います。

### 判断基準

- 左右どちらの受けが強いか。
- ヘッド候補を内包しているか。
- 固定すると消える多面変化は何か。
- ブロック数が足りているか。
- 1シャンテンで最大受けを邪魔していないか。

### 判断手順

1. 中心のリャンメンやメンツ候補を探す。
2. 左右のフォロー牌を確認する。
3. ヘッド利用とメンツ利用を分けて見る。
4. 5ブロックが整ったら不要な端から外す。

### 例

`23456m45p78s33z9p` は広い連続形を含みます。序盤は残して変化を見やすく、1シャンテンでは固定して受け入れを確認します。

### 例外・補正

ドラ周辺や役に絡む側のフォローは残す価値が上がります。終盤には広さより安全度が優先されるため、危険な中張牌を抱えすぎないようにします。

### よくあるミス

- 広い形を早く切り分けて変化を失う。
- 大きな塊を残しすぎてブロック数が曖昧になる。
- 1シャンテンでも変化重視のままにする。

### 一言ルール

ウイング形は広く使い、1シャンテンで整理する。

## 判断チェックリスト

- 複合形を複数の分解で見たか。
- ヘッド候補としての価値を確認したか。
- 受け入れ後の最終形を見たか。
- 5ブロックがそろっているか。
- 1シャンテンなら固定後のテンパイ受けを確認したか。
