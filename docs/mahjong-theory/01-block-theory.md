# ブロック理論

この章で判断できるようになること:

- 手牌を `4メンツ1雀頭` に向けてブロック単位で分解できる。
- 5ブロックと6ブロックの違いを説明できる。
- 1シャンテンで受け入れ枚数を最大化すべき理由を判断できる。
- 孤立牌、弱ターツ、複合形を比較して切る順番を決められる。

PDF参照: 5ブロック理論は p.6-p.9、6ブロックは p.10-p.13、1シャンテンピークは p.14。

## 5ブロック理論

### 要約

通常手は `4メンツ1雀頭` の5要素で完成するため、手牌を5つの完成候補にまとめると判断が安定する。余った牌は、現在の受け入れや将来の変化を比較して整理する。

### 使う局面

- 3シャンテンから1シャンテンまでの通常手。
- メンツ候補とヘッド候補がある程度見えている手牌。
- どのターツを残すか、どの孤立牌を切るか迷う局面。

### 判断基準

- 5ブロックがそろっているか。
- 各ブロックがリャンメン、カンチャン、ペンチャン、トイツのどれか。
- ヘッド候補が十分か。
- 余剰牌が、単なる孤立牌か、複合形の一部か。
- 切る牌によって受け入れ枚数と打点変化がどれだけ減るか。

### 判断手順

1. 完成メンツを数える。
2. ターツとトイツをブロックとして数える。
3. 5ブロックを超えるなら、弱いブロックを探す。
4. 5ブロック未満なら、孤立牌や複合形の伸びを残す。
5. 同等なら、内側の牌、ドラ周辺、タンヤオ化しやすい牌を優先する。

### 例

再構成例:

`123m45m79p345s77z` のように、`123m`、`45m`、`79p`、`345s`、`77z` と数えると5ブロックになる。ここでは `79p` が弱いブロックなので、ほかに強い変化牌があるなら整理候補になる。

PDF p.6-p.9 に、5ブロックへ分解して余剰牌を判断する例が複数ある。画像PDFのため牌姿の厳密転記は `[要確認]`。

### 例外・補正

- 6ブロックにして良形変化を広く見る場面がある。
- 高打点の種、ドラ周辺、三色や一通の芽は単純な弱ターツより残す価値がある。
- 守備が必要な局面では、安全牌を持つために効率を落とすことがある。
- 鳴き前提なら、ポン材・チー材の価値が上がる。

### よくあるミス

- 5ブロックがそろっているのに孤立牌を残しすぎる。
- ブロック数だけを見て、各ブロックの強さを見ない。
- 1シャンテンでも将来変化を追いすぎ、テンパイ枚数を減らす。

### 一言ルール

5ブロックがそろったら、余剰牌ではなく弱いブロックを比較する。

## 6ブロック理論

### 要約

6ブロックは、完成候補を一時的に6つ持って変化を見る構えである。序盤や打点の種がある手では有効だが、どこかで5ブロックへ絞らないと手牌が重くなる。

### 使う局面

- 序盤でまだ形が固まりきっていない。
- 複数の弱ターツがあり、どれが伸びるか未確定。
- 一通、三色、タンヤオ、ドラ受けなど打点変化を見たい。
- ヘッド候補が不安定で、トイツを保険として残したい。

### 判断基準

- 追加ブロックが将来の良形化や打点上昇に関与するか。
- 6ブロックのせいで手牌に浮き牌が多すぎないか。
- 1シャンテンに近づいた時に、切る候補が明確か。
- 鳴き前提で、余ったブロックが仕掛けやすいか。

### 判断手順

1. 6つ目のブロックが何を生むか確認する。
2. 6ブロック維持で増える受け入れと、落とすことで得る安定性を比較する。
3. リャンメン化・役絡み・ドラ絡みが薄いブロックを先に落とす。
4. 1シャンテンになる前後で5ブロックへ絞る。

### 例

再構成例:

`234m56m78p24s557z` は、`234m`、`56m`、`78p`、`24s`、`55z`、`7z`周辺の孤立要素をどう扱うかで6ブロック気味になる。序盤なら `24s` の伸びを見る余地があるが、1シャンテンが近いなら弱いカンチャンから落とす。

PDF p.10-p.13 に、6ブロックを維持する例と5ブロックへ落とす例がある。牌姿の細部は `[要確認]`。

### 例外・補正

- 良形ターツが多い6ブロックは、落とす候補が難しい。
- 役牌トイツやドラトイツは、弱そうでも打点・鳴きで価値が高い。
- すでに巡目が深いなら、変化よりテンパイ速度を優先する。

### よくあるミス

- 6ブロックを「広い」と思っていつまでも維持する。
- 弱いターツを落とさず、強い複合形を壊す。
- 受け入れ枚数だけを見て、最終待ちの悪化を見落とす。

### 一言ルール

6ブロックは序盤の保留形、1シャンテン前後では5ブロックへ絞る。

## 1シャンテンピーク理論

### 要約

牌効率では、1シャンテン時のテンパイ受け入れが最も重要になりやすい。2シャンテン以前は変化を見る余地があるが、1シャンテンでは次にテンパイできる枚数と待ちの質が直接速度に結びつく。

### 使う局面

- 1シャンテンで、どのブロックを固定するか迷う。
- 良形テンパイを取りたいが、受け入れ枚数も落としたくない。
- ヘッド固定、メンツ固定、ターツ固定の選択がある。

### 判断基準

- テンパイする牌の種類と枚数。
- テンパイ後の待ちがリャンメンか悪形か。
- 打点が十分か、リーチを打てるか。
- 鳴きでテンパイを取れるか。
- 危険牌を先に処理できるか。

### 判断手順

1. 候補打牌ごとにテンパイ受け入れを数える。
2. 待ちの質を確認する。
3. 打点差、役の有無、リーチ可能性を足す。
4. 巡目が深いほど、変化よりテンパイ枚数を優先する。
5. 迷ったら、テンパイ枚数を大きく損しない打牌を選ぶ。

### 例

再構成例:

`234m456p78s22344z` のような1シャンテンで、ヘッドをどちらに固定するかによってテンパイ枚数が変わる。1シャンテンでは、将来の打点変化より、まずテンパイできる牌の幅を確認する。

PDF p.14 に1シャンテンピークの考え方がある。牌姿は画像一覧では細部不明のため `[要確認]`。

### 例外・補正

- 高打点確定や明確な役ありなら、少し狭くても良形・高打点を選ぶことがある。
- 親番、ラス目、オーラス条件では速度と打点の重みが変わる。
- 安全度が極端に違う候補では、効率だけで決めない。

### よくあるミス

- 1シャンテンで2次変化を追いすぎる。
- テンパイ枚数だけを数え、最終待ちを見ない。
- ヘッド候補を不用意に固定して、受け入れを大きく減らす。

### 一言ルール

1シャンテンは変化よりテンパイ枚数、ただし待ちの質も同時に見る。

## 実戦判断フロー

1. ブロック数を数える。
2. 5ブロック未満なら、孤立牌・複合形の伸びを残す。
3. 5ブロックなら、余剰牌を整理する。
4. 6ブロックなら、弱いブロックを仮決めする。
5. 1シャンテンなら、候補打牌ごとのテンパイ枚数を数える。
6. 打点、役、鳴き、守備、安全度で補正する。
