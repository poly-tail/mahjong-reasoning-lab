# 手組みテクニック

この章で判断できるようになること: 目先の受け入れ枚数だけでなく、2次変化、浮き牌価値、リャンメン固定、内寄せ、何切る作成の観点から手組みを調整できるようにします。

## 浮かせ打ち

### 要約

浮かせ打ちは、すぐにブロックを固定せず、浮き牌のくっつきや変化を期待して残す打ち方です。主に2シャンテン以前の序盤で有効です。

### 使う局面

5ブロックが弱い、ブロック不足、または孤立牌に強いくっつき価値がある局面で使います。

### 判断基準

- 2シャンテン以前か。
- 浮き牌が内側か、ドラ周辺か。
- タンヤオ、ピンフ、三色などに絡むか。
- 既存ブロックが弱いか。
- 安全牌を手放す価値があるか。

### 判断手順

1. ブロック数を数える。
2. 弱いブロックを探す。
3. 浮き牌のくっつき範囲を確認する。
4. 浮かせた後の受け入れと2次変化を比較する。
5. 1シャンテンに近づいたら整理する。

### 例

`23m45p79s456s33z5m` では、`5m` は浮き牌ですが内側でくっつきが強い牌です。2シャンテン以前なら弱い `79s` と比較して残す価値があります。

### 例外・補正

終盤や他家のリーチ後は、浮き牌の変化より安全度が重要です。打点が十分で速度が必要なときは、浮かせず5ブロック固定に寄せます。

### よくあるミス

- 1シャンテンでも浮かせ打ちを続ける。
- 価値の低い孤立牌まで残す。
- 安牌を失うリスクを見ない。

### 一言ルール

浮かせ打ちは、序盤に変化を買う技術。

## 目先の受け入れと2次変化

### 要約

目先の受け入れが多くても、受けた後の形が悪ければ損になることがあります。2シャンテン以前では、次巡以降に良形化する2次変化も評価します。

### 使う局面

2シャンテン以前で、最大受けと変化残しのどちらを選ぶか迷う局面で使います。

### 判断基準

- 現在の受け入れは何枚か。
- 受けた後の1シャンテン形は強いか。
- 2次変化で良形や打点が増えるか。
- 1シャンテンまで近いか遠いか。
- 巡目が早いか遅いか。

### 判断手順

1. 目先の受け入れを数える。
2. 受けた後の形を確認する。
3. 2次変化を列挙する。
4. 1シャンテンなら受け入れ優先、2シャンテン以前なら変化も加点する。
5. 打点と安全度で補正する。

### 例

`24m456p78s33z67p5m` では、`5m` を残すと `34m56m` などの変化があり、単純な目先受けだけでは評価しきれません。

### 例外・補正

親番や終盤では速度が上がり、2次変化の価値は下がります。打点が必要な局面では、2次変化で役やドラ受けが増えるなら価値が上がります。

### よくあるミス

- 目先の枚数だけで正解を決める。
- 2次変化を追いすぎて1シャンテンの受けを狭くする。
- 受けた後の形を確認しない。

### 一言ルール

2シャンテン以前は将来形、1シャンテンはテンパイ効率を重く見る。

## リャンメン固定

### 要約

リャンメンは強い形ですが、安易に固定すると複合形やヘッド候補を失うことがあります。迷ったときの基本はリャンメン固定ですが、序盤は変化を残す余地を見ます。

### 使う局面

複合形の一部にリャンメンがあり、どこを固定するか迷う局面で使います。

### 判断基準

- 5ブロックがそろっているか。
- ヘッド候補が足りているか。
- 固定で消える2次変化は何か。
- 1シャンテンに近いか。
- 打点や役が固定で消えないか。

### 判断手順

1. リャンメン部分を確認する。
2. 固定前後の受け入れを比較する。
3. ヘッド候補や複合形の価値を確認する。
4. 1シャンテンならリャンメン固定を強く見る。
5. 2シャンテン以前なら変化残しも比較する。

### 例

`2345m456p78s33z9p` の `2345m` は `23m` や `45m` のリャンメンを含みます。固定すると分かりやすい一方、4連形の変化を失う点に注意します。

### 例外・補正

ヘッドレスやブロック不足では、リャンメン固定より複合形維持が強いことがあります。終盤は変化より安全な固定を選びやすくなります。

### よくあるミス

- リャンメンが見えた瞬間に固定する。
- ヘッド不足を見落とす。
- 1シャンテンと2シャンテン以前で同じ判断をする。

### 一言ルール

リャンメンは強いが、固定で消える変化を確認する。

## 内寄せ

### 要約

内寄せは、外側の牌より中張牌を残し、くっつきや良形変化を増やす考え方です。序盤では有効ですが、終盤は安全度で補正します。

### 使う局面

孤立牌や浮き牌を比較するとき、または弱ターツを整理するときに使います。

### 判断基準

- 中張牌でくっつきが多いか。
- タンヤオやピンフに向かうか。
- ドラ周辺か。
- 端牌や字牌に役・安全度があるか。
- 巡目が早いか遅いか。

### 判断手順

1. 孤立牌を内側と外側で分類する。
2. くっつき範囲を比較する。
3. 役、ドラ、安全度を補正する。
4. 序盤は内寄せ、中盤以降は危険度を強く見る。

### 例

`23m45p78s33z5p1s9m` では、`5p` は内側で変化が多く、`1s` や `9m` より残したい候補です。ただし役牌や安全牌の価値がある場合は別です。

### 例外・補正

字牌が役牌、端牌が安全牌、外側がドラ周辺の場合は内寄せだけでは決めません。終盤の中張牌は危険になりやすいため、早めに処理する判断もあります。

### よくあるミス

- 内側なら何でも残す。
- 安全牌の価値を無視する。
- 鳴きや役の都合で外側が必要な場面を見落とす。

### 一言ルール

序盤は内寄せ、終盤は安全度で補正する。

## 何切るの作り方

### 要約

良い何切る問題は、単なる受け入れ枚数比較ではなく、ブロック数、ヘッド数、弱ターツ、複合形、打点、鳴き、場況の差を問います。

### 使う局面

学習用の問題を作るとき、自分の実戦譜を振り返るとき、判断軸を整理したいときに使います。

### 判断基準

- 争点が1つ以上あるか。
- 打牌候補ごとのメリットとデメリットが説明できるか。
- 受け入れ、変化、打点、鳴き、安全度のどれを問う問題か。
- 条件を変えると答えが変わるか。
- 元の牌姿をそのまま暗記する問題になっていないか。

### 判断手順

1. 牌姿を作る。
2. 争点を決める。
3. 打牌候補を2から4個に絞る。
4. それぞれの評価軸を列挙する。
5. 巡目、ドラ、場況を足して答えの変化を見る。

### 例

`23m45p79s456s33z5m` を使い、「弱ターツを残すか、浮き牌を残すか」を問う問題を作れます。見るべき観点は、ブロック数、`5m` のくっつき、`79s` の弱さです。

### 例外・補正

実戦譜から作る場合は、結果論ではなく打牌時点の情報だけを使います。正解を1つに固定せず、局面条件で変わる範囲も残します。

### よくあるミス

- 受け入れ枚数だけの問題にする。
- 場況や巡目を書かず、実戦判断にならない。
- 結果論で正解を決める。

### 一言ルール

良い何切るは、答えより判断軸を問う。

## 判断チェックリスト

- 目先の受け入れと受けた後の形を分けたか。
- 2次変化を追う局面か確認したか。
- リャンメン固定で消える変化を見たか。
- 内寄せを安全度で補正したか。
- 何切るでは争点を明確にしたか。
