# 手組みテクニック

この章で判断できるようになること:

- 浮かせ打ちで次巡以降の変化を残す理由を説明できる。
- 目先の受け入れと2次変化を分けて評価できる。
- リャンメン固定や内寄せを使う場面を判断できる。
- 何切る問題を自作し、判断基準を検証できる。

PDF参照: 第6章テクニックは p.85-p.92。浮かせ打ち p.86、目先の受け入れと2次変化 p.87-p.88、リャンメン固定 p.89、亜リャンメン切り p.90、内寄せ p.91、何切る作成 p.92。

## 浮かせ打ち

### 要約

浮かせ打ちは、ブロックを完全固定せず、孤立牌や余剰牌を残して次巡以降の変化を拾う打ち方である。序盤ほど価値が高く、1シャンテンでは使いすぎに注意する。

### 使う局面

- 5ブロックがまだ弱い。
- 良形変化や打点変化を見たい。
- 孤立牌が内側、ドラ周辺、役絡み。

### 判断基準

- 浮かせる牌が何に変化するか。
- 現在の受け入れをどれだけ失うか。
- 巡目が早いか。
- 打点上昇や役の芽があるか。

### 判断手順

1. 固定した場合の受け入れを確認する。
2. 浮かせた場合の2次変化を列挙する。
3. 受け入れ減と変化価値を比較する。
4. 1シャンテンではテンパイ枚数を優先する。

### 例

PDF p.86 に浮かせ打ちの例がある。牌姿は `[要確認]`。

### 例外・補正

- 巡目が深い時は浮かせる余裕が少ない。
- 安全牌を持つ必要がある時は浮かせ牌を残せないことがある。
- 鳴き手では、浮かせ牌がチー・ポンに役立つかを見る。

### よくあるミス

- 変化を見すぎてテンパイ速度を落とす。
- 何に変化するか説明できない孤立牌を残す。

### 一言ルール

浮かせるなら、次に嬉しいツモを言える牌だけ残す。

## 目先の受け入れと2次変化

### 要約

目先の受け入れは次に前進する牌、2次変化はさらに次巡以降に形が良くなる牌である。序盤は2次変化を重く見て、1シャンテンでは目先の受け入れを重く見る。

### 使う局面

- 受け入れ枚数は多いが形が悪い打牌と、受け入れは少ないが変化が強い打牌を比較する。
- 序盤の孤立牌選択。
- 2シャンテンから1シャンテンへの構え。

### 判断基準

- 目先の有効牌。
- 2次変化の種類。
- 2次変化後の良形率。
- 打点上昇。
- 巡目と速度要求。

### 判断手順

1. 目先の受け入れを数える。
2. 2次変化を列挙する。
3. 2次変化で何が改善するか分類する。
4. 巡目が早ければ変化を加点する。
5. 1シャンテンならテンパイ枚数を優先する。

### 例

PDF p.87-p.88 に、目先の受け入れと2次変化を比較する例がある。牌姿は `[要確認]`。

### 例外・補正

- 親番や供託ありで速度が重要なら、目先の受けを上げる。
- 高打点条件が必要なら、2次変化を追う。

### よくあるミス

- 受け入れ枚数だけで序盤の孤立牌を切る。
- 2次変化を見すぎて1シャンテンの受けを狭める。

### 一言ルール

序盤は2次変化、1シャンテンは目先のテンパイ。

## リャンメン固定

### 要約

リャンメン固定は、良形ターツを確定させて手牌を分かりやすくする判断である。ただし、複合形やヘッドレス形では固定が早すぎると受け入れを減らす。

### 使う局面

- 複合形からリャンメン部分を残すか迷う。
- ヘッド候補が十分にある。
- 1シャンテンで受け入れ最大化したい。

### 判断基準

- ヘッド候補があるか。
- 固定後に失う受け入れ。
- 固定後の最終待ち。
- 打点変化を消さないか。

### 判断手順

1. 固定前の複合形を分解する。
2. リャンメン固定で残る受けを数える。
3. 固定しない場合の変化を数える。
4. 1シャンテンならテンパイ枚数で比較する。

### 例

PDF p.89 に「迷ったときはリャンメン固定」の扱いがある。牌姿は `[要確認]`。

### 例外・補正

- ヘッドレスでは固定しない方が広いことがある。
- 役絡みの複合形は固定で打点を消す場合がある。

### よくあるミス

- リャンメンという言葉だけで即固定する。
- ヘッド候補を確認しない。

### 一言ルール

リャンメン固定は、ヘッドが足りている時に強い。

## 迷ったときの内寄せ

### 要約

内寄せは、外側より中央寄りの牌を残す考え方である。中央牌はリャンメン化、タンヤオ、赤ドラ絡みなどの変化が多く、序盤の比較で優先しやすい。

### 使う局面

- 孤立牌同士の価値が近い。
- 悪形ターツ同士の比較。
- 序盤で手役が未確定。

### 判断基準

- 中央牌か端牌か。
- タンヤオ化しやすいか。
- 赤ドラ受けがあるか。
- 安全牌価値があるか。

### 判断手順

1. 同じ価値に見える候補を並べる。
2. 内側の牌が作るリャンメン変化を確認する。
3. タンヤオ・赤ドラ・役を加点する。
4. 安全度や場況で補正する。

### 例

PDF p.91 に内寄せの例がある。牌姿は `[要確認]`。

### 例外・補正

- 端牌が役やドラに絡むなら残す。
- 安全牌が必要なら字牌や端牌を残す。
- 一通や三色の種なら外側も価値がある。

### よくあるミス

- 内側なら何でも残す。
- 役絡みの端牌を雑に切る。

### 一言ルール

同じなら内側、ただし役と安全度で補正する。

## 何切るを作ってみよう

### 要約

何切る問題を自作すると、判断基準を言語化できる。正解を1つに決めるより、条件を変えたときに打牌が変わる理由を整理することが重要である。

### 使う局面

- 自分の牌効率理解を確認したい。
- 受け入れ、変化、打点、鳴きの比較を練習したい。
- 実戦譜から復習問題を作る。

### 判断基準

- シャンテン数が明確か。
- ブロック数が比較できるか。
- ヘッド候補の数に意味があるか。
- 候補打牌ごとの受け入れ差があるか。
- 打点や鳴きで答えが変わるか。

### 判断手順

1. 手牌、ドラ、巡目、親子、点棒状況を決める。
2. 候補打牌を2から4個に絞る。
3. 各候補の受け入れを数える。
4. 2次変化、打点、鳴きを評価する。
5. 条件を変えて別解を作る。

### 例

PDF p.92 に何切るを作る観点がある。巻末例題一覧は p.100-p.112。個別牌姿は小さく、転記は `[要確認]`。

### 例外・補正

- 実戦では守備や押し引きも入るため、牌効率だけでは決まらない。
- 学習目的なら、あえて牌効率だけに条件を限定するとよい。

### よくあるミス

- 正解だけを覚える。
- 条件を明示せずに議論する。
- 受け入れ枚数だけで解説を終える。

### 一言ルール

何切るは、答えより判断軸を作る練習。
