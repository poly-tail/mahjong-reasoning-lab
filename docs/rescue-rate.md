# Rescue Rate

脇救済率は、短時間窓の中で自分の不利局面が脇の行動や局面進行によって緩和される確率です。

## Definition

対象にする時間窓は明示します。

- 自分の次手番まで
- 一巡以内
- 流局まで
- 任意入力

救済イベント例:

- 脇の和了
- 脇の放銃
- 鳴きによる巡目/安牌変化
- 安牌供給
- 流局接近
- 相手の速度低下

## Calculation

入力値がある場合は概算として次を表示します。

```text
q_total = 1 - product(1 - q_i)
```

ただし、イベントは独立とは限らないため、表示は「上限レンジ」として扱います。

入力値がない場合は定性的な帯を使います。

- 低い: 0-10%
- ややある: 10-20%
- そこそこ: 20-30%
- 高い: 30%超

## Warnings

`q_total > 0.3` のとき、UIは過大評価警告を出します。

脇救済率は危険牌選択の免罪符ではありません。押し引きでは `fold_risk` を下げる補正、`push_value` を上げる補正として参照できますが、時間窓と上限をセットで扱います。
