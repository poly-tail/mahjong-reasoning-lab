# 卓上動態 / 他家介入読み

旧称の「脇救済率」は、Phase1: Reading Probability Core では押し引き判断材料ではありません。

Phase1では、脇の和了、放銃、鳴き、安牌供給、流局接近などで局面文脈が変わる可能性を、卓上動態 / 他家介入読み、または脇介入イベント仮説として扱います。

## Definition

対象にする時間窓は明示します。

- 自分の次手番まで
- 一巡以内
- 流局まで
- 任意入力

含めてよいイベント:

- 脇の和了可能性
- 脇の放銃可能性
- 脇の鳴きによる安牌供給
- 流局接近
- 他家の介入で現在の危険状態や点数文脈が変化する可能性

## Calculation

入力値がある場合は概算として次を表示します。

```text
q_total = 1 - product(1 - q_i)
```

ただし、イベントは独立とは限らないため、表示は「上限レンジ」として扱います。

`q_total` は押し引きEVではありません。行動推奨、局収支EV、順位点EVとして表示しません。

入力値がない場合は定性的な帯を使います。

- 低い: 0-10%
- ややある: 10-20%
- そこそこ: 20-30%
- 高い: 30%超

## Phase1での使い方

この項目は押し引き判断ではなく、卓上動態の読み候補です。

行動推奨には使わず、候補確率、未配分確率、例外候補、未知バッファの整理に使ってください。

Reading Drawer から追加する場合は、必要に応じて4軸影響を持てます。ただし4軸影響はReasoning Labでの影響分析に接続するためのものであり、Action Recommendationではありません。

## Warnings

`q_total > 0.3` のとき、UIは過大評価警告を出します。

禁止:

- 脇救済率を押しの免罪符にする
- q_totalを押し引きEVとして表示する
- 「脇救済率が高いから押し」と表示する
- 行動推奨へ直接接続する

表示文言の基準:

> この項目は押し引き判断ではなく、卓上動態の読み候補です。行動推奨には使わず、候補確率・未配分・例外候補の整理に使ってください。
