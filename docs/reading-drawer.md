# 読みの引き出し

読みの引き出しは、未配分確率が残ったときに追加候補を探すためのローカル catalog です。外部 API や LLM 連携は使いません。

実装は `src/domain/readingDrawer.ts` と `src/ui/reading/ReadingDrawerSuggestionPanel.tsx` です。

## カテゴリ

- 副露意図: 速度副露、役牌バック、染め移行、形式テンパイ、安牌確保副露、牽制/ブラフ
- 打点パターン: ドラ絡み、赤絡み、染め、トイトイ、チャンタ、役牌重なり、親番高打点
- 進行度: 先制テンパイ、1シャンテン、まだ遠い、鳴きで急加速、巡目に対して遅い
- 待ち・形: 良形テンパイ、愚形テンパイ、くっつき、縦受け、変化残り、待ち候補不明
- 危険牌・安全度: 無筋危険牌、片筋、壁、ワンチャンス、現物、スジ引っかけ、間4軒
- 点数状況: トップ目維持、ラス回避、親番維持、オーラス条件、供託回収、本場価値
- 卓上動態: 脇救済、脇の和了、脇の放銃、鳴きによる安牌供給、流局接近
- 相手傾向: 鳴きが軽い、打点寄せ、守備寄せ、ブラフ多め、押し返し多め
- 例外・ノイズ: 空切り、手順偽装、観測ミス、記憶違い、河のノイズ、レア役、意図不明打牌

## 追加時の挙動

候補に追加すると `ChoiceCandidateDraft` に変換します。`default_probability` があれば未配分からその分を割り当て、なければ残り未配分を使います。

例外集に追加すると residual bucket を作ります。反映時には例外ノードとして active case に attach できます。

未知バッファへ送る場合は、候補確率へ按分せず残差として保持します。

## 4軸

各候補は必要に応じて次の4軸への影響を持ちます。

- 進行度・聴牌率
- 打点
- 待ち・形の良さ
- 点数状況・行動閾値

これにより、候補追加が単なるラベル追加ではなく、Reasoning Lab の影響レイヤーに接続しやすくなります。
