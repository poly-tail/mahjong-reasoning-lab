# 手牌価値レンジ4軸

Phase1: Reading Probability Core では、4軸を読みの影響射影先として扱います。押し引きや牌選択の最終判断軸ではありません。

正規4軸:

1. 進行度・聴牌率
2. 打点
3. 待ち・形の良さ
4. 点数状況・行動閾値

点数状況・行動閾値は削除しません。ただし、最終的な押し引き判断そのものではなく、読みが局面文脈上どれくらい重く扱われるべきかを表す文脈射影軸です。

## 排他的候補ではない

4軸は排他的候補ではありません。1つの読みが複数軸を同時に動かすことがあります。

たとえば副露読みは、進行度・聴牌率を上げながら、打点や待ち・形の評価も変えることがあります。したがって、4軸の影響ウェイト合計を100にする必要はありません。

## 影響ウェイト

影響ウェイトは各軸独立の0〜100スコアです。

- 候補確率ではありません。
- 未配分確率でもありません。
- 軸ごとの「どれだけ動かすか」の重みです。

入力値を内部保存するときは従来どおり0〜1に変換します。UI上の `70/100` は内部的には `0.7` です。

## 軸確信度

軸確信度は、方向と影響ウェイトの見積もりをどれだけ信頼するかの0〜100スコアです。

読み全体の確信度、候補確率、未配分確率とは別です。

## 影響配分

影響配分を出す場合、それは派生表示です。入力値そのものではありません。

例:

- 入力: 進行度 70/100、打点 65/100、待ち・形 50/100
- 派生表示: この読みは進行度と打点に強く効いている

派生表示で比率やランキングを作ることはできますが、入力時に4軸を100へ配分する必要はありません。

## 例

「親リーチ後の無筋456」は、進行度・聴牌率に強く効く可能性があり、待ち・形の良さにも効きます。打点への影響は状況次第です。

点数状況・行動閾値には「自分の文脈上、危険読みをどう重く扱うべきか」という読みの射影として効きます。

ただし、この4軸評価だけで「押す/引く/何を切る」を推奨してはいけません。

## 禁止する解釈

- 4軸を候補確率として扱う
- 4軸の合計を100にする
- 点数状況・行動閾値から直接「押し推奨」「引き推奨」を出す
- 4軸だけで牌選択を出す

影響配分を出す場合は派生表示です。入力値そのものではありません。
