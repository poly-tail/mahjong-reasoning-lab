# 見え枚数 UI

更新日: `2026-04-21`

この文書は `Visible x3/x4`、推測見え枚数編集、自家 `2見え以下字牌` の仕様をまとめます。

## 責務分離

| レイヤ | 担当 | 意味 |
| --- | --- | --- |
| 実見え枚数 | `src/visible_tiles.py` | 実際に公開された枚数 |
| 推測見え枚数 | `src/ui/table_renderer.py` | UI 推測で足す枚数 |
| 合わせ打ち | `src/ui/table_renderer.py` | 記号表示の別系統 |

## `Visible x3 / Visible x4`

- 実見え枚数と推測見え枚数の合算グリッドを表示する
- 実見え枚数のみと推測加算ぶんを見分けられるよう境界で区別する
- UI 上限は `4見え`

## 推測見え枚数編集

- 河クリックから入れる
- 37種牌セレクタからも入れる
- 手動補正は推測見え枚数のみを書き換える

## 自家 `2見え以下字牌`

- `0見え / 1見え / 2見え` の字牌を候補表示する
- 公開枚数判定は `捨て牌 + 晒し牌 + ドラ表示牌`
- 表示位置は自河の右、自副露帯寄り
- 目的は「切られた字牌」と「自家の副露状況」を見比べやすくすること
