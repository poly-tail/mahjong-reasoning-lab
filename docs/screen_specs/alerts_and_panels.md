# パネルとアラート

updated: `2026-05-10`

この文書は `AI TOP3`, `SELF`, 相手パネル, 状況表, 自家字牌一覧の表示仕様をまとめます。

## `AI TOP3`

- 最大 3 行
- 各候補は `pt + 和了率`
- 1 位は緑
- 2 位以下でも `top EV - 50pt` 以内なら緑

## `SELF`

- `LOW EV`, `EV<800`, `HIGH EV` などを表示する
- alert 判定は `AI TOP3` の並び順とは別ルール

## 状況表

- `上家 / 対面 / 下家 / 総計` の 4 面を表示する
- `上家 / 対面 / 下家` は各相手の河と副露の間
- `総計` は `AI TOP3` 直下
- manual input は `-4 .. +4`
- 左 click は `+1`
- 右 click は `-1`

## 相手パネル

### `Remain`

- 表示形式は `Remain: current/no-temp`
- `no-temp` 値に応じて色を変える

### `Push`

- パネル上に `Push` chip を表示する
- 通常は `danger >= 9%`、対象にリーチ者が含まれる成立だけ `danger >= 6%` で点灯する
- 河の `P` と同じ latest-discard 条件で点灯する
- ただしパネル側だけ `3巡` 保持と `Push解除` への変換を行う

### `DETAIL`

- 右の shared detail 領域をその相手向けに切り替える
- 対象プレイヤーの `player_profiles.user_memo` を編集する

### `STATUS`

- 右の shared detail 領域を `Player Status` 表示へ切り替える
- 対象プレイヤー名を Nodocchi 検索名として使う
- 表示対象は Nodocchi の `鳳凰卓分析 / 4人打ち`
- 取得中は `成績を取得中...` を表示する
- 成功時はプレイヤー名、取得日時、対局数、平均順位、和了率、放銃率、副露率、リーチ率、順位率、アガリ、リーチ、放銃、役、ドラなどを表示する
- 取得失敗時は `Nodocchiの成績を取得できませんでした` と理由を短く表示する
- データなしの場合は `このプレイヤーの鳳凰卓4人打ち成績が見つかりませんでした` を表示する
- どの状態でも `Nodocchiで開く` ボタンを表示し、外部ページをブラウザで開けるようにする
- 同一プレイヤーの取得中は連打しても多重リクエストしない

### `プレイヤー補正`

- 現時点では shared detail 領域の placeholder 表示

## 自家 `2見え以下字牌`

- 対象は `0見え / 1見え / 2見え` の字牌
- 公開枚数判定には `捨て牌 + 晒し牌 + ドラ表示牌` を使う
- 自河の右側に出す
- 従来の中央寄せではなく、自副露帯寄りに少し下げる
- 視線を `自河 -> 自副露` へ流しやすくする補助表示として扱う
