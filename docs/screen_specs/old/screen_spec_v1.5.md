# 画面仕様書 v1.5

## 1. 文書位置づけ

- 本版は `screen_spec_v1.0.md` を継承し、2026-04-03 時点の UI 追加差分を定義する。
- 基本レイアウト、卓外枠、牌画像寸法の基準は `v1.0` を踏襲する。
- UI 編集プロトコルは `ui_principles.md` / `screen_map.md` / `invariants.md` / `change_request.md` で別管理する。

## 2. 更新対象

- 自家手牌右側 `AI TOP3` ボタン / パネル
- 自家手牌下 danger bar 群
- 他家プレイヤーパネル `SUMMARY` 内の tile rank 表示
- 横長パネル高さの更新

## 3. 自家手牌右側 AI パネル

- ボタンラベルは `AI TOP3` とする。
- ボタンはトグル式とし、ON でパネル表示、OFF でパネル非表示とする。
- OFF 中は新規 POST を発行しない。
- ON 中に手牌が変わった場合は再取得を許可する。
- パネルは手牌 strip の右側に固定表示する。
- パネル内は `順位 / 牌画像 / 期待値` を1行として上位3件を表示する。
- 牌は文字列 `3m` ではなく縮小牌画像を使う。
- 期待値文字列は従来より少し大きめの文字サイズで表示する。

## 4. danger bar 表示

- 自家手牌各牌の下に 3 本の縦 bar を表示する。
- 色は `上家=青`, `対面=黄`, `下家=緑` とする。
- `%` 表示は seat 順で `上家 / 対面 / 下家` とする。
- bar の高さ上限は `30%` を飽和点とする。
- 表示値は `danger_suji` の最終危険度をそのまま使う。

## 5. プレイヤーパネル SUMMARY

### 5.1 共通

- `Remain` は denominator 側の残筋本数を表示する。
- `Line` は line danger 上位3件を表示する。
- `Tile rank` は牌別危険度上位5位までを表示する。
- 同率牌は同一行へ最大5牌までまとめ、右端に共通 `%` を1回だけ表示する。

### 5.2 横長パネル

- 横長パネル高さは `96px` を基準とする。
- 1 行目に `player name` と `Remain` を置く。
- 2 行目に line top3 を 3 カラムで置く。
- tile rank は縦積みではなく、2件ずつ畳んで最大3行に収める。

### 5.3 縦長パネル

- 1 行目に `player name`、次行に `Remain` を置く。
- `Line` 見出しの下に top3 を縦並びで表示する。
- `Tile rank` 見出しの下に上位5行を縦並びで表示する。

## 6. responsive

- 半画面程度まで狭くなった場合は縮小牌画像セットへ切り替える。
- summary 文言は幅内へ収まるよう `_fit_text_to_width()` で丸める。
- danger bar, AI panel, detail panel は縮小時も相互に重ならないこと。

## 7. detail パネル

- `DETAIL` ボタンの挙動自体は継続する。
- 追加した `AI TOP3` パネルと同時表示されても、detail 領域と干渉しないこと。
