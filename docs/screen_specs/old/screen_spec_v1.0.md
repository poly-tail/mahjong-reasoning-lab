# 画面仕様書 v1.0
> 2026-03-22 時点の画面モック設定値を固定化した版ファイル。

## 1. 対象
- 対象実装: `src/LoadImage.py`
- 対象用途: 天鳳補助ツールの卓面モック UI
- 版番号: v1.0
- 作成日: 2026-03-22

## 2. 画面構成
- 右端に詳細情報スペースを 1 つ配置する。
- 画面中央左寄りに卓面を置く。
- 卓面の上に対面プレイヤーパネル、下に自家プレイヤーパネルを置く。
- 卓面の左に上家プレイヤーパネル、右に下家プレイヤーパネルを置く。
- 卓面の四辺に 4 つの捨て牌情報スペースを置く。
- 自家の手牌表示スペースは、自家捨て牌情報スペースの下、自家プレイヤーパネルの上に置く。
- 局情報概要スペースは左上側の空き領域に置く。

## 4. 捨て牌情報スペース仕様
### 4.1 形状
- 対面捨て牌情報スペース: 6 列 x 3 段
- 自家捨て牌情報スペース: 6 列 x 3 段
- 上家捨て牌情報スペース: 3 列 x 6 段
- 下家捨て牌情報スペース: 3 列 x 6 段

### 4.2 サイズ算出式
- `top_bottom_zone_width = bottom_width * 6`
- `top_bottom_zone_height = bottom_height * 3`
- `side_zone_width = side_width * 3`
- `side_zone_height = side_height * 6`

### 4.3 実装上の意味
- `bottom_width`, `bottom_height` は自家向き牌画像の実寸。
- `side_width`, `side_height` は下家向き牌画像の実寸。
- 牌画像サイズを縮小または拡大すると、捨て牌情報スペースは同じ比率で追従する。
- 捨て牌の描画ピッチも牌画像実寸に合わせる。

## 5. プレイヤーパネル仕様
- 対面/自家プレイヤーパネルは横長長方形とする。
- 上家/下家プレイヤーパネルは縦長長方形とする。
- パネル内部は `SUMMARY`、`ALERT`、`BUTTONS` の 3 区画構成とする。
- 自家手牌下バーと相手 `SUMMARY` の筋情報は、同一の最終筋線重みを表示する。
- 最終筋線重みは `0本抑制 -> matagi -> chi補正 -> 内牌→外牌補正 -> lag補正` の順で作る。
- `kanchan` / `penchan` / `ryanmen` の鳴き形補正は画面専用値ではなく、内部 danger 計算値をそのまま使う。
- 概要表示、アラート表示、詳細切替ボタン群を収める。

## 6. 詳細情報スペース仕様
- 詳細情報スペースは画面右端に独立配置する。
- 上部を `3枚見え情報スペース` とする。
- 中部を `4枚見え情報スペース` とする。
- 下部を `詳細情報表示スペース` とする。
- `3枚見え情報スペース` の見出しは、共通タイトルと重ならないよう表示開始位置を下げる。

## 7. 局情報概要スペース仕様
- 表示内容は、局数、本場、ドラ、供託を想定する。
- 現行モックでは `EAST 3 / 1 HONBA`、`DORA`、`RIICHI STICKS` を表示する。
- 中央のガイド四角形は表示しない。
- 捨て牌情報スペースと重ならない空き領域内に収める。

## 8. 手牌表示仕様
- 手牌は横並びで表示する。
- 14 枚目のツモ牌は右側に少し空けて表示する。
- 手牌表示スペースの背面に黒い長方形は描画しない。

## 9. 色と見た目
- 卓背景: 単色に近い青系
- プレイヤーパネル: 暗い紺系
- 捨て牌情報スペース: 卓面より少し濃い青
- 手出し牌: 赤枠
- ツモ切り牌: 暗色化

## 10. 既知の調整ポイント
- プレイヤーパネル位置は数 px 単位で追加調整の余地がある。
- 局情報概要スペースは、左上空き領域との干渉確認を継続する。
- 詳細情報スペースの見出し位置は、フォントや文言変更時に再確認する。
